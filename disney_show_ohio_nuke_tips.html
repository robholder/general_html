doNuke

Launch using doNuke. This is a wrapper for run_nuke. It adds more checks to see if there are third-party or prime contents to flag. 

doNuke --{flag} fullcomp.v####.nk

Flags

  • -nukex <- Loads NukeX (not Nuke)
  • -sapphire <- Loads with Sapphire plugin
  • -opticalFlares <- Loads with Optical Flares plugin
  • -pause <- Starts Nuke with viewers paused
  • -n <- Starts Nuke with postage stamps paused
