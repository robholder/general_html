Unlocking

To Explore ONLY

If you try to snoop inside a locked module, you will get 'Permission Denied'.

To explore a node/packet (without checking out):

  • RMB on the node graph while inside a task/node
    • Allow Editing of Contents

This allows you to click around and see what's going on, including viewing the Lightbox node, and other nodes.

⛔ DON'T MODIFY ANYTHING! ⛔

⚠️ Caution ⚠️

Unlocking will prevent updates from upstream.

The node which has been unlocked will have a crossed-out circular warning.

To restore inheritance, either:

  • RMB on the node graph and choose:
    • Match Current Definition
    • You'll get a lot of errors on a message box
  • -HOTL shelf:
    • Upgrade to Latest
YOU'LL LOSE ANY CHANGES IF YOU UPDATE.

"Update Available"

Indicated with: ⚠️

Apparently, there will be an indication of any available updates on the node in question (if a new version is published). This will appear as a caution triangle with an arrow on the node.

There is a tool on the HOTL toolbar which might elude to 'upgrade to the latest'. Haven't seen, but that's what has been mentioned.

If you have the module/node unlocked, you have to remove any changes and edits to be able to initiate the update.

RECOMMENDED Solution to this predicament

  • Duplicate the unlocked node.
  • Remove your edits.
  • Update the 'cleaned' node
  • Manually copy your changes from one to the other.

To Actually Edit

Only edit if you are Authorized to work in that HOTL!

  • RMB > HOTL > Check-out

If you Are in a checked-out state, this option with be switched to Commit... in the context menu:

  • RMB > HOTL > Commit...
⚠️ ONLY COMMIT WHAT YOU ARE AUTHORIZED TO! ⚠️

Terms

  • Checkout (allow for authorized changes)
  • Commit ('publish' for others' availability)

RegionGrad Layout

If you are adding multiple RegionGrads make them in parallel (not 'inline') and plug into the merge_RgradShapes node.

More efficient: This way, changing one won't force all to re-cook.

Lightbox panel

Don't 'pin' a parameter pane with Lightbox on it! This causes a re-cook for every change.

Instead use the dedicated Lightbox pane.

Houdini Tips

Tips and Tricks (Houdini)

Thumbnail tip

To get a thumbnail preview of the shot(s) you are working on:

  • Select your 'shot' node
  • On the -Lighting Tools shelf:
    • Click on Load DPix Thumbnail

Working in the Open Lighting Area

If you use the 'open' area to construct light setups (not in a Lightbox)

  • Too many lights in series - bad. (Too much cooking)
  • Merge them in parallel instead. (I don't know which is the correct merge option here.)

Checking Stereo in Nuke

QUIP: View Stereo in RV

To show the images in RV there are two buttons on the Quip panel:

  • Mono
  • Stereo

Hover over these buttons to see a note on the RV hotkeys for viewing in various modes.

  • Toggle left and right with dropdown (bottom right) or with hotkeys.

Switch to Stereo

In Quip, use the:

  • Switch to Stereo button:
    • Nuke will drop red stereo backdrops where necessary.
  • Check Stereo button:
    • Nuke will do a logic test and report issues in a message box.
  • Check Inline Nodes button:
    • Flags things tricky for Stereo artists.
    • A message box shows a list of nodes.

Post-Render Delivery "Lighting Submit"

You have to run the Check Lighting button when using lighting_submit (at 'Final').

It's the same check as in Nuke - with a dialog box which lists issues.
