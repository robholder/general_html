Zsh - History Management

Thorough Command History in Zsh (with Tmux)

To make Zsh keep a massive, persistent, and synchronized command history across all your open tabs, windows, and Tmux panes, add the following configuration block to your ~/.zshrc: 

# History file configuration
HISTFILE="$HOME/.zsh_history"
HISTSIZE=1000000
SAVEHIST=1000000

# History behavior options
setopt EXTENDED_HISTORY          # Write the history file in the ":start:elapsed;command" format
setopt INC_APPEND_HISTORY        # Write to the history file immediately, not when the shell exits
setopt SHARE_HISTORY             # Share history across all active sessions/Tmux panes
setopt HIST_EXPIRE_DUPS_FIRST    # Expire duplicate entries first when trimming history
setopt HIST_IGNORE_DUPS          # Don't record an entry that was just recorded again
setopt HIST_IGNORE_ALL_DUPS      # Delete old recorded entry if new entry is a duplicate
setopt HIST_FIND_NO_DUPS         # Do not display a line previously found when searching
setopt HIST_IGNORE_SPACE         # Don't record an entry starting with a space
setopt HIST_SAVE_NO_DUPS         # Don't write duplicate entries in the history file
setopt HIST_REDUCE_BLANKS        # Remove superfluous blanks before recording entry

Why this works seamlessly with Tmux:

  • SHARE_HISTORY is particularly powerful for Tmux users. It ensures that as soon as you type a command in one Tmux pane, it becomes immediately available via the up-arrow or search in all other open Tmux panes and windows.
  • EXTENDED_HISTORY logs exact timestamps and command execution durations, which is great for auditing when things ran.
