RegionGrads - as Color Mattes

  • ExternalLink: GoogleDrive - Video - RGrads-Colormattes-HD4K-5Mbps.mp4

Make an RGrad

  • Create a RGrad in space

Setup ColorMattes to recieve RGrad Matte(s)

  • Create a Color Matte:
    • Tab and drop a ColorMattes node (not 'dpipe Modifier'):
      • Set an lrig Palette field (Local?)
      • Click on the Color Mattes Wizard icon (tricolor icons)
        • Set a channel (R, G or B with a check in the checkbox)
        • Create button to create matte channel
        • Close Gui.
NOTE ON SCREEN OF TUTORIAL: Legacy method described. (However, it's still the way to do this.

Setup RGrad Matte(s) Definition

  • You should be dropped into the colormattes node where you'll see a node for each channel you chose/setup.
  • On Attributes tab:
    • Toggle the User Vars section:
      • Choose regionGradients from the + dropdown.
      • Rename if you want in the field (<rgrad_name> for this explanation.)
      • NOTE: This name is only used to define the grad in the [0, 0, 0] expression - it's not the actual RGrad name.
    • In the Custom area that is exposed below the RegionGrad section:
      • For the Green channel:
        • colorMatte0 (or whatever number you have) -> [0, <rgrad_name>, 0]
    • Again under the RegionGradients field:
      • Click on the regionGradients slot creation (+ for each - usually 1)
      • In the Layer Settings section that appears:
        • Region Grad Prim Shapes
        • Drag your actual RegionGradient shape from your SGT (Scene Graph Tree)
        • Use the node/item that ends in _rgshp (the 'shape')
        • This will add a path to the RGrad

Assignments

  • Go to the Assingments tab:
    • Assign as normal:
      • items
      • collections
      • etc.

Activate

  • Activate ColorMatte0 (or whatever ColorMatte# you've made)
    • RenderOutputEdit node at the base of the Render layer(s)
    • Switch on the ColorMatte#
