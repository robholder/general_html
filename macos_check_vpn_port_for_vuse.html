Check Port of VPN for Vuse

To Only Have Vuse Active When A VPN Is Active

In Vuse, open Preferences:

  • Vuse > Preferences > Connection >Advanced Network Settings

Get the Interface ID

Find the interface:

In a shell: 

ifconfig -v

Look for port description which contains the VPN name. It'll look something like this: 

ipsec0: flags=8051<UP,POINTOPOINT,RUNNING,MULTICAST> mtu #### index 15
        eflags=1002080<TXSTART,NOAUTOIPV6LL,ECN_ENABLE>
        inet ###.##.##.### --> ###.##.##.### netmask 0xf#######
        agent domain:NetworkExtension type:VPN flags:0x3 desc:"VPN: StrongVPN IKEv2 Configuration"
        state availability: 0 (true)
        scheduler: FQ_CODEL
        effective interface: en1
        qosmarking enabled: no mode: none
        low power mode: disabled

In this case, enter ipsec0 into the "Bind to local IP address or interface" field.
