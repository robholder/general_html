Bash (& Zsh) - Colors in Scripts

How to Use a Color Picker for Terminal Scripts

You can use any standard design color picker (like Google's color picker, Figma, or your OS color wheel) to choose a color, grab the hexadecimal (#RRGGBB) or RGB (R, G, B) value, and feed it directly into your terminal scripts.

True Color / RGB Format (Recommended)

Most modern terminals support 24-bit true color. This bypasses the terminal's theme settings entirely, meaning your script will look exactly the same on every machine.

  • The ANSI Template: \033[38;2;<R>;<G>;<B>m
  • Example: Let's say your color picker gives you a custom coral red with RGB values 255, 99, 71: 
COLOR_CORAL = "\033[38;2;255;99;71m"

256-Color Palette Format

If you are working on older systems or constrained environments, you can use a fixed 256-color palette.

  • The ANSI Template: \033[38;5;<ColorNumber>m
  • How to pick: You can look at a standard 256-color ANSI chart to pick a fixed color number (for example, number 196 is a clean, bright red). 
COLOR_PURE_RED = "\033[38;5;196m"

Integrating True Color into Your Script

You can update your script's error logging block using explicit, beautiful True Color definitions to ensure it stays readable regardless of your terminal setup: 

# True Color RGB definitions (Independent of terminal themes)
COLOR_ERROR_RED="\033[38;2;255;75;75m"    # Crisp, bright cherry red
COLOR_INFO_BLUE="\033[38;2;100;149;237m"  # Cornflower blue
COLOR_RESET="\033[0m"                     # Clears color styling

show_usage() {
    echo -e "${COLOR_ERROR_RED}==================================================================${COLOR_RESET}"
    echo -e "${COLOR_ERROR_RED}❌ ERROR: Invalid or Missing Arguments${COLOR_RESET}"
    echo -e "${COLOR_ERROR_RED}==================================================================${COLOR_RESET}"
    echo -e "Usage:   $(basename "$0") <sequence> <shot> <flavor>"
    echo -e "Flavors: 'hou' (Houdini) or 'nuke' (Nuke)"
    echo -e "${COLOR_INFO_BLUE}------------------------------------------------------------------${COLOR_RESET}"
    echo -e "Example: $(basename "$0") 100 37 hou"
    echo -e "${COLOR_ERROR_RED}==================================================================${COLOR_RESET}"
    exit 1
}

(Note: When printing these explicit escape strings via the echo command in Bash, remember to use the -e flag so the shell interprets the backslash escapes instead of treating them as plain text.)

Script to Generate Palette

Here is a quick script to generate a color testing matrix directly inside your terminal, followed by the specific syntax for coloring text backgrounds.

Part 1: The 256-Color Palette Preview Utility

Run this single command block directly in your Zsh or Bash terminal (it works perfectly inside active Tmux panes as well). It loops through every color index from 0 to 255 and prints the color number over its corresponding background block. 

for i in {0..255}; do
    printf "\033[48;5;%sm%4s \033[0m" "$i" "$i"
    if [ $(( (i + 1) % 8 )) -eq 0 ]; then echo; fi
done
  • How to read the grid: Look through the generated chart to find a tone you like, then note its exact number identifier.
  • Why it breaks cleanly: The code features an inline math check (% 8) to automatically snap rows into clean blocks of eight numbers so it stays organized.

Part 2: Working with Background Colors

To change the background color of your text instead of the text itself, you alter a single digit in the ANSI escape sequence.

  • Foreground (Text color): Uses code identifier 38 (True Color) or 3X (Basic).
  • Background (Block highlight): Uses code identifier 48 (True Color) or 4X (Basic).

256-Color Background Template

# Template syntax structure: \033[48;5;<COLOR_NUMBER>m
BACKGROUND_GOLD="\033[48;5;214m"
COLOR_RESET="\033[0m"

echo -e "${BACKGROUND_GOLD} ATTENTION: RE-RENDERING CACHE ${COLOR_RESET}"

24-Bit True Color (RGB) Background Template

# Template syntax structure: \033[48;2;<R>;<G>;<B>m
BACKGROUND_DEEP_RED="\033[48;2;139;0;0m"
TEXT_WHITE="\033[38;2;255;255;255m"
COLOR_RESET="\033[0m"

echo -e "${BACKGROUND_DEEP_RED}${TEXT_WHITE} CRITICAL CORE ERROR ${COLOR_RESET}"
