Linux

There are several quick commands built into Linux to check when a workstation was last rebooted.

The uptime Command (Easiest)

You can use the --since flag to get the exact date and time the system was last started up: 

uptime -s

(Or just typing plain uptime will show you how long the system has been running overall).

The who Command

Using the -b (boot) flag with who prints the exact timestamp of the last system boot: 

who -b

The last Command (For Reboot History)

If you want to see a historical log of previous reboots rather than just the current session, check the system's login records: 

last reboot

This lists out past reboot events, kernel versions used at the time, and timestamps.

The last command does not have a built-in flag to change its sort order, but you can easily reverse the list by piping the output into tac (which prints lines in reverse order, putting the oldest reboots at the top and the newest at the bottom): 

last reboot | tac
