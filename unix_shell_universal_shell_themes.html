You can extend theme-switching workflow to other terminals like WezTerm, macOS Terminal.app, and Linux Virtual Consoles / Standard Terminals (like GNOME Terminal, Konsole, or generic xterm-compatible Linux terminals).

The trick is using Terminal Escape Sequences or CLI configuration triggers that each application supports natively.

WezTerm

WezTerm handles themes via its Lua configuration file (~/.config/wezterm/wezterm.lua). It doesn't use a live hot-reload file like Kitty's current-theme.conf out of the box, but you can achieve dynamic switching by having your script rewrite a small state file or Lua module that WezTerm reads.

In your wezterm.lua:

Read a dynamic theme file written by your shell script: 

local wezterm = require 'wezterm'
local config = {}

-- Try to read a theme override written by your switch_theme function
local f = io.open(os.getenv("HOME") .."/.config/wezterm/active-theme.txt", "r")
if f then
    config.color_scheme = f:read("*all"):gsub("%s+", "")
    f:close()
else
    config.color_scheme = 'Catppuccin Frappe' -- default fallback
end

return config

Add WezTerm handling to your switch_theme function

Map your themes to WezTerm’s built-in scheme names (WezTerm natively includes "Catppuccin Frappe", "Nord", etc.) and write to that tracking file: 

# Inside your switch_theme function:
if command -v wezterm &>/dev/null && [[ -n "$wezterm_scheme" ]]; then
    echo "$wezterm_scheme" > "$HOME/.config/wezterm/active-theme.txt"
    # WezTerm automatically watches and hot-reloads config changes!
fi

Standard Linux Terminals (GNOME Terminal, Konsole, Xterm, etc.)

Standard Linux terminal emulators can change their background and text colors dynamically without restarting using ANSI OSC (Operating System Command) escape sequences.

You can push color changes directly to the current terminal window standard output stream. This works universally on almost any standard Linux terminal.

To change the background color via script: 

# Format: \e]11;#RRGGBB\a
echo -ne "\e]11;#2e3440\a" # Sets background to Nord dark

To change the foreground (text) color via script: 

# Format: \e]10;#RRGGBB\a
echo -ne "\e]10;#d8dee9\a" # Sets text color

macOS Terminal.app

Apple's built-in Terminal app doesn't natively parse standard ANSI background escape sequences reliably across all profiles. Instead, it relies on AppleScript.

You can execute AppleScript directly inline from your Zsh function using osascript -e to change the active window's profile or RGB background color: 

if [[ "$OSTYPE" == "darwin"* ]] && command -v osascript &>/dev/null; then
    # Option A: Switch to a predefined macOS Terminal Profile name
    osascript -e "tell application \"Terminal\" to set current settings of window 1 to settings set \"$macos_profile_name\""
    
    # Option B: Or send explicit RGB background values (values from 0 to 65535)
    # osascript -e "tell application \"Terminal\" to set background color of window 1 to {12288, 14336, 17408}"
fi

Unified Multi-Terminal Function Example

Here is how you can expand your switch_theme function to handle Kitty, WezTerm, Linux ANSI sequences, and macOS Terminal all at once: 

switch_theme() {
    local theme_name="$1"
    
    # Define your themes: 
    # "short_name : eza_file : kitty_file : wezterm_scheme : macos_profile : bg_hex"
    local -A themes=(
        [catppuccin]="theme-catppuccin.yml:Catppuccin-Frappe.conf:Catppuccin Frappe:Pro:#303446"
        [nord]="theme-nord.yml:Nord.conf:Nord:Basic:#2e3440"
        [adapta]="theme-adapta.yml:Adapta_Nokto_Maia.conf:Adapta:Ocean:#222d32"
    )

    if [[ -z "${themes[$theme_name]}" ]]; then
        echo "Unknown theme: '$theme_name'"
        echo "Available themes: ${(k)themes[*]}"
        return 1
    fi

    IFS=':' read -r eza_file kitty_file wezterm_scheme macos_profile bg_hex <<< "${themes[$theme_name]}"

    # 1. Update eza theme
    local eza_target="$HOME/.config/eza/$eza_file"
    if [[ -f "$eza_target" ]]; then
        cp "$eza_target" "$HOME/.config/eza/theme.yml"
        echo "Updated eza theme to: $theme_name"
    fi

    # 2. Apply to Kitty (if active)
    if command -v kitty &>/dev/null && [[ "$TERM" == "xterm-kitty" ]]; then
        local kitty_target="$HOME/.config/eza/$kitty_file"
        [[ ! -f "$kitty_target" ]] && kitty_target="$HOME/.config/kitty/$kitty_file"
        if [[ -f "$kitty_target" ]]; then
            rm -f "$HOME/.config/kitty/current-theme.conf"
            cp "$kitty_target" "$HOME/.config/kitty/current-theme.conf"
            kill -SIGUSR1 $(pgrep -u $USER -x kitty) &>/dev/null
        fi
    fi

    # 3. Apply to WezTerm (if active)
    if [[ "$TERM_PROGRAM" == "WezTerm" ]]; then
        echo "$wezterm_scheme" > "$HOME/.config/wezterm/active-theme.txt"
    fi

    # 4. Apply to macOS Terminal.app (if on Mac)
    if [[ "$OSTYPE" == "darwin*" ]] && command -v osascript &>/dev/null; then
        osascript -e "tell application \"Terminal\" to set current settings of window 1 to settings set \"$macos_profile\"" 2>/dev/null
    fi

    # 5. Fallback generic Linux Terminal ANSI background change
    if [[ -n "$bg_hex" ]] && [[ "$TERM" != "xterm-kitty" ]] && [[ "$TERM_PROGRAM" != "WezTerm" ]]; then
        echo -ne "\e]11;${bg_hex}\a"
    fi

    echo "Successfully applied theme: $theme_name"
}

Preparing Config files for each Platform/Terminal

Because every terminal app handles themes via its own proprietary configuration format, a unified shell script acts as a "router" telling each app what theme name, profile, or color code to load.

The varieties of settings map out across your environment as follows:

eza (Syntax & UI Metadata)

  • What it is: The YAML file (theme-catppuccin.yml, theme-nord.yml, etc.) located in your ~/.config/eza/ directory.
  • How it works: It dictates the color map specifically for eza's file listings (e.g., directory colors, symlinks, file size text, permissions output).
  • For other themes: You download or write the respective .yml mapping file from the eza-community/eza-themes repository and place it in your eza configuration folder.

Kitty (Terminal-Specific Native Config)

  • What it is: The .conf file (Catppuccin-Frappe.conf, Nord.conf) containing raw terminal palette hex codes.
  • How it works: Kitty dynamically reads current-theme.conf inside its config folder to paint the background, text, and ANSI 16-color blocks.
  • For other themes: You extract or download the raw .conf file tailored for Kitty (most theme creators provide a .conf alongside their theme repository) and reference it in your script mapping.

WezTerm (Lua-Driven Terminal)

  • What it is: WezTerm built-in color scheme string identifier (e.g., "Catppuccin Frappe", "Nord").
  • Diego Vicente
  • How it works: WezTerm natively includes over 700+ popular color schemes built directly into its engine. You do not need to hunt down files for it. You just need to look up WezTerm's exact name string for that theme.

WezTerm

For other themes: Check WezTerm's online color scheme gallery or write a quick loop to see if it's built-in, then plug the exact string name (like "GruvboxDark") into your script mapping.

macOS Terminal.app (Apple Ecosystem Profile)

  • What it is: A saved profile name inside Apple's native Terminal application preferences (e.g., "Pro", "Basic", "Ocean").
  • How it works: macOS Terminal doesn't easily let scripts change every single RGB color on the fly via plain text files. Instead, it relies on pre-configured Profiles that you save manually via Terminal > Settings > Profiles.
  • For other themes: You manually create a profile inside the Terminal app GUI, customize its colors to match your theme, name the profile (e.g., "Nord-Mac"), and then put that exact profile name string into your script variable.

bg_hex (Generic Linux ANSI Fallback)

  • What it is: A raw hexadecimal background color code (e.g., #2e3440).
  • How it works: If you are on a standard Linux terminal emulator (like GNOME Terminal or Konsole) that isn't Kitty or WezTerm, the script bypasses profile files and fires a raw ANSI escape sequence (\e]11;#HEX\a) straight into the shell stream to force the background color to change instantly.
  • For other themes: You just look up the core background hex code of that theme and supply it as a string.
