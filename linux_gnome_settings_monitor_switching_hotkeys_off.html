Gnome - Switch off 'meta + P' monitor switching

I need the 'meta + P' in Nuke (as a shortcut to make 'premult' nodes), but Gnome has a system wide keyboard shortcut

To disable: 

gsettings set org.gnome.mutter.keybindings switch-monitor "[]"

To restore: 

gsettings reset org.gnome.mutter.keybindings switch-monitor
