Pulling All Branches From Remote

In two steps:

One... 

git fetch --all --prune

...two... 

git pull

...done.

However, you have to 'git pull' on every branch to update them all. 

# List branches:
git branch -a
# for each branch:
git switch <branch>
git pull

Step by Step

git fetch --all --prune

git pull

Get a list of remote branches: 

git branch -a

Switch to each branch listed, and run: 

git switch <branch name>

Pull: 

git pull

Do this for all branches.

You need to switch each time before pulls and pushes (unless an alias or loop is used to automate).
