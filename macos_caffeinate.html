macOS caffeinate Reference

caffeinate is a built-in macOS command-line utility that creates power management assertions to prevent sleep, display dimming, or disk idle while a task runs.

Common Patterns

Wrap a Command (Releases Sleep Lock Automatically)

Keeps your Mac awake only until the wrapped command finishes, then restores normal power settings: 

caffeinate -dims rsync -avP user@mac-ip:/path/to/Source.utm /path/to/destination/

Stay Awake Until Stopped Manually

Runs in the terminal until you press Ctrl + C: 

caffeinate -d

Stay Awake for a Set Duration

Prevents sleep for a fixed number of seconds (example: 3600 seconds = 1 hour), then exits automatically: 

caffeinate -t 3600

Key Flags

Flag Effect
:--- :---
-d Prevents the display from sleeping.
-i Prevents the system from idle sleeping.
-m Prevents disks from idle sleeping.
-s Prevents system sleep while on AC power (useful on MacBooks).
-t <seconds> Sets a timeout in seconds before caffeinate exits.

Practical Caveats

  • MacBook lid-close behavior: Closing a MacBook lid without an external display and power adapter attached (clamshell mode) will still put the Mac to sleep—leave the lid open for long transfers.
  • Pair with power and disk space: Keep laptops plugged in during large jobs (such as multi-gigabyte backups or .utm copies) and confirm sufficient free space before starting.
