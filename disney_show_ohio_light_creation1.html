Light Creation and Placement - Part 1

  • ExternalLink: Houdini Light Types

Notes

In Houdini you can create lights by:

  • Tab and dpipe followed by name/type of light
  • Shelf tool Light and Materials Shortcuts
  • Within Light Box node

Look Through Light

  • Viewport:
    • Right side lozenge
    • Look Through Light, and choose
    • Lock the icon on the Right Vertical panel

Tip: Select character (target), the to frame on it:

  • Unlock
  • <Space> f
  • Lock

Snap Tool

  • select light
  • Click magnet icon on Left Vertical panel
  • Move mouse to 'snap' to geo in the viewport

Look At Mode

Add extra manipulators to a selected light:

  • <Shift> + L

Then use the magnet icon (LVP) to snap the target manipulator on the light to geometry

Numerical Settings

On the light's Transform tab, you can adjust conventionally with numbers.

  • MMB on a field to envoke Houdini adjustments in number fields

You can append values in Houdini's numerical fields

  • Transform tab > Operator Order > Append

Types of Lights

  • Distant light
  • Dome light
  • Quad Light
  • Sphere light
  • Spot light

Parm Panel

ALL THESE LIGHTS CAN BE ADJUSTED IN THE LIGHTBOX LRIG PANE.
  • Palette Prim:
    • Choose where to put the light.
  • Name - NOT THE NODE NAME IN THE INTERFACE:
    • (Rename an item iwth the top field title.)
  • Template:
    • Choose light time after creation (change).
    • You'll lose information if you switch after editing.
  • Hyperedit button:
    • Update 'this' light in Helios.

Tabs

Emission

  • Emissive: On/Off toggle
  • Emission Category - dropdown menu:
    • Asterisk will indicate that the emission number is already used.
    • However, you can add a light to an existing category number.
  • Light Color
  • Light Color Expression:
    • Expression field to add things like Cucaloris
  • Exposure value
  • Eye Spec checkbox (apply light to eye-spec shader)
  • Visible to Volumes - whether to light volumes
  • Visible to Camera - whether light source is visible in cam
  • Visible to Non-Camera - whether light source is visible in secondary rays

In Quad lights:

  • Virtual Light - if DISABLED, the light will cast a shadow
  • Angle - Size of light source
  • Soft Edge - blurring of shadow - not great.

Tab: Other

  • Region Grad:
    • Open widget and add rgrads here
  • Exclusive Targets:
    • Set up targets to receive the light's rays
    • Use paths, or the add buttons (including the Xgen add button on the end)
  • Exclusive Excludes:
    • Opposite of above.
    • Exclude the listed items from the light
  • Scatter:
    • Enables the facility to add a color cast on shadow edges.
    • It looks like a tint or bounce
    • Conserve Energy:
      • Colors don't affect the value of light
    • Scatter Size:
      • Heat or effect amount (default is 0.1)
    • Scatter Distribution:
      • spread (regardless of heat)

Palette User Vars

User Vars

Dome Lights

Similar to others but with other attributes.

  • IBL Environment:
    • Plug in HDR images
  • Override Lower Hemisphere:
    • This makes the lower half of the sphere a black
    • You can adjust to give upwards influence; color etc.
  • Camera Exposure:
    • Adjust brightness of IBL/HDR image

Quad Light

Emissions Tab has:

  • Width and Height controls for quad size
  • Disc Matte:
    • change to circle
  • Directional:
    • zero -> emit naturally
    • one -> emit along direction

Sphere Light

Emissions Tab has:

  • Radius:
    • Change size of sphere

Spot Light

Emissions Tab has:

  • Radius:
    • radius of the light aperture and cone
  • Spot Cone Angle:
    • Angle of the cone divergence
  • Spot Penumbra:
    • Angle of full light to full umbra/shadow
    • Larger values give softer edges
  • Penumbra Color:
    • Enable Enable Penunbra Color
    • Select color to give the gradient between dark and light a color
  • Penumbra Smoothness:
    • Not sure.

Lightbox

  • Select a category/level in the lrig list
  • Create lights here

Then all the parameters should be available as columns for each light

  • You can mult-select and apply values in one go

Overrides

If values are changed on an node further down the network, you'll create overrides on existing lights/light values.

You will see a red dot on the item/light, and a red dot on the parameter also.

What an override does is set an override toggle on the actual item/nodes parms.
