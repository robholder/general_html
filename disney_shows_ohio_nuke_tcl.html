Node Expression - Based on Shot Number

This is applied to a switch node. (It's only on/off for a specific shot.)

Switch Knob

There are two available syntax formats for the actual 'Switch' knob:

This one works for math logic (but not strings - so can't be used in Labels):

Math only: 

[expr {[getenv NAV_SHOT] == "29.00" ? 0 : 1}]

Or:

This one works as the results are boolean values: 

[if { [getenv NAV_SHOT] == 033.00} {return 0} {return 1}]

Label

This is for the Label: 

[if {[value which] == 0} {return [getenv NAV_SHOT "NO VAR PRESENT"]} {return "default"}]

Notice the expr variety is for math logic only.


Example

Here's the node to copy & paste: 

set cut_paste_input [stack 0]
version 15.0 v1
push 0
push $cut_paste_input
Switch {
inputs 2
which {{"\[expr \{\[getenv NAV_SHOT] == \"29.00\" ? 0 : 1\}]"}}
name Switch3
label "\[if \{\[value which] == 0\} \{return \[getenv NAV_SHOT \"NO VAR PRESENT\"]\} \{return \"default\"\}]"
note_font "Bitstream Vera Sans Bold"
note_font_size 14
selected true
xpos 16830
ypos 15898
}
