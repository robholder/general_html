Terminal Title Bar (Showing Env Vars)

This is how I added Env Vars to the Terminal's title bar.

NOTE: For script created Tmux sessions, I had to use a separate system as described here:

  • Bash & Zsh - Terminal Title Bar (and Tmux)

# ░▀█▀░▀█▀░▀█▀░█░░░█▀▀░░░█▀▄░█▀█░█▀▄
# ░░█░░░█░░░█░░█░░░█▀▀░░░█▀▄░█▀█░█▀▄
# ░░▀░░▀▀▀░░▀░░▀▀▀░▀▀▀░░░▀▀░░▀░▀░▀░▀

# Set Gig, Seq & Shot in title bar (for Bash & Zsh):

# ~/.window_title.sh

# Guard clause: Skip if inside Tmux or script-launched Tmux
# if [ -n "$TMUX" ] || [ -n "$TMUX_SCRIPT_LAUNCHED" ]; then
#     return 0
# fi
if [ -n "$TMUX_SCRIPT_LAUNCHED" ]; then
    return 0
fi

set_window_title() {
    local title="${PRODUCTION:-No Gig} - ${NAV_SEQ:-No Seq}/${NAV_SHOT:-No Shot}"
    echo -ne "\033]0;${title}\a"
}

# Hook into Zsh or Bash prompt commands
if [ -n "$ZSH_VERSION" ]; then
    precmd_functions+=(set_window_title)
elif [ -n "$BASH_VERSION" ]; then
    if [[ "$PROMPT_COMMAND" ]]; then
        export PROMPT_COMMAND="$PROMPT_COMMAND;set_window_title"
    else
        export PROMPT_COMMAND="set_window_title"
    fi
fi
