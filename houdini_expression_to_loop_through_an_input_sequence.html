Expressions to Loop or Bounce an Input Sequence of Maps

I had a limited (seamless loop) of input maps. The sequence stopped after the last image when driven by ＄F (or in my proprietary version of a Houdini tool, ＄frame).

These are some expressions to either 'loop' them or 'bounce' them back and forth.

All these examples assume the sequence is a collection of files from 1 to 102.

Original expression: 

$frame

Simple Loop

Simple loop: 

# Singlemap > Pick Map Expr
(($frame - 1) % 102) + 1

Bounce Options

If it doesn't loop nicely, try bounce with: 

((($frame + 100) % 202) - 101)

How it works:

  • 202 is the full cycle length of a complete bounce (101 frames up + 101 frames down).
  • + 100 and - 101 shift the wave so it neatly bottoms out at 1 and peaks at 102.
  • abs() turns the falling slope of the modulo division into a rising-and-falling triangle wave.

Illustrated in Python

In more detail... 

def bounce(f):
    return 1 + abs(((f + 100) % 202) - 101)

def breakdown(f):
    p1 = f + 100
    p2 = p1 % 202
    p3 = p2 - 101
    p4 = abs(p3)
    p5 = p4 + 1
    return f"Frame {f}: ({f} + 100) = {p1} | {p1} % 202 = {p2} | {p2} - 101 = {p3} | abs({p3}) = {p4} | {p4} + 1 = {p5}"

for f in [1, 50, 102, 103, 150, 203]:
    print(breakdown(f))

Breakdown

It helps to break down the formula step-by-step. The snippet you shared is actually the inner "engine" of the full bounce formula, which looks like this with the abs() (absolute value) and + 1 included: 

$1 + abs((($frame + 100) % 202) - 101)$$

Here is what each part of that expression does to turn a linear timeline into a triangle wave (rising up to 102, then falling back down to 1):

Step-by-Step Breakdown

  1. ＄frame + 100 (The Shift): Shifts your timeline forward so the math aligns neatly with our cycle blocks.
  2. % 202 (The Loop): The modulo operator divides the frame by 202 and outputs only the remainder. This creates a repeating sawtooth pattern that resets every 202 frames.
  3. - 101 (The Center): Shifts that 0-to-201 sawtooth range down so it oscillates between -101 and +100.
  4. abs(...) (The Bounce): Absolute value turns all negative numbers positive. Instead of dropping off a cliff when it hits zero, it bounces back up. This turns the sawtooth wave into a "V" shaped wave (rising and falling).
  5. + 1 (The Final Offset): Shifts the minimum value from 0 up to 1 (and the peak from 101 up to 102).

Walkthrough with Example Frames

Let's trace what happens to specific frames as they pass through the formula:

Conditional

Option 2: The Conditional Approach

If you prefer a logic-based layout that reads explicitly like a timeline split, you can use an if statement (commonly supported in expression parsers like Houdini Hscript): 

$x = ($frame - 1) % 202;
($x < 102) ? ($x + 1) : (203 - $x)

Note: If your environment doesn't allow multi-line variable declarations in a single field, you can flatten it into a single-line inline if function: 

if((($frame - 1) % 202) < 102, (($frame - 1) % 202) + 1, 203 - (($frame - 1) % 202))
