Core Organization Layout

To isolate property performance while keeping unified corporate statements, the system maps financial data across two distinct dimensions: rows (Chart of Accounts / Groups) and columns (Divisions).

1. Divisions (Properties)

Divisions act as property tracking codes, allowing you to filter Profit & Loss statements by individual addresses.

  • Create a unique Division for each rental property, plus a generic General division (e.g., Sawtooth, Silverbell, and General) under Settings > Divisions.
  • The "General" Division Strategy: Always create an explicit division named General for corporate expenses (like postage, CPA fees, or software). This keeps shared overhead from distorting individual property yields and prevents these lines from cluttering the audit logs.
  • Tag the Division field on every single transaction line item (invoices, payments, receipts) to ensure precise asset, liability, and expense tracking.

2. Mortgage Escrow Accounts (Standard Balance Sheet Assets)

Overview

Mortgage escrows hold prepaid funds with your lender for property taxes and insurance. Instead of creating them as Bank and Cash Accounts (which hides them from standard Payment line-item dropdowns and requires manual transfers), set them up as standard Balance Sheet Asset accounts inside a visual Group folder.

This approach provides two key benefits:

  • Direct Mortgage Split Mapping: Each property's escrow account appears directly in the Account dropdown on Line 3 of your monthly mortgage Payment split.
  • Individual Summary Lines: Nesting individual property accounts under a Mortgage Escrows visual group displays each property's live running balance separately on your Summary dashboard.

Step 1: Create the "Mortgage Escrows" Visual Group

  1. Go to Settings > Chart of Accounts.
  2. Click the New Group button on the left-hand (Balance Sheet) side.
  3. Configure the form:
    • Name: Mortgage Escrows
    • Group: Assets
  4. Click Create.

Step 2: Create Individual Property Escrow Asset Accounts

Create one standard asset account per property (or a single Mortgage Escrow account if you only own one property):

  1. Still in Settings > Chart of Accounts, click New Account on the Balance Sheet side for your first property:
    • Name: Mortgage Escrow - Sawtooth (omit property name if single property)
    • Group: Mortgage Escrows
    • Cash Flow Statement: Operating activities
    • Click Create.
  2. Repeat New Account for additional properties (e.g., Mortgage Escrow - Silverbell), assigning each to the Mortgage Escrows group.

Step 3: Enter Starting Balances (Legacy Migrations Only)

If porting existing escrow balances from QuickBooks:

  1. Go to Settings > Starting Balances > Balance Sheet Accounts.
  2. Click New Starting Balance for each property:
    • Account: Mortgage Escrow - [Property Name]
    • Type: Debit
    • Amount: Enter the exact escrow balance held by the lender on your cutover date.
  3. Click Create.

3. Mortgage Loan Accounts (Standard Liabilities Group)

Mortgages are formal financial debts, not liquid cash. In Manager.io's architecture, custom Control Accounts are reserved for sub-ledger modules. Mortgages must be managed inside the standard Chart of Accounts using a sub-group.

Step 1: Create the Mortgage Loans Sub-Group

If you have multiple Mortgage Loans, set up a Group, else go to Step 2.

  1. Go to Settings > Chart of Accounts.
  2. Click New Group.
  3. Name it Mortgage Loans and set the Group to Liabilities. Click Create.

Step 2: Create Individual Property Loans

    • Group: Balance Sheet: if you have multiple loans, select the new Mortgage Loans sub-group else leave blank.
    • Cash Flow Statement: Select Financing activities.
  3. Click Create.

    Depreciation Strategy

    Here is the complete, sequential blueprint to build fixed asset profiles from scratch for two rental properties, inject their historical values, and log the first year of flat straight-line depreciation.

    Step 1: Create the Asset Categories (Chart of Accounts)

    Before adding individual buildings, the standard ledger needs a home for the non-depreciable land.

    Create a Group for Property Land Value

    If you have more than one property, create a Group to house the Property Values (else move to next step without):
    1. Go to Settings > Chart of Accounts.
    2. Click the New Group button at the top right.
    3. Configure the form:
      • Name: Property Land Value
      • Group: select Assets.
    4. Click Create.

    Set Up the Land Account (Sawtooth for example)

    1. Go to Settings > Chart of Accounts.
    2. Click the New Account button at the top right.
    3. Configure the form:
      • Name: Property Land Value or add a property label if more than one, like Property Land Value - Sawtooth
      • Group: select Assets (or if you have the group above, Property Land Value).
      • Cash Flow Statement: select Investing activities.
    4. Click Create.

    Set Up any other Land Accounts (Silverbell for example)

    1. Click New Account again.
    2. Configure the form:
      • Name: Property Land Value - Silverbell
      • Group: select Assets (or if you have the group above, Property Land Value).
      • Cash Flow Statement: select Investing activities.
    3. Click Create.

    We will populate the values in these accounts later.

    Step 2: Set Up the Fixed Asset Profiles (Sub-Ledger Setup)

    Now create the terminal sub-ledger profiles for the buildings.

    Note: There are no fields to enter purchase prices or dollar values on this screen; this step purely builds the identity cards for the properties.

    1. Go to the Fixed Assets tab on the left sidebar menu.
    2. Click the New Fixed Asset button.
    3. Configure the first property profile:
      • Name: Property Building Value or if you have multiple properties, add a label Property Building Value - Sawtooth
      • Depreciation rate: Leave this box completely blank (since we are using straight-line accounting for historic properties, we bypass Manager's declining balance calculator).
      • Set Division to the relevant property
    4. Click Create.
    5. Click New Fixed Asset again and repeat the process for the second property:
      • Name: Property Building Value - Silverbell
      • Depreciation rate: Leave blank.
      • Set Division to the relevant property
    6. Click Create.

    Step 3: Initialize the Property Starting Balances

    With the identities established, you can now hook up the historical dollar balances.

    A. Record the Depreciable Buildings

    1. Go to Settings > Starting Balances.
    2. Click directly on the row for Fixed Assets.
    3. Click the New Starting Balance button at the top right.
    4. Configure the form for the first building:
      • Fixed Asset: Select Property Building Value (or the labeled value, Property Building Value - Sawtooth)
      • Starting Balance (Acquisition Cost): type exactly the original historical building cost basis - NOT LAND.
      • (e.g., 153920.00 for Sawtooth)
      • Starting Balance Accumulated Depreciation: This is the previously claimed depreciation in total (so far).
      • (e.g., 106775.04 for Sawtooth after 19 years (the total cumulative depreciation claimed)).
    5. Click Create.
    6. Configure the form for subsequent buildings if required:
      • Fixed Asset: Select Property Building Value - Silverbell
      • Starting Balance (Acquisition Cost): type exactly 138465.00 (the original historical building cost basis).
      • Starting Balance Accumulated Depreciation: type exactly 95665.00 (the total cumulative depreciation claimed over the past 19 years).
    7. Click Create.

    B. Record the Non-Depreciable Land

    1. Go back to Settings > Starting Balances.
    2. Click on the row for Balance Sheet Accounts.
    3. Click the New Starting Balance button at the top right.
    4. Configure the form:
      • Account: select Property Land Value (or assign each if multiple properties, Property Land Value - Sawtooth).
      • Type: select Debit.
      • Amount: type the land cost basis (e.g., for Sawtooth, 51302.00).
    5. Click Create.
    6. Configure the form (for the subsequent properties):
      • Account: select Property Land Value - Silverbell.
      • Type: select Debit.
      • Amount: type the land cost basis (e.g., 46155.00).
    7. Click Create.

    Step 4: Record the Current Year's Depreciation Expense

    With the historical baseline set, you will now log the current year's flat depreciation.

    1. Go to the Depreciation Entries tab on the left sidebar menu.
    2. Click the New Depreciation Entry button.
    3. Set the Date to the current fiscal year-end close (e.g., 2026-12-31).
    4. In the lines grid, build a row for each property division:
      Row # Fixed Asset Division Amount Description
      Line 1 Property Building Value - Sawtooth Sawtooth 5597.00 Annual Straight-Line Building Depreciation 2026
      Line 2 Property Building Value - Silverbell Silverbell 5035.00 Annual Straight-Line Building Depreciation 2026
    5. Click Create at the bottom of the page.

    Next year, simply open this entry, click Clone at the top of the form, change the date to 2027-12-31, and click Create to complete the annual depreciation in seconds.

    A Better Visual Layout for Property Depreciation Expense in the Summary

    By moving the Annual Property Depreciation Expense out of the Property Operating Expenses group, you create a much clearer visual distinction between your "real" out-of-pocket operational costs (like HOAs, repairs, and utilities) and your structural tax write-offs.

    The Fixed assets - depreciation account is a hardcoded system account. The moment you activate the Fixed Assets module, the software automatically creates this account and forces all depreciation entries to route directly through it. You cannot delete it, you cannot bypass it inside the Depreciation Entries screen, and its dropdown assignment is entirely locked.

    However, you can customize this layout by using a Structural Re-Mapping Strategy - renaming the default account and moving it into your own group.

    Step 1: Create Your Isolated Group Folder

    1. Go to Settings > Chart of Accounts.
    2. Click the New Group button on the right, at the top of the Profit & Loss Statement side of the Summary.
    3. Configure the form:
      • Name: Property Depreciation & Cost Recovery.
      • Type: select Expenses Group.
    4. Click Create.

    Step 2: Uncouple the Default Account by Re-Mapping It

    1. While still inside the Chart of Accounts screen (on the right side), locate the system-generated Fixed assets - depreciation row.
    2. Click the Edit button next to it.
    3. Change the Name: backspace the generic default name and type Annual Property Depreciation.
    4. Change the Group: Locate the Group dropdown field and move it over to your brand-new Property Depreciation & Cost Recovery group.
    5. Click Update at the bottom of the form.

    On the Balance Sheet side of Summary (on the left), rename the Fixed assets, accumulated depreciation item:

    1. Click on the Edit button for Fixed assets, accumulated depreciation
    2. Change the name to Property Buildings Depreciation
    3. Balance Sheet: Assets
    4. Click Update

    And the same for Fixed assets, at cost:

    1. Click on the Edit button for Fixed assets, at cost
    2. Change the name to Property Buildings Value at Cost
    3. Balance Sheet: Assets
    4. Click Update

    Why This Is the Perfect Untangling Move

    • Zero Disruption to the Engine: Because you only edited the label and visual grouping rather than deleting or bypassing the account, Manager.io’s backend routes automated entries from the Depreciation Entries tab cleanly.
    • Visually Isolated Dashboard: On your main Summary screen and multi-column Profit & Loss reports, depreciation now sits inside its own distinct bottom section, keeping your out-of-pocket operating expenses uncluttered.

    Separating Property Buildings Value at Cost and Property Buildings Depreciation for Multiple Properties

    With multiple properties, you can display each property's building value on its own separate line on your Summary screen by creating a custom Control Account for each property. Because Manager.io rolls all Fixed Assets assigned to a single Control Account into one combined line, splitting them into separate Control Accounts nested under a parent group separates the balances visually while keeping the Fixed Assets module working normally.

    Step 1: Create a Parent Visual Group Under Assets

    This creates a clean bold header on your Summary dashboard to hold your individual property lines.

    1. Go to Settings > Chart of Accounts.
    2. Click the New Group button on the left-hand (Balance Sheet) side.
    3. Configure the form:
      • Name: Property Buildings Value at Cost
      • Group: select Assets
    4. Click Create.

    Step 2: Create One Control Account Per Property

    This gives each property its own visible line on your Summary screen.

    1. Go to Settings > Control Accounts > Fixed Assets.
    2. Click New Control Account for your first property:
      • Name: Building Cost - [Property 1 Name]
      • Group: Balance Sheet: select your new Property Buildings Value at Cost group.
      • Click Create.
    3. Repeat New Control Account for each additional property (e.g., Building Cost - [Property 2 Name]), assigning each to the Property Buildings Value at Cost group.
    4. (Optional) Go back to Settings > Chart of Accounts and rename the old built-in Property Buildings Value at Cost control account back to Fixed assets, at cost (it will automatically disappear from your Summary screen once its balance hits zero).

    Step 3: Re-Assign Each Building in the Fixed Assets Tab

    Point each building record to its new individual Control Account container.

    1. Click on the Fixed Assets tab on your left sidebar menu.
    2. Click Edit next to your first property's building.
    3. Change the Control account dropdown to Building Cost - [Property 1 Name].
    4. Click Update, then repeat for your other property buildings.

    To Add Owner Capital Starting Balance(s) As One Entry

    To add the historical personal cash investment into the company, record it as Owner's Capital (or Capital Contributions).

    The Capital Accounts tab is a dedicated sub-ledger module designed specifically for tracking real estate owners' out-of-pocket investments, drawings, and equity allocations.

    Step 1: Create the Owner Profile

    1. Go to the Capital Accounts tab on the left sidebar menu.
    2. Click the New Capital Account button.
    3. Name: type the name (e.g., [the Name or 'Owner'] - Investment).
    4. Division: Either a General division tag, or leave blank.
    5. Click Create.

    Note: Just like the Fixed Assets setup, there are no dollar fields on this screen; you are purely building the identity card for the owner.

    1. Go to Settings > Starting Balances.
    2. Click directly on the row named Capital Accounts.
    3. Click the New Starting Balance button at the top.
    4. Configure the form fields precisely:
      • Capital Account: select the name dropdown that you built in Step 1.
      • Starting Balance: set to Credit
      • Balance: type the exact total of the historical personal cash investment.
    5. Click Create.

    Why This Simplifies the Summary Page

    • The personal name and investment total appear cleanly as a sub-ledger under the Equity card.
    • Manager.io uses the personal funding total to absorb any negative capital gap sitting in Retained earnings.

    Year-End Partner Profit & Loss Allocation (Multi-Partner Partnerships)

    Manager.io accumulates annual net profit or loss inside the default Retained earnings equity account. If you operate a multi-partner LLC or joint venture (e.g., a 50/50 split) and want each partner's individual Capital Account on the Balance Sheet to reflect their share of the year's net income or loss:

    Step 1: Create a "Share of Profit" Capital Sub-Account

    1. Go to Settings > Capital subaccounts.
    2. Click New Subaccount, name it Share of Profit (or Net Income Allocation), and click Create.

    Step 2: Record the Year-End Allocation Journal Entry

    After all income, expenses, depreciation, and amortization entries are finalized for the year (12/31), check your Net profit (loss) figure on the Summary screen and post a year-end Journal Entry:

    • If the Business Had a Net Profit (e.g., +＄4,000.00 split 50/50):
      • Line 1 (Debit): Retained earnings | Amount: 4,000.00
      • Line 2 (Credit): Capital accounts -> Partner A -> Share of Profit | Amount: 2,000.00
      • Line 3 (Credit): Capital accounts -> Partner B -> Share of Profit | Amount: 2,000.00
    • If the Business Had a Net Loss (e.g., -＄10,430.34 split 50/50):
      • Line 1 (Debit): Capital accounts -> Partner A -> Share of Profit | Amount: 5,215.17
      • Line 2 (Debit): Capital accounts -> Partner B -> Share of Profit | Amount: 5,215.17
      • Line 3 (Credit): Retained earnings | Amount: 10,430.34

    Result: Retained earnings resets to ＄0.00 for the new year, and each partner's equity line on the Summary dashboard accurately reflects their cumulative contributions, drawings, and net tax profit/loss.

    Porting Legacy Loan Costs - Overview

    'Refinancing loan costs' are classified as Assets (prepaid legal rights amortized over the 30-year loan term). To migrate them from QuickBooks to Manager.io, set up:

    • Asset accounts to hold each property's remaining unamortized balance.
    • An Asset sub-group to roll them into a single clean line on the Summary screen.
    • An Expense account to record annual year-end write-offs.

    Step 1: Set Up the Chart of Accounts

    Go to Settings > Chart of Accounts:

    1. Create the Asset Sub-Group (Balance Sheet on the left side):
      • Click New Group.
      • Name: Financing & Borrowing Costs
      • Group: Assets
      • Click Create.
    2. Create the Property Asset Accounts (Balance Sheet side):
      • Click New Account for each property:
        • Name: Unamortized Loan Costs or Unamortized Loan Costs - Sawtooth for multiple property setups.
        • Group: Balance Sheet: Financing & Borrowing Costs
        • Cash Flow Statement: Investing activities
        • Click Create.
      • Click New Account again and repeat for any further properties, e.g. Unamortized Loan Costs - Silverbell.
    3. Create the Amortization Expense Account (Profit & Loss side):
      • If not present yet, create Property Financing Expenses Group: New Group called Property Financing Expenses, set as Expense Group.
      • Click New Account.
      • Name: Loan Cost Amortization Expense
      • Group: Profit & Loss Statement > Property Financing Expenses (or main Expenses group)
      • Cash Flow Statement: Operating activities
      • Click Create.

    Summary Result: Nesting both assets inside Financing & Borrowing Costs displays a single expandable total (＄3,349.93) on your Summary dashboard instead of separate long lines.

    Step 2: Enter Remaining Starting Balances

    Go to Settings > Starting Balances > Balance Sheet Accounts and click New Starting Balance for each property:

    • Sawtooth:
      • Account: Unamortized Loan Costs - Sawtooth
      • Type: Debit
      • Amount: 1861.11
    • Silverbell:
      • Account: Unamortized Loan Costs - Silverbell
      • Type: Debit
      • Amount: 1488.82

    Step 3: Record Annual Year-End Amortization

    At year-end, write down the asset balances using a 4-line Journal Entry:

    1. Go to Journal Entries > New Journal Entry.

Formula: ＄2,976.68 ÷ 30-Year Loan Term = ＄99.22 per year flat straight-line amortization.

    Why this is highly effective

    By saving these notes, you create a seamless audit trail. If you or your CPA ever wonder where the figures ＄99.22 or ＄80.26 came from down the road, clicking on either the account card or the transaction itself will immediately reveal the exact math.

    Set Up Management as a Supplier

    1. Click on the Suppliers tab on the left sidebar menu.
    2. Click the New Supplier button.
    3. Enter the Property Management Company's name (e.g., Premier Property Management).
    4. Leave the Division field completely BLANK.
    5. Click Create.

    Method A: The Purchase Invoice Workflow (Recommended for Accrual & Shortfalls)

    1. Monthly Processing: When the digital property management PDF statement arrives, go to the Purchase Invoices tab.
    2. Click New Purchase Invoice and select your Management Company Supplier.
    3. Build out your statement line-by-line using negative numbers for rent revenues and positive numbers for expenses:
      • Issue date: Management statement's date
      • Reference: e.g., Oct 26 - 1176 Fruit Tree
      • Supplier: Management company, e.g., Barrett Real Estate LLC
      • Line 1: Account: Rent Income | Unit price: -2500.00 | Division: Sawtooth
      • Line 2: Account: Management Fees | Unit price: 250.00 | Division: Sawtooth
      • Line 3: Account: Repairs & Maintenance | Unit price: 180.00 | Division: Sawtooth
    4. Review the Invoice Total at the bottom:
      • If the Total is Negative (e.g., -＄2,070.00): They owe you money (registers a credit balance in Accounts Payable).
      • If the Total is Positive (e.g., +＄150.00): You owe them an "Owner Contribution" due to high repair costs (registers a liability bill in Accounts Payable).

    Allocate Statement to Receipt/Payment

    1. Import your monthly QBO/CSV checking statement.
    2. Go to Bank and Cash Accounts and click the blue number under Uncategorized receipts (for payouts received) or Uncategorized payments (for owner contributions paid).
    3. Click Edit on the matching cash line item:
      • Change the single-line account mapping to Accounts Payable
      • Select your Management Company and choose the matching Purchase Invoice
      • Click Update (this clears the Accounts Payable balance to ＄0.00).

    Why the Negative Number Works

    Because a Purchase Invoice is designed to log bills you owe, entering a negative sign on your rental income line reverses the math - recognizing gross revenue while netting out positive expense lines down to the exact net wire transfer.

    Method B: Split Receipt Clone Workflow (Cash Basis)

    If recording directly from checking deposits without Purchase Invoices, record the full monthly owner statement as a Split Receipt (positive lines for gross rent, negative lines for management fees and repairs) equal to the net checking deposit:

    Annual Straight-Line Building Depreciation Worksheet Automation

    NOTE: This method is problematic when transferring from existing legacy accounts. Manual straight-line entries via the Depreciation Entries tab (Step 4 of Depreciation Strategy) are preferred.

    Manager.io's native Depreciation Calculation Worksheet uses the Declining Balance method (multiplying the rate against the shrinking book value, not the original purchase cost). To use the worksheet for a flat, fixed US straight-line deduction every single year, you must adjust the percentage value annually:

    The Recalculation Workflow

    1. Go to the Fixed Assets tab and find the building's current Net Book Value.
    2. Calculate the custom target worksheet percentage using this formula: 
      (Required Annual Straight-Line Building USD Deduction / Current Net Book Value) x 100 = Target Percentage Value
    3. Click Edit on the fixed asset profile and swap the old rate for this new target percentage.
    4. Go to Reports > Depreciation Calculation Worksheet and run the current fiscal period.
    5. CRUCIAL DATE RULE: The worksheet will completely hide an asset if its starting baseline date matches the report's "From" date. Always shift the worksheet's From date to one day later than the asset start date (e.g., if asset starts 2026-01-01, set worksheet From date to 2026-01-02).
    6. Click Create Depreciation Entry at the bottom of the worksheet screen. Tag each row line item with its proper property Division (Sawtooth or Silverbell) and save to push the values to the ledger.
    7. Note: Depreciation entries never dynamically update after creation. If you edit an asset's percentage later, you must open the saved Depreciation Entry, click Edit, and manually overwrite the amount box or delete it and re-run the worksheet.
