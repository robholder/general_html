Bash & Zsh - Ascii Art

I created a slow load colored Ascii Art header in the Terminal with this format.

The art is colored, and formatted at this website:

  • ExternalLink: Text to ASCII Art Generator

I used a wrapper to:

  • Trigger loading by:
    • A new shell session (Bash or Zsh)
    • If environment variable is set to a particular value (e.g. ＄PRODUCTION = OHIOTR)
  • Load with a line by line delay
  • Fix transparency

How to Repeat This Process on Any New ASCII Code

To convert any future raw colored ASCII art text block into this script-ready format, follow these steps:

  • Wrap each individual line inside double quotes ("...").
  • Escape backslashes if your text editor interprets them weirdly, though keeping them as literal \033[...] sequences inside the Bash/Zsh array string works seamlessly.
  • Fix the background colors: Do a find-and-replace across your codes:
    • Replace any instance ending in
    • ;40m (solid black background) with
    • ;49m (default/transparent terminal background).
    • Leave background codes with specific color targets (like ;43m or ;46m) alone.
  • Append the printing loop: Feed the array into the exact loop structure at the bottom: 
for line in "${lines[@]}"; do
    printf "%b\n" "$line"
    sleep 0.04
done

Scrolling Intro Banner

This approach loads banners from a subfolder, where each txt file holds a banner in colored ascii.

It slowly builds the banner line by line (deliberately), then pauses and scrolls the screen to lift the live prompt, clearing the banner off the screen of the terminal.

This block lives in the bashrc or zshrc (or sourced from there). 

#---------------------------- Colored 'Hexed' text ----------------------------#
#
# Check if the environment variable equals a specific value (e.g., "my_theme")
if [[ "$PRODUCTION" = "OHIO" || "$PRODUCTION" = "OHIOTR" ]]; then
    # Define the directory where the ASCII art text files are stored
    banner_dir="$HOME/.ascii_art_dir"
    
    # Check if the specified directory actually exists on the filesystem
    if [[ -d "$banner_dir" ]]; then
        # Gather all .txt files in the directory into an array
        files=("$banner_dir"/*.txt)

        # Check if the array contains at least one file before proceeding
        if (( ${#files[@]} > 0 )); then
            # Generate a random index safely compatible with both Bash (0-indexed) and Zsh (MOD adjusted)
            rand_idx=$(( (RANDOM + $$) % ${#files[@]} ))
            random_file="${files[rand_idx]}"
            
            # Clean the file path string by stripping any hidden carriage return characters (\r)
            random_file=$(printf '%s' "$random_file" | tr -d '\r')

            # Verify that the randomly selected path points to a valid, readable file
            if [[ -f "$random_file" ]]; then
                # Initialize an empty array to hold the lines of the file (removed 'local' to prevent top-level execution errors)
                lines=()
                
                # Read the file line-by-line safely, preserving empty lines
                while IFS= read -r line || [[ -n "$line" ]]; do
                    lines+=("$line")
                done < "$random_file"

                # Loop through each line of the ASCII art, force an absolute horizontal offset (column 25), 
                # and print with a slight delay for an animation effect
                for line in "${lines[@]}"; do
                    printf "\033[25G%b\n" "$line"
                    sleep 0.04
                done

                # Pause briefly so the user can look at the fully rendered art
                sleep 0.8

                # Measure current terminal window height (rows) dynamically
                term_rows=$(tput lines 2>/dev/null || echo 24)
                
                # Calculate the exact height (number of lines) of the ASCII art
                banner_height=${#lines[@]}
                
                # Scroll enough to clear both the art height AND the full terminal window height 
                total_scroll=$(( banner_height + term_rows ))

                # Scroll the terminal window upward dynamically 
                # to push the banner cleanly into the scrollback history buffer
                for ((i=1; i<=total_scroll; i++)); do
                    printf "\033[1S"
                    sleep 0.01
                done

                # Snap the cursor back to the top-left corner (Row 1, Column 1) 
                # so your fresh prompt renders right at the top of the window
                printf "\033[H"
            fi
        fi
    fi
fi

# Preview ASCII art file directly with escape sequence evaluation
preview_art() {
    local target_file="$1"
    
    if [[ -f "$target_file" ]]; then
        echo "=== PREVIEW: $target_file ==="
        while IFS= read -r line || [[ -n "$line" ]]; do
            # %b expands backslash escape sequences (like colors and formatting)
            printf "%b\n" "$line"
        done < "$target_file"
        echo "=============================="
    else
        echo "Error: File '$target_file' not found."
    fi
}

Here is your code refactored into a clean function called show_ascii_banner. It includes local declarations to ensure variables don't leak into your broader shell session. 

show_ascii_banner() {
    # Check if the environment variable equals a specific value (e.g., "my_theme")
    if [[ "$PRODUCTION" = "OHIO" || "$PRODUCTION" = "OHIOTR" ]]; then
        # Define the directory where the ASCII art text files are stored
        local banner_dir="$HOME/.ascii_art_dir"
        
        # Check if the specified directory actually exists on the filesystem
        if [[ -d "$banner_dir" ]]; then
            # Gather all .txt files in the directory into an array
            local files=("$banner_dir"/*.txt)

            # Check if the array contains at least one file before proceeding
            if (( ${#files[@]} > 0 )); then
                # Generate a random index safely compatible with both Bash (0-indexed) and Zsh (MOD adjusted)
                local rand_idx=$(( (RANDOM + $$) % ${#files[@]} ))
                local random_file="${files[rand_idx]}"
                
                # Clean the file path string by stripping any hidden carriage return characters (\r)
                random_file=$(printf '%s' "$random_file" | tr -d '\r')

                # Verify that the randomly selected path points to a valid, readable file
                if [[ -f "$random_file" ]]; then
                    # Initialize an empty array to hold the lines of the file
                    local lines=()
                    
                    # Read the file line-by-line safely, preserving empty lines
                    while IFS= read -r line || [[ -n "$line" ]]; do
                        lines+=("$line")
                    done < "$random_file"

                    # Loop through each line of the ASCII art, force an absolute horizontal offset (column 25), 
                    # and print with a slight delay for an animation effect
                    for line in "${lines[@]}"; do
                        printf "\033[25G%b\n" "$line"
                        sleep 0.04
                    done

                    # Pause briefly so the user can look at the fully rendered art
                    sleep 0.8

                    # Measure current terminal window height (rows) dynamically
                    local term_rows=$(tput lines 2>/dev/null || echo 24)
                    
                    # Calculate the exact height (number of lines) of the ASCII art
                    local banner_height=${#lines[@]}
                    
                    # Scroll enough to clear both the art height AND the full terminal window height 
                    local total_scroll=$(( banner_height + term_rows ))

                    # Scroll the terminal window upward dynamically 
                    # to push the banner cleanly into the scrollback history buffer
                    for ((i=1; i<=total_scroll; i++)); do
                        printf "\033[1S"
                        sleep 0.01
                    done

                    # Snap the cursor back to the top-left corner (Row 1, Column 1) 
                    # so your fresh prompt renders right at the top of the window
                    printf "\033[H"
                fi
            fi
        fi
    fi
}

QUESTION

Will this trigger constantly?

ANSWER

This specific trigger function will not repeat on every single command you type, provided you place it correctly inside your shell startup files (like .zshrc) rather than hooking it into a per-command execution loop (like precmd or PROMPT_COMMAND).

If you just put the trigger call at the bottom of your .zshrc file like this: 

# At the very bottom of .zshrc
trigger_banner

It will only execute once, right when that shell instance initializes (i.e., when you first open the terminal or type zsh to spawn a new shell). Once you are sitting at the prompt, typing random commands (ls, git status, etc.) will not re-trigger it.

Handling Your Goals Explicitly

If you want to fine-tune when it fires—such as ensuring it only happens when entering zsh or tracking state changes—you can adapt the trigger logic.

Scenario A: Only run when freshly launching/entering zsh

If you want to ensure it fires when entering zsh, putting it in .zshrc naturally achieves this because .zshrc is read every time an interactive zsh process starts.

Scenario B: Prevent repeating if you nest shells or source .zshrc again

If you manually type source ~/.zshrc later in the same session, a basic environment check would run the banner again. If you want to guarantee it only runs once per session even if .zshrc is re-sourced, use a tracker variable: 

trigger_banner() {
    # Check if the banner was already shown in this specific shell process
    if [[ "$PRODUCTION" == "OHIO" || "$PRODUCTION" == "OHIOTR" ]] && [[ -z "$_BANNER_SHOWN" ]]; then
        show_ascii_banner
        export _BANNER_SHOWN="true"
    fi
}

trigger_banner

  • How it works: The first time the shell starts, it sees PRODUCTION is set and _BANNER_SHOWN is empty. It shows the banner and locks _BANNER_SHOWN="true". If you source your config again or run sub-commands, _BANNER_SHOWN stops it from repeating.

QUESTION

Would this trigger if the env var PRODUCTION was changed during a session? (I hope it does.)

ANSWER

No, it won't trigger if you change PRODUCTION mid-session under the previous setup.

Because that version only calls trigger_banner once when the shell first starts up, changing the environment variable later via export PRODUCTION="OHIO" while sitting at the prompt will do nothing.

How to make it trigger when changed mid-session

If you want it to detect changes while you are working (and fire immediately when you export or modify that variable), you need to hook the check into Zsh's precmd (which runs before every prompt is drawn).

To prevent it from repeating on every single command after it's set, we can track the last state it fired for: 

# Keep track of what state we last showed the banner for
_LAST_SHOWN_PRODUCTION=""

check_production_banner() {
    if [[ "$PRODUCTION" == "OHIO" || "$PRODUCTION" == "OHIOTR" ]]; then
        # If it matches, but we haven't shown it for THIS value yet, show it now!
        if [[ "$_LAST_SHOWN_PRODUCTION" != "$PRODUCTION" ]]; then
            show_ascii_banner
            _LAST_SHOWN_PRODUCTION="$PRODUCTION"
        fi
    else
        # If PRODUCTION changes away from OHIO/OHIOTR, reset the tracker 
        # so it can fire again if you switch back later.
        _LAST_SHOWN_PRODUCTION=""
    fi
}

# Register it as a Zsh precmd hook
autoload -U add-zsh-hook
add-zsh-hook precmd check_production_banner

How this behaves:

  • Fresh start: If you open a terminal where PRODUCTION="OHIO" is already set, it fires instantly.
  • Mid-session change: If you open a normal terminal and later type export PRODUCTION="OHIO", the very next time you press Enter (at the prompt), it will catch the change and trigger the banner.
  • No spam: It won't repeat the banner every time you type ls or git status, because _LAST_SHOWN_PRODUCTION remembers it already displayed it for that value.
