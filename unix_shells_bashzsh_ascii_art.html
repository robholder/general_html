Bash & Zsh - Ascii Art

I created a slow load colored Ascii Art header in the Terminal with this format.

The art is colored, and formatted at this website:

  • ExternalLink: Text to ASCII Art Generator

I used a wrapper to:

  • Trigger loading by:
    • A new shell session (Bash or Zsh)
    • If environment variable is set to a particular value (e.g. ＄PRODUCTION = OHIOTR)
  • Load with a line by line delay
  • Fix transparency

How to Repeat This Process on Any New ASCII Code

To convert any future raw colored ASCII art text block into this script-ready format, follow these steps:

  • Wrap each individual line inside double quotes ("...").
  • Escape backslashes if your text editor interprets them weirdly, though keeping them as literal \033[...] sequences inside the Bash/Zsh array string works seamlessly.
  • Fix the background colors: Do a find-and-replace across your codes:
    • Replace any instance ending in
    • ;40m (solid black background) with
    • ;49m (default/transparent terminal background).
    • Leave background codes with specific color targets (like ;43m or ;46m) alone.
  • Append the printing loop: Feed the array into the exact loop structure at the bottom: 
for line in "${lines[@]}"; do
    printf "%b\n" "$line"
    sleep 0.04
done

Scrolling Intro Banner

This approach loads banners from a subfolder, where each txt file holds a banner in colored ascii.

It slowly builds the banner line by line (deliberately), then pauses and scrolls the screen to lift the live prompt, clearing the banner off the screen of the terminal.

This block lives in the bashrc or zshrc (or sourced from there). 

#---------------------------- Colored 'Hexed' text ----------------------------#
#
# Check if the environment variable equals a specific value (e.g., "my_theme")
if [[ "$PRODUCTION" = "OHIO" || "$PRODUCTION" = "OHIOTR" ]]; then
    # Define the directory where the ASCII art text files are stored
    banner_dir="$HOME/.ascii_art_dir"
    
    # Check if the specified directory actually exists on the filesystem
    if [[ -d "$banner_dir" ]]; then
        # Gather all .txt files in the directory into an array
        files=("$banner_dir"/*.txt)

        # Check if the array contains at least one file before proceeding
        if (( ${#files[@]} > 0 )); then
            # Generate a random index using Zsh's RANDOM plus the process ID ($$) for uniqueness, 
            # then use modulo (%) and 1-based indexing to pick a random file from the array
            rand_idx=$(( (RANDOM + $$) % ${#files[@]} + 1 ))
            random_file="${files[rand_idx]}"
            
            # Clean the file path string by stripping any hidden carriage return characters (\r)
            random_file=$(printf '%s' "$random_file" | tr -d '\r')

            # Verify that the randomly selected path points to a valid, readable file
            if [[ -f "$random_file" ]]; then
                # Initialize an empty local array to hold the lines of the file
                local -a lines=()
                
                # Read the file line-by-line safely, preserving empty lines
                while IFS= read -r line || [[ -n "$line" ]]; do
                    lines+=("$line")
                done < "$random_file"

                # Loop through each line of the ASCII art and print it with a slight delay for an animation effect
                for line in "${lines[@]}"; do
                    printf "%b\n" "$line"
                    sleep 0.04
                done

                # Pause briefly so the user can look at the fully rendered art
                sleep 1.5

                # Calculate the exact height (number of lines) of the ASCII art
                banner_height=${#lines[@]}
                
                # Scroll the terminal window upward dynamically (plus extra clearance rows) 
                # to push the banner cleanly into the scrollback history buffer
                for ((i=1; i<=banner_height+15; i++)); do
                    printf "\033[1S"
                    sleep 0.02
                done
            fi
        fi
    fi
fi
