Secure Copy (scp)

scp copies files and directories securely between hosts over an SSH connection.

It uses existing SSH keys, ~/.ssh/config aliases, and -i identity flags.

Basic Syntax

scp [options] [source] [destination]
  • Local to remote:
    • scp local/file.txt user@host:/remote/path/
  • Remote to local:
    • scp user@host:/remote/file.txt local/path/
  • Remote to remote:
    • scp user@host1:/path/file.txt user@host2:/path/

Common Examples

Copy a Single File

scp /Users/noddy/bin/sync_manager.sh noddy@macbook-m3.local:/Users/noddy/bin/sync_manager.sh
  • The target directory (/Users/noddy/bin/) must already exist on the destination host.
  • A trailing directory path (such as /Users/noddy/bin/) preserves the original filename.

Copy a Directory Recursively

Use -r to copy a folder and its contents: 

scp -r /Users/noddy/scripts/ noddy@macbook-m3.local:/Users/noddy/scripts/

Specify a Custom Port or Key

  • Custom SSH port (-P, uppercase): 
scp -P 2222 archive.tar.gz noddy@macbook-m3.local:/tmp/
  • Specific private key (-i): 
scp -i ~/.ssh/id_ed25519_macmini file.txt noddy@macmini.local:~/

Preserve Timestamps and Modes

Use -p to keep modification times, access times, and file permission modes: 

scp -p config.sh noddy@macmini.local:~/bin/config.sh

Practical Notes and Troubleshooting

  • Target folder missing: If the destination parent folder does not exist, scp fails with No such file or directory. Create it over SSH first with mkdir -p.
  • Overwrites: scp overwrites an existing destination file with the same name without prompting.
  • Large or frequent syncs: For large transfers, resume support, or skipping unchanged files, use rsync instead of scp.
