A Note on Depreciation and Equity

The accumulated depreciation (as legally claimed against tax), reduces the value of the buildings. As a result, the equity is reduced 'on paper'. The result has to be expressed in the equity calculations. In my case, the equity reflects thus: 

   $292,385.00  (Original Building Cost)
-  $213,072.00  (19 Years of Past Tax Deductions/Depreciation)
--------------------------------------------------------------
=   $79,313.00  (Current "Paper" Value of the Buildings)
+   $97,457.00  (Actual Starting Value of the Land)
+   $11,750.86  (Checking Account Cash)
+    $2,988.74  (Mortgage Escrow Cash)
--------------------------------------------------------------
=  $191,509.60  (Total Standing Value of Assets on Day 1)

-  $219,898.65  (Actual Outstanding Mortgage Principles Owed)
--------------------------------------------------------------
=  -$28,389.05  (The Net Capital Deficit / Global Equity Weight)

Depreciation Entries

Here is the complete, sequential blueprint to build fixed asset profiles from scratch for two rental properties, and to inject their historical values, and log the first year of flat straight-line depreciation.

Step 1: Create the Asset Categories (Chart of Accounts)

Before adding individual buildings, the standard ledger needs a home for the non-depreciable land.

  1. Go to Settings > Chart of Accounts.
  2. Click the New Account button at the top right.
  3. Configure the form:
    • Name: Property Land Value
    • Group: select Assets.
    • Cash Flow Statement: select Investing activities.
  4. Click Create.

Step 2: Set Up the Fixed Asset Profiles (Sub-Ledger Setup)

Now create the terminal sub-ledger profiles for the buildings.

Note: There are no fields to enter purchase prices or dollar values on this screen; this step purely builds the identity cards for the properties.

  1. Go to the Fixed Assets tab on the left sidebar menu.
  2. Click the New Fixed Asset button.
  3. Configure the first property profile:
    • Name: Sawtooth - Building Value
    • Depreciation rate: Leave this box completely blank (since we are using straight-line accounting for historic properties, we bypass Manager's declining balance calculator).
  4. Click Create.
  5. Click New Fixed Asset again and repeat the process for the second property:
    • Name: Silverbell - Building Value
    • Depreciation rate: Leave blank.
  6. Click Create.

Step 3: Initialize the Property Starting Balances

With the identities established, you can now hook up the historical dollar balances.

A. Record the Depreciable Buildings

  1. Go to Settings > Starting Balances.
  2. Click directly on the row for Fixed Assets.
  3. Click the New Starting Balance button at the top right.
  4. Configure the form for the first building:
    • Fixed Asset: Select Sawtooth - Building Value
    • Starting Balance (Acquisition Cost): Type exactly 153920.00 (the original historical building cost basis).
    • Starting Balance Accumulated Depreciation: Type exactly 106775.04 (the total cumulative depreciation claimed over the past 19 years).
  5. Click Create.
  6. Repeat this exact sub-ledger process for Silverbell - Building Value using its unique historical cost and accumulated depreciation numbers.

B. Record the Non-Depreciable Land

  1. Go back to Settings > Starting Balances.
  2. Click on the row for Balance Sheet Accounts.
  3. Click the New Starting Balance button at the top right.
  4. Configure the form:
    • Account: Select Property Land Value.
    • Type: Select Debit.
    • Amount: Type the land cost basis (e.g., 51302.00).
  5. Click Create. (Repeat this if you track Silverbell's land value in a separate ledger row).

Step 4: Record the Current Year's Depreciation Expense

With the historical baseline set, you will now log the current year's flat depreciation.

  1. Go to the Depreciation Entries tab on the left sidebar menu.
  2. Click the New Depreciation Entry button.
  3. Set the Date to the current fiscal year-end close (e.g., 2026-12-31).
  4. In the lines grid, build a row for each property division:
    Row # Fixed Asset Division Amount Description
    Line 1 Sawtooth - Building Value Sawtooth 5597.00 2026 Annual Straight-Line Depreciation
    Line 2 Silverbell - Building Value Silverbell [Silverbell Amt] 2026 Annual Straight-Line Depreciation
  5. Click Create at the bottom of the page.

Next year, simply open this entry, click Clone at the top of the form, change the date to 2027-12-31, and click create to complete the annual depreciation in seconds.

A Better Visual Layout for Property Depreciation Expense in the Summary

By moving the Annual Property Depreciation Expense out of the Property Operating Expenses group, you create a much clearer visual distinction between your "real" out-of-pocket operational costs (like HOAs, repairs, and utilities) and your structural tax write-offs.

The Fixed assets - depreciation account is a hardcoded system account. The moment you activate the Fixed Assets module, the software automatically creates this account and forces all depreciation entries to route directly through it. You cannot delete it, you cannot bypass it inside the Depreciation Entries screen, and its dropdown assignment is entirely locked.

However, you can completely outsmart this layout restriction by using a Structural Re-Mapping Strategy. Instead of bypassing the default account, you can rename it to match your desired structure and move it into your new group.

Here is exactly how to untangle this step-by-step for your notes:

Step 1: Create Your Isolated Group Folder

  1. Go to Settings > Chart of Accounts.
  2. Click the New Group button at the top of the Profit & Loss Statement side of the Summary.
  3. Configure the form: • Name: Structural Non-Cash Expenses (or Property Depreciation & Cost Recovery). • Group: Select Expenses.
  4. Click Create.

Step 2: Uncouple the Default Account by Re-Mapping It

Instead of fighting the compulsory account, you will customize it so it fits your new structure:

  1. While still inside the Chart of Accounts screen, locate the system-generated Fixed assets - depreciation row.
  2. Click the Edit button next to it.
  3. Change the Name: Backspace the generic default name and type your preferred clean line label: Annual Property Depreciation.
  4. Change the Group: Locate the Group dropdown field. Change it from Property Operating Expenses (or the root Expenses folder) over to your brand-new Structural Non-Cash Expenses group.
  5. Click Update at the bottom of the form.

Why This Is the Perfect Untangling Move

• Zero Disruption to the Engine: Because you only edited the label and the visual grouping rather than trying to delete or bypass the account, Manager.io’s backend code remains completely happy. When you post an automated entry in the Depreciation Entries tab, the system will still route the numbers here flawlessly [5.1]. • Visually Isolated Dashboard: The moment you save this change, the default item is dragged out of your clean operating expenses group. On your main Summary screen and your multi-column Profit & Loss reports, it will now sit by itself inside its own distinct bottom section, keeping your "real" cash operating columns completely uncluttered and easy to read! OLD CONFUSED INSTRUCTIONS THAT ULTIMATELY DON'T WORK

In the latest version of Manager.io, you should use the dedicated Depreciation Entries functional tab alongside the Fixed Assets module to track the property write-offs.

Because you manage multiple rental properties, the software allows you to map the depreciation expenses line-by-line directly to the individual property Divisions (Sawtooth, Silverbell, or General).

Step 1: Enable the Modules

If you don't see these tabs on the left menu, turn them on:

  1. Click Customize Control at the bottom of the left sidebar.
  2. Check the boxes for Fixed Assets and Depreciation Entries.
  3. Click Update.

Step 2: Establish the Property Asset Record

Before you can depreciate a building, it must exist as a sub-ledger entity:

  1. Go to the Fixed Assets tab and click New Fixed Asset.
  2. Set the name (e.g., Sawtooth - Building Value).
  3. Crucial Property Rule: Land does not depreciate. Do not include the land purchase price here. Only enter the structural, depreciable value of the building or capital improvements (like a new roof).
  4. Save the asset record.

Step 3: Enter the Depreciation Transaction

You can record the depreciation at the end of the year or at the end of each financial period:

  1. Go to the Depreciation Entries tab.
  2. Click the New Depreciation Entry button.
  3. Configure the form fields:
    • Date: The date you want the expense to hit the books (e.g., 2026-12-31).
    • Fixed Asset: Select the asset profile (e.g., Sawtooth - Building Value).
    • Division: Select the corresponding property Division (Sawtooth). This ensures the deduction hits that property's specific report columns!
    • Amount: Enter the exact calculated depreciation value (e.g., 5000.00).
  4. Click Create.

Enter the Value

In Manager.io, when you go to the Fixed Assets tab and click New Fixed Asset, there is purposefully no field on that form to type in the asset's purchase price / value.

Manager.io separates the creation of an asset profile from the funding of that asset. When you first create the profile, its acquisition cost defaults to a blank dash (-). To actually give that asset a real financial value, you must assign a transaction or a starting balance to it.

Depending on whether you are bringing over a historical value or logging a brand-new transaction, use the appropriate method below to enter its value:

Method 1: If it is a Historical / Existing Property (Opening Balance)

If you already owned the property before the tracking start date, you assign its opening value via the initialization screen:

  1. Go to Settings > Starting Balances > Fixed Assets (or choose Bank and Cash / Balance Sheet Accounts depending on the layout sub-menus).
  2. Click Edit next to the property (e.g., Sawtooth - Building Value).
  3. You will see two hidden financial fields appear:
    • Starting Balance (Acquisition Cost): Type the original cost basis of the building layout (e.g., 250000.00).
    • Starting Balance (Accumulated Depreciation): Type any write-offs you claimed in prior tax years before migrating to Manager.io (e.g., 15000.00).
  4. Click Save. the asset register will now perfectly display its true net book value.

Method 2: If It Is a Brand-New Property Purchase

If you just bought the house during the active tracking period, you establish its value by logging a real banking transaction:

  1. Go to the Payments tab or Purchase Invoices tab.
  2. Create a new transaction representing the purchase settlement.
  3. In the line-items grid, do not select an expense account. Instead:
    • Account: Select Fixed Assets, at cost.
    • Fixed Asset: A new dropdown will pop open. Select Sawtooth - Building Value.
    • Amount: Type the transaction settlement cost (e.g., 250000.00).
  4. Click Create.

Why Manager.io Uses This Layout Method

By forcing you to back up an asset's cost with either a starting balance entry or a banking payment record, Manager.io prevents artificial numbers from just showing up out of nowhere.

Once either of these steps is completed, go back to the main Fixed Assets tab dashboard. You will see the blank dash has vanished and the real, auditable property capital value is loaded into the ledger.

💡 The Automated Approach (Using Worksheets)

If you prefer not to calculate the depreciation figures manually, modern builds of Manager.io can calculate them automatically using a native worksheet tool:

  1. Go to Fixed Assets and click Edit on the property asset record.
  2. Enter the annual depreciation percentage rate inside the Annual depreciation rate text field and save.
  3. Go to the Reports tab and select Depreciation Calculation Worksheet.
  4. Click New Report, enter the date range, and the software will dynamically compute the exact daily-rate write-off for the rental properties and generate the matching depreciation entries instantly.

The Ledger Impact

Once saved, Manager.io automatically updates the financials without requiring manual journal entries. It debits the Fixed assets - depreciation expense account (reducing net profit under the specific property column path on the P&L) and credits Fixed assets, accumulated depreciation (lowering the book value of the property asset on the Balance Sheet).

The Depreciation Calculation Worksheet

The Depreciation Calculation Worksheet natively calculates tax write-offs using the declining balance method. It evaluates the exact asset book value and computes depreciation on a highly accurate daily rate based on the number of days inside the specified tracking period.

Follow these steps to run the worksheet and let Manager.io auto-generate the property write-offs:

Step 1: Assign the Depreciation Rates to the Properties

Before running the report, you must define the annual depreciation rate directly inside the property asset sub-ledger profiles:

  1. Go to the Fixed Assets tab on the left sidebar.
  2. Click Edit next to the first depreciable building record (e.g., Sawtooth - Building Value).
  3. Locate the Depreciation rate text field and enter the annual percentage as a number (e.g., type 3.636 if you are writing off a residential property using the standard US 27.5-year timeline).
  4. Click Update to save. (Repeat this for the Silverbell building asset using its correct rate).

Step 2: Generate the Calculation Worksheet

  1. Go to the Reports tab on the left sidebar menu.
  2. Under the Fixed Assets heading, click on Depreciation Calculation Worksheet.
  3. Click the New Report button.
  4. Configure the Parameters:
    • From: Select the starting date of the current fiscal period (e.g., 2026-01-01).
    • To: Select the close date of the period (e.g., 2026-12-31).
    • Description: Give it a clear name (e.g., 2026 Annual Property Depreciation).
  5. Click Create.

Step 3: Run the Automation Workflow

When the report renders on the screen, it displays a comprehensive audit grid. You will see the property buildings listed as row headers alongside columns detailing their Starting Book Value, the Daily Rate Calculation, and the Calculated Depreciation Amount for that date window.

To officially push these numbers to the books without typing them line-by-line:

  1. Look at the very bottom left corner of the generated worksheet screen.
  2. Click the New Depreciation Entry button.
  3. Manager.io will instantly open a pre-filled, balanced, multi-line transaction. It will automatically populate the exact calculated dollar figures, match them to the buildings, and link them to the proper Chart of Accounts items (Fixed assets - depreciation and Fixed assets, accumulated depreciation).
  4. The Property Division Step: Because this auto-generated page lists all the assets on separate rows, make sure to look at each row and select the matching property Division dropdown (Sawtooth or Silverbell) so the expense hits the property reports correctly.
  5. Click Create at the bottom of the page to finalize the entry.

⚠️ A Critical Structural Rule for New Assets

Because Manager.io applies depreciation from the absolute "From" date specified on the report range, if you buy a new property midway through the year, you must create a separate worksheet for it. Run its unique worksheet with the "From" date set precisely to its day of acquisition through the end of the year to avoid over-calculating its write-off days.

Summary Page Layout

the asset cost and its accumulated depreciation should always be paired together in a sub-group called Fixed Assets (or Property, Plant & Equipment). This keeps the main Summary page clean while automatically displaying the property’s true Net Book Value.

Here is exactly how to set up the group and collapse it in the latest version of Manager.io:

Step 1: Create the Fixed Assets Group

  1. Go to Settings > Chart of Accounts.
  2. Click the New Group button at the top right.
  3. Configure the form:
    • Name: Fixed Assets (or Real Estate Portfolio Asset Value)
    • Group: Select Assets.
  4. Click Create.

Step 2: Move the Accounts Into the New Group

  1. While still inside the Chart of Accounts screen, look under the Assets section.
  2. Click Edit next to Fixed Assets, at cost.
  3. Change the Group dropdown from Assets to the newly created Fixed Assets sub-group.
  4. Click Update.
  5. Repeat this exact process for Fixed Assets, accumulated depreciation, moving it into the same Fixed Assets sub-group.

Step 3: Collapse the Group on the Summary Dashboard

To hide these two rows from cluttering the view, tell the Summary tab to condense them:

  1. Click on the main Summary tab on the left sidebar menu.
  2. Click the Edit button in the top right corner.
  3. Scroll down to the Groups to collapse dropdown field.
  4. Select the custom Fixed Assets group.
  5. Click Save or Update at the bottom.

The Clean Result

the dashboard will now display a single row named Fixed Assets. Manager.io will automatically do the math behind the scenes—subtracting the accumulated depreciation from the historical purchase costs—and display the exact real estate portfolio equity value in one clean, summarized number.

Grayed out

When you add a group to the Groups to collapse setting, Manager.io turns the main group title gray and disables clicking on it. The software does this because it is displaying a frozen, high-level summary total; it cannot open a single ledger view for a collapsed group because that group contains multiple completely different accounts (at cost and accumulated depreciation) mixed together.

If you want to view the transaction details inside those grayed-out asset accounts, use any of these three quick alternative paths:

Path 1: The "Fixed Assets" Tab (Recommended)

Since you activated the sub-ledger module, you don't need the Summary tab to look at the property data:

  1. Click directly on the Fixed Assets tab on the left sidebar menu.
  2. Here, you will see the properties (Sawtooth, Silverbell) listed cleanly.
  3. You can click on the blue numerical figures under the Acquisition cost or Accumulated depreciation columns to view their complete, itemized transaction history.

Path 2: Uncollapse the Group Temporarily

If you prefer the Summary view for auditing the accounts:

  1. Click Edit at the top right of the Summary dashboard tab.
  2. Remove Fixed Assets from the Groups to collapse field and hit Save.
  3. The rows will unroll. They will turn back into clickable blue hyperlinks so you can click them directly, examine the entries, and then re-collapse the group when you are finished.

Path 3: The Chart of Accounts Screen

  1. Go to Settings > Chart of Accounts.
  2. Find the accounts nested inside the sub-group. They remain fully interactive here. You can click on the balance figures to run the deep-dive audits.

Historic Depreciation Integration

Step 1: Initialize the Asset Cost and Historical Depreciation

Because you have enabled the Fixed Assets sub-ledger tab, you do not use the plain "Balance Sheet Accounts" screen for the buildings.

Navigate directly to the dedicated sub-ledger initialization page:

  1. Go to Settings > Starting Balances.
  2. Click on the row for Fixed Assets.
  3. Click the New Starting Balance button.
  4. Configure the form precisely like this:
    • Fixed Asset: Drop down the menu and choose the first asset (e.g., Sawtooth - Building Value).
    • Starting Balance (Acquisition Cost): Type the Building Basis value (original purchase price minus land value).
    • Starting Balance (Accumulated Depreciation): Type the total cumulative depreciation claimed on that property from the purchase date up until the current tracking year.
  5. Click Create at the bottom of the form. (Repeat this exact step for the Silverbell property building).

Step 2: Establish the Non-Depreciable Land Basis

Land must never be mixed into the depreciable building asset line, or Manager.io's calculation worksheets will write off too much money. Because land never depreciates, it is built as a standard, standalone asset account:

  1. Go to Settings > Chart of Accounts.
  2. Click New Account and create an asset named Property Land Value (set its group to Assets).
  3. Set Cash Flow Statement to Investing activities
  4. Click Create/Update
  5. Go to Settings > Starting Balances.
  6. Click on Balance Sheet Accounts.
  7. Click on New Starting Balance button at the top.
  8. Now, a form will open providing the value fields you need:
    • Account: Select Property Land Value (the account from step one) from the dropdown list.
    • Type: Select Debit.
    • Amount: Type the Land Basis value.
  9. Click Create.

Step 3: Verify the Net Book Value Baseline

Once those two steps are saved, the historical foundation is completely established. To verify the math:

  1. Click directly on the Fixed Assets tab on the left sidebar menu.
  2. Look at the dashboard grid. You will see that Manager.io has automatically calculated the starting point:

Acquisition Cost (Building) - Historical Accumulated Depreciation = Current Net Book Value

When you eventually run the first live Depreciation Calculation Worksheet for the current tax year, the system will read this Net Book Value as its baseline and automatically compute the new depreciation correctly going forward.
