Capture the name of the current file or buffer in Vim:

To copy the current filename without its extension directly to your system clipboard while in Normal Mode, run this command: 

:let @+ = expand("%:t:r")

Breakdown of the command:

  • expand("%"): Gets the current file path.
  • :t: Modifies it to keep only the tail (just the filename, stripping away any directory paths).
  • :r: Modifies it to keep only the root (stripping away the file extension, like .txt or .py).
  • @+: Assigns that final result to your system clipboard register so you can paste it anywhere (p in Vim, or Ctrl+V / Cmd+V outside Vim).
