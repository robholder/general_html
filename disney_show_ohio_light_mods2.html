Cucoloris

There is a cucoloris/asset library.

  • Projector mask:
    • White -> on
    • Black -> off
    • It does respect chroma also
  • Enable projection option in light!
  • Projection comes from a single point (not the area of the light)
  • Reflections don't honor the cuc shapes.

IES

There is an IES/asset library.

  • Digital fingerprint of real-world bulb/emitter:
    • 'Describes' reflectors/lenses/shades

Light Texture / Gel / Studio HDRI

There is a Light Texture/asset library.

  • Unlike a 'cuc', this applies to a quad/dome as a texture (not a point projector).
    • Example - studio softbox image.
  • Reflections honor the texture.

PTX

Most elements in the asset library are .ptx files. These work in Houdini, but need to be converted in Nuke.

  • Lighting menu >:
    • Shaodowbox
    • Search for ptx
    • Import
  • In the node, pipe in (Texture filename field) a texture.
  • Click create.

Custom Painting Cucs

Video Frame #: 30800

  • Select light
  • From the Lighting Tools shelf, select:
    • Cucoloris Snapshot and Paint button
    • Opens GUI.
  • Choose one of either:
    • Create Singlemap Cucoloris
      • Stick to light emission (moves with original Light)
    • Create Camera Projection Cucoloris:
      • Stick cuc at current position in space
      • This is using a New light
      • No even if you move the light the shadow/cuc is tied to the location of the new 'fake' light
  • Set Resolution
  • Directory should default to the seqData folder (lightMaps)
  • Filename field is where you name the file
  • Select filetype with Extension
  • Open in:
    • Gimp
    • Krita
    • Photoshop (on Mac)
  • Click Look Through:
    • Moving here will move the light if using singlemap.
    • Moving here will more the fake light is using Camera Projection Map
  • Check on Autohide snapshot in PSD
  • Click Take Snapshot:
    • Paint app should open
    • Paint & blur in white for 'light'
    • Also color is respected.
    • But you don't have to paint the whole canvas:
      • No pixel paint = black
    • Save..
  • Back in the gui:
    • Convert to ptx and Update
  • To update, click on the Listen for files changes checkbox:
    • Save in the paint app, and Ion will update automatically

Note on Camera Projection Option

When using Camera Projection option, the parm on the light's UserVars tab will hold the position of the 'fake' light. Edit position here.

Moving in the snapshot viewport will move these parameters (and the fake light).

Moving the 'real' light will leave the cuc pattern where it is.

FOV setting allows you to restrict the field of view of the projection.

NOTE: Use distant/parallel light placed very far away to simulate more parallel rays if using volume.

Editing Upstream Light Editing

If you inherit a light (with a cuc already on it) and you want to edit it, you need to drop a dpip Edit Helper node down.

  • Select the light in the Scene Graph Tree pane:
    • RMB > dpipe Edit Helper
    • Action should be set to Edit
    • Activate (override) the UserVar for the cuc projection:
      • Set to Set or create (cog icon to pencil widget)
  • Instead of Cucoloris Snapshot and Paint use the Lighting Tools tab > Camera Projection Map

Limitation on Scatter Colors

Scatter effects don't work with the cuc 'shadows' (since they are not shadows).

Volumes

The cuc projection will work through volumes too! (For god-ray effect.)

FOV setting allows you to restrict the field of view of the projection.

NOTE: Use distant/parallel light placed very far away to simulate more parallel rays if using volume.

To Apply Cucs In Houdini

  • Open Asset Library tab
  • Switch catalog to Cucs or IEs from drop-down (top left)
  • Select light (or item)
  • RMB > Add Cuc to material (in Houdini only, not catalog)
  • or...
  • Drag and drop onto the User Vars > SingleMap Name field
  • Nothing will change immediately:
  • It adds to the User Vars (tab):
    • Singlemap field points to texture map:
      • sScale
      • tScale
      • sOffset
      • tOffset
      • Rotate
      • Blur doesn't function with Ion, but does with Hyperion
    • The User Vars name gets piped into the Light Color Expression on the Emission tab of the light.
    • Activate modifier checkbox to see the effect:
      • Projection (for cucs)
      • IES (for IES)

Scrubbing with an animated texture will reveal motion.

To Apply HDR in Houdini

  • Open Asset Library tab
  • Switch catalog to StudioHDRI from drop-down (top left)
  • Select light (or item)
  • RMB > Add Cuc to material (in Houdini only, not catalog)
  • or...
  • Drag and drop onto the User Vars > SingleMap Name field
  • Nothing will change immediately:
  • It adds to the User Vars (tab):
    • Singlemap field points to texture map:
      • sScale
      • tScale
      • sOffset
      • tOffset
      • Rotate
      • Blur doesn't function with Ion, but does with Hyperion
    • The User Vars name gets piped into the Light Color Expressoin on the Emission tab of the light.
    • Do not check any modifier checkboxs:
      • This just applies to the light as a texture

To Apply IES

  • Open Other tab > IES Control
  • Enable IES Control
  • Drag and drop IES map onto IES path input field
  • Set Cone Angle
  • Set Color Fringe if needed

Modifying IES Maps

  • In catalog, RMB and choose Open Copy in LightDesigner
  • In the interface, click on the toggle arrow to expose the code on the right
  • Adjust the curve in the scope graphic.
