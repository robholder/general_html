ptxConvert - Images to Textures/Cucoloris

Converting in a terminal

Navigate to the image directory and use ptxconvert [source].[file_format] [destination].ptx

Note: To convert an image successfully to a ptx it needs to have a 'power of 2' resolution (ie: 256x256, 512x512, 2048x2048, etc.)

Example:

ptxconvert myfile.exr myfile.ptx

Supported file formats are:

  • .tif, .jpg, .png, etc. - standard image files
  • .tx - prman (tif) texture
  • .ptx - ptex texture (single face only)
  • .penv - ptex environment cube map

And to convert to each mode:

Clamp (default behavior):

ptxconvert myfile.ptx myfilewater.tif
ptxconvert -mode clamp myfile.ptx myfile.tif

Black:

ptxconvert -mode black myfile.ptx myfile.tif

Periodic:

ptxconvert -mode periodic myfile.ptx myfile.tif
