Lighting Techcheck

Lighting takes two approvals:

  • Creative approval
  • Techcheck approval

Techcheck

Render at:

  • Higher SPP
  • Right & Left eyes

With:

  • All upstream updates
  • Matte lines and issues fixed

Shotgun/Flow

The shot will be flipped to Lighting-Techcheck in Flow.

  • Tasks:
  • Go to the shot page and click on the 'Tasks' tab.
    • All should be green and good to go:
      • Every department should be 'green' and complete.
      • Icon: green circle with a tick.
  • Notes:
    • All lighting notes should be addressed
      • There shouldn't be any open notes.

Other tabs:

  • Activity
  • Shot Info

  • Shot Elements
  • Asset Readiness

Asset Checks

  • Look for IP
  • Missing assets.

Render Submitter

  • Select shot in the list
  • RMB:
    • Switch to Stereo and TC:
      • This creates overrides (red dots)
      • Includes 'new' supplemental render layers (for stereo):
        • Disparity maps
        • Reprojection Masks
    • Switch to Stereo and TC
  • Samples:
    • Between 128 and 256 SPP

Nuke - Stereo Flags

In Quip:

  • Switch to Stereo button:
    • This will add backdrops to label areas for Stereo attention.
    • Add any Stereo backdrops to places that didn't get auto-flagged.

Checklist For TC Renders

  • Check EXRs:
    • Matte lines
    • Rotos
    • Noise
    • Exposure:
      • 2 stops up & down
      • RV shortcuts:
        • E enter exposure control
        • E + -2 for stops down
        • E + 2 for stops up
        • Delete reset (make sure you are still in Exposure when pressing)
          • E then Delete
        • Scrub left and right to adjust interactively.
    • Values:
      • Brights
      • Clamped
      • Blacks
    • Eyes/Teeth balance
  • DPix:
    • Check continuity with surrounding shots
  • Check right eye for consistency with left:
    • rv3d:
      • <Alt> + S:
      • To toggle: , & .
    • rv3dpair:
      • To open in side-by-side view

Techcheck Previews

  • Submit to DPix
  • Post link in team chat (Slack)

Lighting Submit

Navigate to shot env:

  • n <seq> <shot>
  • Run lighting_submit:
    • Submit as... -> Final
    • Department -> Lighting
    • Scene Path -> (auto-completed) path to hip scene file
    • Nuke Path -> (auto-completed) path to nuke file
  • Attend Tech Check Reviews

Redos

  • If flagged for 'redo':
    • Run lighting_redo:
      • Stereo's latest gets converted to a new fullcomp_v####.nk file
    • Leave copious notes to Stereo as to what changed.
  • When complete:
    • Run lighting_submit again.

Contact the stereo artist if you see they've started, to keep each other informed on status of the shot.
