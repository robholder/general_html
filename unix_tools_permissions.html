Permissions

Understanding Unix/Linux file permissions is essential for keeping your work secure while sharing specific assets (like your EE directory) with teammates.

1. The Three Core Permissions

Every file and directory has three base permissions assigned to three distinct categories of people (User/Owner, Group, and Others).

Permission Symbol What it means for a File What it means for a Directory
Read r View or copy the contents of the file. List the files inside the directory (e.g., using ls).
Write w Modify, overwrite, or delete the file. Create, delete, or rename files inside the directory.
Execute x Run the file as a program or script. Traverse (step inside/access paths through) the directory.

2. Who Gets the Permissions?

Permissions are managed across three identity groups:

  • u (User/Owner): You - the person who created or owns the file.
  • g (Group): A collection of users assigned by the system (e.g., your department or studio group).
  • o (Others): Everyone else on the system outside of your user account and group.
  • a (All): Shorthand for combining user, group, and others simultaneously.

3. The Two Ways to Modify Permissions (chmod)

You can change permissions using either Symbolic Mode (adding/removing specific flags) or Numeric Mode (using octal math codes).

Method A: Symbolic Mode (Human-Readable)

Symbolic mode uses letters to target groups and operators to change rules.

  • Operators: + (add permission), - (remove permission), = (set exact permission, wiping out everything else).

Examples:

  • chmod o+r file.txt - Add read permission for others.
  • chmod g-w shared_dir/ - Remove write permission for the group.
  • chmod o=x Documents/ - Set others to only have execute/traverse (wiping out read and write).

Method B: Numeric / Octal Mode (Mathematical)

Numeric mode uses a 3-digit code (e.g., 755). Each digit represents a category in order: User, Group, Others.

Each permission is assigned a numerical value:

  • Read (r) = 4
  • Write (w) = 2
  • Execute (x) = 1
  • None = 0

You add the values together for each category. For example, Read + Write + Execute = 4 + 2 + 1 = 7.

Examples:

  • 755: User gets 7 (rwx), Group gets 5 (r-x), Others get 5 (r-x). Standard for directories/scripts.
  • 644: User gets 6 (rw-), Group gets 4 (r--), Others get 4 (r--). Standard for normal files.
  • 700: User gets 7 (rwx), Group gets 0 (---), Others get 0 (---). Private files/folders.

4. Common Permission Cheat Sheet

Code / Command Visual Representation Use Case
chmod 700 rwx------ Strictly Private: Only you can access or view it.
chmod 600 rw------- Private File: Only you can read/write the file.
chmod 755 rwxr-xr-x Public Read/Execute: You have full control; everyone else can view and enter, but not modify.
chmod 644 rw-r--r-- Standard File: You can edit; everyone else can only read.
chmod g=x,o=x --x--x--x Traversal Only: Users can "pass through" a parent directory to reach a subfolder, but cannot list its contents.
