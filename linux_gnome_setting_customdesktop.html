Gnome - Desktop - Setting Plain Color on Locked Settings

In Gnome on redhat, is it possible to just have a plain color as a desktop background? My settings only have a few colors and images chosen by admin. Yes, it is possible, even though modern versions of GNOME removed the solid color picker from the graphical Settings menu.

Because Red Hat restricts your GUI choices or locks down backgrounds via admin policy, you can bypass the Settings panel entirely by configuring GNOME's underlying background engine using the terminal (gsettings).

How to set a plain color via command line

Open your terminal and run the following commands: 

# 1. Disable the background image wallpaper
gsettings set org.gnome.desktop.background picture-options 'none'
gsettings set org.gnome.desktop.background picture-uri ""
# 2. Set your desired solid color (replace '#2e3440' with any hex code or name)
gsettings set org.gnome.desktop.background color-shading-type 'solid'
gsettings set org.gnome.desktop.background primary-color '#404040'

This suggestion didn't work (but apparently it's a more recent addition): 

gsettings set org.gnome.desktop.background picture-uri-dark ''

Will this work if your admin locked things down?

  • If it's a soft policy (Default defaults): The commands above will instantly change your background to your chosen solid color, overriding the default template.
  • If the admin hard-locked the background: If your organization used dconf locks to enforce a corporate wallpaper, the gsettings command might silently fail or revert when you log back in. If that happens, the system policy overrides user changes, and you would need admin rights to modify /etc/dconf/db/.

How do you revert if this is successful?

To revert back to your admin's default background settings, you can reset the GNOME background properties to their default states.

Run the following commands in your terminal: 

# Reset all background-related gsettings to default/admin values
gsettings reset org.gnome.desktop.background picture-options
gsettings reset org.gnome.desktop.background picture-uri
gsettings reset org.gnome.desktop.background color-shading-type
gsettings reset org.gnome.desktop.background primary-color

This suggestion didn't work (more recent versions of Gnome apparently): 

gsettings reset org.gnome.desktop.background picture-uri-dark

Using the reset subcommand clears out your custom overrides and tells GNOME to fall back to whatever default or admin-enforced configuration was originally in place.
