Bash Errors (on Redhat)

I was getting these errors in Kitty. The error appeared every time the shell opened, and with a command or <Enter>. 

bash: PROMPT_COMMAND: line 1: syntax error near unexpected token `:'
bash: PROMPT_COMMAND: line 1: `history -a; history -a; ;set_window_title;set_window_title'

After trials and errors, it was coming from the Redhat environment, and not any extra sourced files or aliases of my own.

This was the solution that seemed to work (although I haven't field tested fully to see if it breaks any other functionality): 

#shell_integration no-rc
env PROMPT_COMMAND=history -a

As a precaution, I added these guard blocks to my dot-disney_titlebar and any other config files that seemed to call on PROMPT_COMMAND: 

if [ -n "$ZSH_VERSION" ]; then
    precmd_functions+=(set_window_title)
elif [ -n "$BASH_VERSION" ]; then
    # Safely append set_window_title only if it isn't already present
    if [[ ";$PROMPT_COMMAND;" != *";set_window_title;"* ]]; then
        if [[ -n "$PROMPT_COMMAND" ]]; then
            export PROMPT_COMMAND="$PROMPT_COMMAND; set_window_title"
        else
            export PROMPT_COMMAND="set_window_title"
        fi
    fi
fi
