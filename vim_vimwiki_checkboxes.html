  • <Ctrl> + <Space> on bullet points:
    • start
    • result of <Ctrl> + <Space> on the line above
    • result of <Ctrl> + <Space> again on the line above
    • result of <Ctrl> + <Space> yet again on the line above

Repeated and the checkbox toggles x and tick.

This toggles between glyph 1 and 4 below.

If you have the glyphs for checkboxes set, you can use these commands to cycle through four settings:

  • gln - Cycles forward through the four custom list symbols
  • glp - Cycles backward

Example of glyph choices. 

" Glyphs for chechboxes:
let g:vimwiki_listsyms = '✗○◐●✓'

To get these to show up on a CSS style sheet driven HTML approach, add this: 

/* --- 8. VIMWIKI TASK LIST CHECKBOXES --- */
ul > li.done0, 
ul > li.done1, 
ul > li.done2, 
ul > li.done3, 
ul > li.done4 {
    list-style-type: none;
    margin-left: -1.2em;
}

ul > li.done0::before { content: "✗ "; color: #e57373; }
ul > li.done1::before { content: "○ "; color: #b0b0d0; }
ul > li.done2::before { content: "◐ "; color: #3AB4F1; }
ul > li.done3::before { content: "● "; color: #3AB4F1; }
ul > li.done4::before { content: "✓ "; color: #9ece6a; }
