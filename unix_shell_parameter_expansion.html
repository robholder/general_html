Shell Parameter Expansion Reference Guide (Bash & Zsh)

Parameter Expansion is a built-in feature of POSIX-compliant shells like Bash and Zsh. It allows you to manipulate strings, extract substrings, provide default values, and perform search-and-replace operations instantly without invoking external utilities like sed, awk, or cut.

Because it happens entirely within the shell, it is extremely fast and works identically across scripts and interactive terminal prompts.

Basic Syntax

The general form of parameter expansion is: 

${parameter}

In many cases, the braces {} are optional (e.g., ＄var), but they become mandatory as soon as you add modifiers, operators, or attempt to attach text immediately following the variable name.

1. Substring Removal (Pattern Matching)

These operators look at a variable's value and trim matching patterns from either the right (end) or left (beginning). They come in two flavors: shortest match (% or #) and longest match (%% or ##).

Right-Side Removal (Suffix)

Used heavily for changing file extensions or stripping trailing paths.

  • ＄{var%pattern} (Shortest Suffix Match)

Removes the smallest matching pattern from the end of the string. 

filename="archive.tar.gz"
echo "${filename%.*}"
# Output: archive.tar
  • ＄{var%%pattern} (Longest Suffix Match)

Removes the largest matching pattern from the end of the string. 

filename="archive.tar.gz"
echo "${filename%%.*}"
# Output: archive

Left-Side Removal (Prefix)

Used heavily for stripping directory paths or protocol prefixes.

  • ＄{var#pattern} (Shortest Prefix Match)

Removes the smallest matching pattern from the beginning of the string. 

filepath="/usr/local/bin/node"
echo "${filepath#*/}"
# Output: usr/local/bin/node   (removes the very first slash)
  • ＄{ar##pattern} (Longest Prefix Match)

Removes the largest matching pattern from the beginning of the string. Often used to isolate a filename from an absolute path (like basename). 

filepath="/usr/local/bin/node"
echo "${filepath##*/}"
# Output: node   (removes everything up to the final slash)

(Note: These patterns support wildcards like *, ?, and character classes like [0-9]*).

2. Substring Extraction

You can slice a variable by index, much like an array or Python string.

  • ＄{var:offset}

Extracts everything from the string starting at the given 0-based index. 

str="Hello_World"
echo "${str:6}"
# Output: World
  • ＄{var:offset:length}

Extracts a specific number of characters starting from the offset. 

str="Hello_World"
echo "${str:0:5}"
# Output: Hello

3. Search and Replace

You can substitute parts of a string inline without writing complex regular expressions.

  • ＄{var//pattern/replacement} (Global Replacement)

Replaces all occurrences of the pattern. 

sentence="foo bar foo baz"
echo "${sentence//foo/qux}"
# Output: qux bar qux baz
  • ＄{var/pattern/replacement} (Single Replacement)

Replaces only the first occurrence of the pattern. 

sentence="foo bar foo baz"
echo "${sentence/foo/qux}"
# Output: qux bar foo baz

4. Default Values and Error Handling

Parameter expansion can also control what happens if a variable is unset, empty, or uninitialized.

  • ＄{var:-default} (Use Default If Unset or Empty)

If var is empty or unset, it evaluates to default. (If it has a value, it keeps it). 

echo "${USERNAME:-guest}"
  • ＄{var:?error_message} (Error If Unset or Empty)

If var is missing, it halts execution and prints your custom error message to standard error. Great for shell script validation. 

: "${API_KEY:?Error: API_KEY environment variable is required.}"

Summary Cheat Sheet

Expression Description
＄{var%pattern} Trim shortest match from the right (end)
＄{var%%pattern} Trim longest match from the right (end)
＄{var#pattern} Trim shortest match from the left (start)
＄{var##pattern} Trim longest match from the left (start)
＄{var/pat/repl} Replace first match of pat with repl
＄{var//pat/repl} Replace all matches of pat with repl
＄{var:offset:len} Extract substring by index and length
＄{var:-default} Fallback value if unset or empty
