Text Documentation (Not linked on Training Page)

Description

Light Box is a Houdini LOP node that shows the lights & lighting-related prims on the USD stage at a certain point in the LOP network, and encapsulates light create and edit nodes in order to edit attributes of lights coming from upstream or create new lights.

Features

Creation

In the toolbar at the top of the window, you can create lights, modifiers, procedural modifiers, transport modifiers, and hypersets.

In the hierarchy

The system automatically handles the placement and naming of new items to ensure an organized hierarchy, while still allowing for manual overrides during the creation process.

  • Automatic Parenting Logic. When creating a new item, the system determines its parent based on the current selection. By default, the item will be parented to the first selected Palette. If an item different from a Palette is selected, the system will automatically target that item's Palette for the new addition.
  • Customization via Creation Dialog. Before the item is finalized, a creation dialog is presented to the user. This interface provides the opportunity to explicitly define the item's Name and manually reassign its Parent if the default selection is not wanted.
  • List Order and Visibility. To ensure that newly created items are immediately accessible, all new items are added to the top of the Palette. This "top-down" placement logic prevents new additions from being lost at the bottom of long hierarchies.

In the world

The 3D placement of a new light depends on the shortcut modifier used when clicking the creation icon. These shortcuts allow for precise positioning directly from the toolbar:

  • Standard Creation (LMB): Initializes the light at the world origin.
  • Camera Match (Shift + LMB): Positions and orients the light to match the current camera view.
  • Interactive Placement (Ctrl + LMB): Enables a "click-to-place" mode, allowing the light to be positioned anywhere in the viewport with a single click.

For quick reference, hovering over the toolbar icon will display a tooltip with the complete list of available shortcuts.

Duplicate

The duplication process now includes a naming step to improve scene organization:

  • A dialog now prompts for a name when duplicating item.
  • When duplicating multiple items at once, the provided name is applied to all of them with automatic numbering. For example, entering "foo_01" will create foo_01_lgt, foo_02_lgt, etc.

Copy/Paste

  • Full copy from Lightbox:
    • RMB - Copy
  • Paste into the network or in a Lightbox under a palette.
  • Supported types: Lights and TMods.

Bake out

  • Bake out all the lights from a lightbox and drop a new lightbox in the network:
    • There's a 'bake' button (like a tiny oven) that is meant to bake/flatten a Lightbox into a new Lightbox
  • Not working completely (LIMA-9591)

Editing in Parm Panel

Options:

  • Horizontal split
  • Vertical split

Selection

Selections between LightBox and the SGT are decoupled by default, allowing for independent navigation in each view. To synchronize them, use the following workflows:

Syncing selection from LightBox to SGT

  • Manual Sync:
    • Select your items in LightBox, RMB, and choose Select in SGT.
  • Quick Selection (Alt + LMB):
    • For Lights: Selects the item in the SGT and triggers the LightBox viewer state.
    • For Non-lights: Updates the SGT selection only, maintaining the current viewer state.

Syncing selection from SGT to LightBox

  • Manual Sync: Select your items in the SGT, right-click RMB, and choose Select in Lightbox.

Viewer state

Quicker light transformation by staying on the Lightbox level

Solo and Mute

While the core logic mirrors the SGT, the LightBox implementation focuses on intuitive Palette management:

  • Toggling Solo or Mute at the Palette level automatically applies that state to every item within that group. This allows for rapid, one-click isolation or silencing of entire light sets.
  • Toggling an individual light’s state breaks the unified Palette status. Consequently, the parent Palette will lose its Solo/Mute status and its associated icon will be removed to reflect the mixed state of the group.
  • To streamline the workflow, a context menu is available to quickly Clear All Solos or Clear All Mutes across the entire scene.

Reordering

  • Drag & drop to change prim order within palette
  • Locally created lights can be reordered and reparented.
  • Upstream prims can only be reordered within its parent palette.
  • Right-click option on the palette to Clear Prim Order Edits.
  • New lights will be placed at the top under a palette.

Constraints

  • Blue Chain-links: indicates constrained by constraint nodes
  • Orange Chain-links: indicates constrained within a light meaning that it has the lookat parm enabled.
  • Blue & Orange Chain-links: indicates that it has both types of constraints
  • RMB > Jump to External Constraints
