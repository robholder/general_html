Lightbox Node

Viewing - Two options:

  • Parmameters panel:
    • Don't pin - it'll be a UI update hog.
  • Dedicated Lightbox panel:
    • Better - doesn't have to recalculate all the time through stream.

Panel

Customization of UI

  • Rearrange columns:
    • Tricky you have to follow the divider down until the <-> icon appears.
  • Change width of columns:
    • you can re-space the columns by grabbing the name of the property, then sort of letting go of the mouse in the vertical column area.

Choose Columns

  • RMB in the title area:
    • Choose Columns:
      • check boxes
      • There's an Edit Attribute Columns at the base:
        • you can filter with search string here
        • If you are looking for a parm, hover the mouse over a parm panel to see programmatic names

Saving Settings

  • RMB in the title area:
    • Save Changes
    • Save As...
    • Rename
    • Revert Changes

Material Enabled and Emissive

Video Frame #: 3034

(Material) Enabled

(Use with caution. Not normal workflow.)

This removes the light from the render.

  • material:enabled is light enabled basically:
    • Sometimes shows up as correctly as enabled due to some bug.
    • This is linked to the Enabled checkbox on the light.

Emissive

This does not remove the light from the render, although it may well render 'black'. It will still occupy a 'category'.

  • Emissive:
    • This parameter toggles Emmisive checkbox on the light.

Light Management

  • You can re-order the lights

However...

  • Inherited Lights:
    • You can't move between 'palettes'
  • Local Lights (created in the particular Lightbox):
    • You CAN move between 'palettes'
  • Palettes stay where they are.

Remembering States

  • Dedicated Lightbox Panel may not remember open/close states
  • Parameter view of Lightbox is more robust at this.

Duplicating Lights

  • RMB > Duplicate:
    • you get a dialog to name/rename
    • Duplicate and Cancel buttons.

Solo

NOTE: To see soloing in the Viewport and Ion, the 'Apply Viewport Overrides' must be toggled 'on' in the 'Interactive' node (base of Stage network).
  • This parameter effects Viewport and Ion
  • Does not pass through to Helios and final renders
  • RMB to clear all solo selections

Filters

  • There's a filter field to type in search strings
  • Hitting enter/return will filter the Light Box panel to match the search term.

Dialog

Click the filter icon to the right of the filter field to get a GUI with more filter options.

Light Creation Icons

  • Clicking the light icons will create the light at the top of the selected palette light list.
  • Clicking with a selected light, the new light will be in the same palette as the selected light.

Light Creation options

THESE ARE BIT FLAKY. NOT VERY RELIABLE OR ACCURATE.

Hover mouse over icons to see creation options.

  • LMB - create light at origin.
  • <Shift> + <LMB> - Create a light from the current camera view.
  • <Cntl> + <LMB> - Lets you place the light where you click.

Constraint Flags

You might see little 'link' or 'chain' icons when you hover over a light in the Lightbox light/palette list:

  • Orange is 'look at' constraint
  • Blue indicates a constraint node 'upstream'

You can RMB on the light to Jump to External Constraint(s)

Overrides

  • Red dots will appear when something (from upstream) is edited.
  • To remove edits:
    • RMB on property and select Clear

Edit Details

To show the light/item parameters:

  • Click on the 'invisible till hovered over' Edit Detail icon (next to the 'invisible' Transform handle icon).

Selecting light in the SGT (from Lightbox)

  • Clicking lights in Lightbox doesn' select in SGT
  • To actually put on focus on light in SGT (select and enable handles)
    • RMB > Select in SGT
      • ...and you can multi select in this way.
    • <Alt> + RMB

Corollary - you can RMB in SGT and select in Lightbox.

Inheritance

  • You can't delete or rename a light that's from upstream.

Workaround

  • RMB on light:
    • Prune
      • Delete in effect (but not really)
    • Prune and Duplicate As...:
      • Allows you to rename a light
      • But - inheritance is lost

Prune

  • When a 'Prune' is invoked, a prune_before_lightbox will appear above the Lightbox.
  • Additional 'Prunes' will be appended to this node.

Jump To Existing Editor Node

To see where a light or parameters are coming from:

  • RMB on a light/palette:
    • Jump to Existing Editor Node
    • List will be shown to the right:
      • Click on the one

Multiple Light Boxes

You can use multiple Light Boxes, including 'off to the side'.

Random

  • TMODs can be Copy & Paste'd
  • The subnet within Lightbox is visible, but it's not recommended to poke around:
    • Technically you can copy stuff out of the Light Box subnet.
    • However, RMB and copy should be the same thing and preferable.
