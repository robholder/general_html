Simple Volumes

The volume exists inside a boundary and are 'placed' in the scene.

To Create:

  • In the node graph, in the lgtAsset backdrop area, drop:
    • simple volume
  • Place the bounding cube in the scene (the volume will be within those boundaries).
    • Be conservative.
    • Scale -> size:
      • e.g., 1000 x 1000

To Preview in Ion

  • Switch Viewport to Ion
  • D key in Viewport to bring up Display Options:
    • Render Tab:
      • Enable Volumes checkbox to 'on'

Controlling the Volume

  • Attributes tab:
    • General toggle-down widget:
      • Extinction:
        • absorbed color
      • Extinction Distance:
        • How far before total extinction of light occurs
        • Higher is less dense (finer)
        • Lower is more dense (thicker)
      • Albedo:
        • reflected/scattered color
      • Eccentricity:
        • The scatter profile.
        • Direction of scatter:
          • 0 - all directions
          • Steam:
          • -1 - like steam:
            • see mostly light that shining onto the volume from the camera
          • Sand:
          • 1 - dusty and dirty:
            • see mostly light that's shining through towards the camera

Keep the Extinction and Albedo similar

Example:

  • Extinction to red:
    • absorb red
  • Albedo to white:
    • reflect result with no further coloring
  • Resutl -> Green

Excluding Lights

Excluding Lights from the Simple Volume - Technique One

Video Frame #: 21328

This technique is clunky, labor intensive and open to error (especially when developing rig or importing lights and rigs).

On you volume's parm panel:

  • Select light you want to exclude
  • Other tab:
    • Targets:
      • Exclusive Targets
        • Add whole shot:
          • :wdas:shot:shot:
    • Excludes:
      • Exclusive Excludes
        • Add light as a target (to exclude)
          • :wdas:shot:lgtAsset:lgtAsset

TMODs

In the 'Modifiers' area of Houdini's Node Graph:

  • Drop a Transport Modifier (TMOD)
  • In the TMOD parms: Select the light(s) in the SGT (Scene graph tree), select the light(s)
  • Lights to Exclude:
    • Select the light(s) in the SGT (Scene graph tree)
    • In the parm panel, Sources:
      • Add with the hexagon button (with the + icon)
  • Volume to set:
    • Select the volume item in the SGT (Scene graph tree)
    • In the parm panel, Layers:
      • Add with the hexagon button (with the + icon)
    • To the right of that parm panel (scroll across):
      • Set the V Path Restrictions checkbox to 'off'

Render Passes for Volumes

Video Frame #: 29456

Example setup

  • en_all:
    • Chars are hidden from camera
  • ch_all:
    • Env matting out characters (isMatte)

If we add volume, it'll show up in the renders.

Setting up Volume Pass

Create Pass

  • Select the RenderPassManager node (at the base of the node graph)
  • In the parm panel:
    • Create New Pass:
      • Template -> SimpleVolume
      • Category -> VOLUME
      • Render Pass Name -> fx_atmo_vol
  • Accept and place with mouse to the right.

The pass automatically creates an isMatte node.

  • Select in the node graph.
  • Activate by un-checking the yellow pass-through flag.
  • The Assignments tab shows:
    • Targets:
      • Entire shot
      • :wdas:shot:*:trs_mater
    • Excludes:
      • All lighting assets:
        • :wdas:shot:lgtAsset*:trs_master

Disable Volumes in main passes

Disable volume overall, and activate it for passes that require it.

Prune Method

To remove the volume from all passes, in the Node graph:

  • Switch Ion to ALL pass to view what's going on.
  • Directly after the SimpleVolume node:
    • Add a lgt Prune node (It'll get renamed to dlgt_prune1)
  • In the prune parm panel, in Targets:
    • Add the volume locator:
      • /shot/lgtAsset/trs_master/trs_shot/trs_aux/model/SimpleVolume1_VolumeLocator
  • In Ion, all volume should disappear.

Bring back Volume where you need it.

  • Copy the Prune node and paste a copy into the Volume pass
  • Switch these copied nodes from:
    • Action -> Prune
    • to:
    • Action -> Unprune
  • Copy this node to any other passes that needs volume: e.g:
    • All
    • fx_atmo_vol

Hidden From Camera Method

NOTE: The 'SimpleVolume' shader has a 'visibleToNonCamera' option on it's 'Visibility' section: set to on by default.

This method

  • Gives more 'accurate' lighting
  • Adds more bounce
  • Can cause flickering.
  • Slower

Recommendation is to use Prune for general atmospheric volumes (unless you are rendering a sauna or heavy, heavy mist.

Simple Volumes Directly on Passes

You might see a SimpleVolume node being placed just above the isMatte node in the pass blocks.

The disadvantage is that the following method makes any All pass not strictly the same as the elemental passes combined.

Implications

The TMOD won't work (if you have one to remove lights) since it's below the TMODs.

So you need to exclude lights in a different way.

You could add a dpipe Modifier and switch to emissionOFF and add lights.

  • Targets takes everything:
    • :wdas:shot:lrg*:trs_master
  • Excludes needs the lights that need to be turned off.
  • Example:
    • :wdas:shot:lrigLOCAL:all_candle_PRC_03_lgt

Editing Inherited Values

  • The volume's location and dimensions are controlled on the locator item in the SGT.
  • The volume's shader is adjusted in the SimpleVolume's material item in the SGT.

Editing Shader

To edit the shader then, select the material SimpleVolume (cloud icon) under model/matPalette/volume_materals item in the SGT, and right click on the item (in the SGT) and choose:

  • RMB > dpipe Edit Helper

Editing Location

To edit the location/locator, select the locator model/SimpleVolume1_VolumeLocator (of similar) item in the SGT, and right click on the item (in the SGT) and choose:

  • RMB > dpipe Edit Helper
