To add a pass:

    • Click on the dropdown toggle on the Add field to see a list.

Custom Color Mattes

RGB Mattes

Creates R, G and B mattes.

In Nuke:

  • Use RGB_Combine node to mix/separate.
NOTE: Use iBlur for masked Blur effects.

Creating Color Mattes

In the 'Color Mattes' area of the shot/packet backdrop:

  • Add a Color Mattes node
  • In the parm panel:
    • Make sure there's a populating the field (use the drop down to choose)
    • click the Color Matte Wizard teeny button.
    • In the GUI, you'll see three tabs.
    • Select the vacant color mattes by selecting the R, G or B checkbox(es) and hit Create
    • You'll get dropped into the Color Matte node (or jump in yourself), and you'll see a dpipe Modifier node for each channel (R, G or B).
    • Click on these in turn, and on the Assignments tab, you can indicate or add Targets (to show up in the matte).

Setup ColorMattes: Summary

  • To create a Color Matte:
    • Tab and drop a ColorMattes node (not 'dpipe Modifier'):
      • Set an lrig Palette field
      • Click on the Color Mattes Wizard icon (tricolor icons)
        • Set a channel (R, G or B with a check in the checkbox)
        • Create button to create matte channel
        • Close Gui.

Deepmattes

This is the Disney version of Cryptomatte.

The hy_all_utility_deepmattes pass creates a node in Nuke that shows nothing until you add a DeepMatte Nuke node.

  • Select and view the DeepMatte node
  • Node the On click parameter dropdown for type of item.
  • <Ctrl> + LMB in the viewer to add items
  • <Ctrl><Shift> + LMB to multiselect:
    • Also, if you have a tricky selection (fur, skin etc. in one area), use the shift click and remove unwanted.
    • This selects all candidates for the pixel, not just the dominant.
  • Use GUI + and - to add/remove
  • Edit Matte Strings with wild cards.
  • Display Only Selected shows only the item selected in the GUI list - off and all selection are indicated (by red highlight).

Nuke Position Mattes

Like the deepmattes, you can use secondary nodes to use the data from the position passes.

  • PosSphere:
    • Creates a spherical selection area around a point.
    • <Ctrl><Alt/Option> LMB to select center from pos pass.
    • Alpha will contain the matte.
  • PosPlanes:
    • Create a box in space
    • You get six parameters for each cube side
  • RegionGrad similar workflow to the PosSphere
    • Alpha will contain the matte.

Nuke Pref Mattes

The same as Pos pass, but mattes derived from this pass will 'stick' to moving geometry/items.

Use with the same utility nodes (PosSphere, RegionGrad, etc.).

Modifiers

Video Frame #: 57436

Modifiers can be dropped in the pass backdrops (ch, en, etc.):

  • Tab -> dpipe Modifier:
    • choose from Template dropdown:
      • hiddenFromCamera
      • isMatte
      • isBlack
      • emissionOff
      • emissionOn
      • etc.

These fall into categories (not in UI):

  • Visibility
  • Material
  • Light
  • Render Output
  • Stereo
  • Procedural (has its own node)

Must Know Modifiers

  • isMatte:
    • holdout mattes in RGBA (but still contribute to scene)
  • hidden:
    • Remove items (as if they don't exist)
  • hiddenFromCamera:
    • Hide items from camera rays, (primary rays; but they still show in scene physics.)
  • hiddenFromNonCamera:
    • Hide in non-camera rays (secondary rays; shadows, reflections etc.)
  • emission ON/OFF:
    • Switch off lights for the pass.

Good to Know Modifiers

  • forwardCameraTag:
  • Passes modifier effect to reflections:
    • add forwardCameraTag
    • Attributes tab:
      • Custom field dropdown:
        • Reflection Only
        • No effect
        • Refraction Only
        • Refractions and Reflections
  • forwardTransportModTag:
    • Assigned to object (like glass) if the object is blocking the effect of a TMOD.
    • This modifier allows the TMOD effect to pass through the glass.
  • isBlack:
    • Put matte black shader on items
    • Useful for volume passes
  • emissionExpr:
    • Assignments Tab:
    • Target lights
      • Assign lights (per target) (Assignment Tab)
    • Attributes Tab
      • Adjust exposure (per target):
        • Either edit expression, or just replace with number value.
      • Adjust saturation (per target)
  • emissionCategory:
    • Assign target lights
    • Change emission numbers
  • dpipe_proceduralModifier:
    • This is a SEPARATE node (not dpipe Modifier)
      • Affects procedural stuff
      • Usually adjusting density of XGen etc.

Ray Guide

  • Camera Ray (Primary) - ray FROM the camera
  • Non-Camera Ray (Secondary) - the scene physics:
    • Shadows
    • Reflections
    • Refractions
