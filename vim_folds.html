Persistant Folds

To remember the folds in a file, add to vimrc: 

" Save and restore folding status in a file:
augroup save_folds
    autocmd!
    autocmd BufWinLeave *.* mkview
    autocmd BufWinEnter *.* silent loadview
augroup END

Vim Fold Markers Reference Guide

When you set foldmethod=marker, Vim looks for specific text patterns (markers) to automatically group and collapse lines of code or text. By default, it looks for {{{ to open a fold and }}} to close one.

Basic Syntax

  • Open a fold: Append {{{ to a comment line or heading.
  • Close a fold: Append }}} where you want the section to end.
  • Specify Fold Levels: You can add a number (1 through 9) to indicate the exact hierarchical nesting level (e.g., {{{1, {{{2).

Example in a Shell Script / Config File: 

# Main Configuration Section {{{1

  # Database Settings {{{2
  DB_HOST="localhost"
  DB_PORT=5432
  # }}}2

  # Server Settings {{{2
  SERVER_TIMEOUT=30
  # }}}2

# }}}1

Customizing Marker Characters (Optional)

If your file type doesn't support curly braces well or you prefer different symbols, you can change the marker strings using foldmarker: 

# vim:foldmethod=marker:foldmarker=START,END

With this setup, you would type # START and # END instead of {{{ and }}}.

Overriding Folding In Just A Host File

# vim:fileencoding=utf-8:foldmethod=marker

This line is a Vim modeline. It tells Vim to apply specific settings automatically to only that file when you open it, overriding your global settings.

Here is what each part of that specific line does:

  • # vim:: Tells Vim that everything following the colon is a configuration setting for this file (using # as the comment leader, which works for Python, Bash, shell scripts, etc.).
  • fileencoding=utf-8: Sets the character encoding of the file to UTF-8.
  • foldmethod=marker: Tells Vim how to organize and handle code folding for this file. It uses markers (usually defined by {{{ and }}}) to determine where collapsible sections begin and end, rather than trying to automatically fold based on syntax or indentation.
