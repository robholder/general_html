Python - Shortcuts

After updating to macOS 27 (Golden Gate), I found my Quick Actions (stored in /Users/user/Library/Services/<name>.workflow) no longer worked.

I tried a bazillion security tweaks in the System Settings, but they refused to work.

Eventually, I found a suggestion that each of my Automator (.workflow) items should be rebuilt using the macOS application, Shortcuts.

Shortcuts

If you've already constructed a Quick Action in Automator, the elements can be reused in the Shortcuts app.

Creating a 'Quick Action' as a Shortcut

Open the Shortcuts app.

  • You should see 3 panels:
    • A list of 'types':
      • Gallery
      • Automation
      • Library
      • All Shortcuts
      • Share Sheet
      • Quick Actions
      • Starter Shortcuts
    • A middle panel showing the selected group
    • An Ai dialog box on the right

Quick Actions

  • Click on Quick Actions
  • Create a new Shortcut:
    • <Cmd> n
    • You can Right-Mouse click and choose Rename and Change Icon
  • Double-click to open the editor panel:
    • You should have a left panel and a right panel:
      • Left panel:
        • A pre-populated panel with something like:
          • Receive Apps and 18 more from Quick Actions
      • Right panel:
        • With group titles at the top
        • Items at the bottom section

Set First Block:

  • Click Apps and 18 more:
    • For most of my file based Quick Actions, I just need 'Files'
    • To do this:
      • Select All, then Deselect All
      • Then select Files
  • Click on Quick Actions:
    • This should open the i panel on the right (in place of the items)
    • Switch on Use as Quick Action
    • Switch on Finder

Set Script type

  • Click on the receding folder icon on the right to return to items:
    • Click on Terminal in the top section (scroll down to find it)
    • This will reveal the Run Shell Script option in the lower section.

Script Addition

  • Drag Run Shell Script from the right panel to the middle (below the starting block)
  • If you have an existing Automator style Quick Action, you can copy the shell options and script from there.
  • For a lot of mine, I flipped the Shell: option to Python3 (if it's installed)
  • Sometimes this might be bash if calling an external script (perhaps Python)
  • Input is usually File for my shortcuts
  • Pass Input: to as arguments (usually for me)
  • Paste your script into the shell script field. (For me this was a copy and paste from existing Quick Actions in Automator).

You don't need to save, the Quick Action should appear as usual in the RMB context menu under Quick Actions (once they've been activates in the Extensions settings - see below).

It the action fails, you may get an error notification in the Notifications area of macOS (top right).

Activating Each Shortcut.

Each Shortcut needs to be 'switched on' in the System Settings:

  • System Settings > General > Login Items & Extensions
  • In the Extensions area:
    • By Category
    • Finder (click on the i)
    • Switch on each of the available Shortcuts, then Done

Sharing

You can backup or share the Shortcuts by

  • Selecting in the main panel and
  • File > Export... to save them.
  • These can be imported via the File > Import... dialog.

You can also use airdrop.

The shortcuts should be available to all your devices on the same account if iCloud sync is switched on.

Other Shortcuts (non scripted)

For things like image resizing, I had to use Gemini (Ai) to figure out how to replicate the Automator routine in Shortcuts.
