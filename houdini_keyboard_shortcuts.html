Network Editor

Keystroke action
TAB Node menu (and type to narrow down search)
<shift> TAB Node menu, but append the new node to the selected node, and the render flag is set
R Set selected node's Display Flag and Render Flag
Q Toggle selected node's 'bypass'
E Toggle selected node's 'template' flag
<alt> LMB Drag to duplicate selected node
Y LMB Drag across wire/connections to delete
J LMB Drag across nodes to connect with one swipe
<shift> LMB Move node and all above with it
<cntl> LMB Move node and all below with it
L Vertically align selected node's branch
A LMB (drag vertically) Align selected nodes vertically
A LMB (drag horizontally) Align selected nodes horizontally
<cntl> B Maximize panel
P Show parameter panel as inset on Network Editor
   

| MMB| On a network node to show the 'i' pane.

MacOS  
<command> # Set Quickmark # (quick navigation), e.g. 'command + 2'
<cmd> MMB On a network node to show the 'i' pane, but keep open
Linux/Windows  
<cntl> # Set Quickmark # (quick navigation), e.g. 'control + 2'
<cntl> MMB On a network node to show the 'i' pane, but keep open
   
# (number keys) Jump to Quickmark location, e.g., '2'
   
F2 Rename selected node
select nodes <alt> LMB Drop pre-wired 'Merge'. Select nodes, alt click below in empty space - a merge will appear, all connected

Esoteric Shortcuts

From:

  • ExternalLink: Medium - Uncommon Houdini Shortcuts
  • Ctrl dragging colors/shapes onto nodes sets them as the default.
  • Ctrl + Shift + Alt dragging nodes creates reference copies.
  • Holding 8 and moving nodes around prevents you from connecting with any wires.
  • Hold J and drag your mouse to connect as many nodes as you need.
  • Holding J button to connect all the nodes
  • Drag and drop any parameter from any node onto the viewport and select HUD Handle to adjust the values on the viewport.
  • Taking a screenshot and pasting it in the Network View with the Labs add on is called Capture and Embed. You can also place a sticker or paint over on the Network View. Hit Ctrl + I to edit the things you put on the Network View.
  • Similarly to the Labs Tool above, Shift + I add background images onto your Network View and again Ctrl + I lets you edit them.
  • Ctrl + Middle Click on a node pops out the info window.
  • To select a color outside Houdini with the eyedropper (for example inside a Color SOP) click the eyedropper then hold the Middle Mouse Button to select any color anywhere.
  • Hitting Shift + Enter while adding a new node will put that new node after the currently selected node, connect it and put the display flag on it.
  • Ctrl + Alt + S hides all panels.
  • Ctrl +/- while having the cursor on a VEXpression window increases/decreases font size.
  • Hitting = on your keyboard brings in the Choose Geometry window. Once you select any geometry, a file node is created for that.
  • Move a node outside the Network View while holding Spacebar to scroll the whole Network View.
  • Alt + Dragging copies a node but did you know that Alt + Ctrl + Dragging copies the node and the outputs. Similarly Alt + Shift + Dragging copies the node and the inputs.
  • Ctrl + F inside the Network View to find any node by searching for its name.
  • Hit Alt + [ to split any pane where your cursor is left/right. Alt + ] to split top/bottom. Hit Ctrl + W to close a panel.
  • Ctrl + B to maximize and panel.
  • Shift + O puts the selected nodes inside a network box. Selecting the box and hitting Shift + M resizes the network box to fit.
  • You probably know hitting L layouts all the nodes but if you select some nodes and hit Shift + L it layouts only those nodes.
