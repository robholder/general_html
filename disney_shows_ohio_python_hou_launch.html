Hou Launch - A Utility by J ames L ojo

Overview of the Script

At a high level, this script is a custom command-line launcher and search utility for Houdini scene (.hip) files in a studio pipeline.

Instead of forcing an artist to manually open a terminal, navigate through complex nested directory trees, remember naming conventions, and look up file modification dates, this script automates the entire process:

  1. It figures out what show, sequence, shot, and department you are working on using environment variables or command-line arguments.
  2. It crawls through the studio's file storage hierarchy under those constraints.
  3. It filters the files based on who owns them or whether they match a specific shot configuration stored inside the binary files.
  4. It presents an interactive, numbered menu sorted by modification date so you can pick one to launch immediately with a single keystroke.

Section-by-Section Breakdown & Techniques

To understand how it pulls this off, let's break the script down into its functional parts:

1. Setup, Environment Variables, and Help Text

  • What it does: It sets up custom color formatting (F_COLOR, F_BOLD) for the terminal output using ANSI escape codes, defines the help documentation, and grabs active pipeline context variables from the operating system (PROD, NAV_SEQ, NAV_SHOT, NAV_DEPT, USER).
  • Technique: os.getenv() is used to read environmental context. Pipeline environments (like Shotgun/Flow or custom studio shells) populate these variables so the script automatically knows your current context when you open your terminal.

2. Command-Line Argument Parsing

  • What it does: It loops through whatever flags and numbers you type in your terminal (e.g., hou -l -mine 15). It separates control flags (-mine, -user, -launch, -list, --help) from positional arguments (like a specific shot or sequence number).
  • Technique: A custom while loop with an index tracker (i += 1 or i += 2) handles flags that consume the next argument (like -user bobby). This is a standard manual way to parse CLI arguments without relying heavily on Python's built-in argparse module, giving the author total control over custom shorthands.

3. Context Resolution (nav.Navigator)

  • What it does: It imports a custom studio-specific core service module (coreservices import nav) to validate and resolve shorthand numbers (like typing 15 into a sequence) into official production strings (like sequence 010 and shot 015.00).
  • Technique: External library integration. Studio pipelines often write proprietary core Python packages to ensure all pipeline tools talk to the database or file naming convention standardly.

4. Directory Traversal and Path Construction

  • What it does: It builds the root path down to the department directory (e.g., seqData/lighting/) and prepares to loop through user subdirectories while skipping clutter (miscData, logs, pic, temp, texture).
  • Technique: Combining os.path.join(), os.listdir(), and boolean list comprehensions (if os.path.basename(sub).lower() not in EXCLUDED_DIRS) to safely filter paths in cross-platform Python.

5. File Discovery, Filtering, and the strings Trick

  • What it does: Depending on whether you're looking for a specific shot or all shots (wildcard_mode), it executes file searches. For specific shots, it uses a clever pipeline trick: because Houdini files are binary, it uses the Unix strings utility piped into grep to peek inside the binary .hip file text-stream to see if it contains the target shot metadata configuration (uiconfig / shot tag).
  • Technique: Subprocess execution and command pipelining. The script uses subprocess.getoutput() and subprocess.run(..., shell=True) to leverage powerful native Unix shell utilities (find, ls, sort, tail, strings, grep, stat) directly from Python. This is common in VFX/animation pipelines where Linux command-line tools are heavily optimized for file-system crawling.

6. Sorting, Displaying, and Interactive Selection

  • What it does: Once a list of matching .hip file paths is compiled, it queries the operating system for each file's modification timestamp (os.stat().st_mtime) and owner username (stat -c %U). It sorts them from newest to oldest, formats them into a clean numbered list, and prints them to the terminal.
  • Technique: Tuple sorting and formatting. It stores files as tuples (mtime_ts, mtime_str, owner, path), sorts them using Python's sort(reverse=True, key=lambda x: x[0]) (putting the most recently modified files at the top), and uses f-strings with alignment padding (:<12) for a neat terminal UI.

7. Launching Houdini

  • What it does: If you pass -l (launch-only) or type a number from the interactive menu, it constructs a launch command (run_houdini -n /path/to/file.hip &) and fires it off in the background.
  • Technique: subprocess.Popen() runs the external command asynchronously (using the & background operator in shell mode), meaning the launcher script can safely exit while your newly spawned Houdini session opens up independently. 
    #!/usr/bin/env python3
"""
################################################################################
Script Name: hou_launch (Houdini File Launcher / Finder)
Description: Searches and launches Houdini scene files based on production context,
             sequence, shot, and user-defined directory hierarchies.

Author:
    - Original Author: J ames L ojo
    - Modified By:     me

Version:
    - 1.1.0 (2026-08-27) - me:
        * Updated directory traversal to support the new multi-user
          'seqData/lighting/<username>/' hierarchy.
        * Added explicit exclusion handling for miscData, logs, pic, temp, texture.
        * Integrated 'houdini' subdirectory checks prior to .hip file search.

    - 1.0.0 (Original) - J ames L ojo
        * Initial script creation and core navigation logic.
################################################################################
"""

import sys
import os
import subprocess
from datetime import datetime
from coreservices import nav

F_COLOR = "\033[38;5;208m"
F_BOLD = "\033[1m"
F_UNDERLINE = "\033[4m"
F_END = "\033[0m"
HELP_TEXT = f"""
 {F_COLOR}{F_BOLD}hou

 Usage:
   hou_launch [flags] <shot>
   hou_launch [flags] <seq> <shot>

 Flags:
   -mine                          search for hip files owned by you
   -u, -user                      search for hip files owned by bobby
   -l, -launch                    skip selection and just launch latest matching hip file
   -list                          list results and exit
   -h, --help                     show this help message and exit

 Examples:
   hou_launch                            search for hip files containing the current seq and shot
   hou_launch 15                         search for hip files containing shot 015.00 of the current seq
   hou_launch -l -mine 15                launch your latest hip containing shot 015.00
   hou_launch -l -u bobby 15             launch latest hip for shot 015.00 owned by bobby{F_END}
"""

args = sys.argv[1:]
prod = os.getenv("PROD")
seq_default = os.getenv("NAV_SEQ")
shot_default = os.getenv("NAV_SHOT")
dept_default = os.getenv("NAV_DEPT")
user_self = os.getenv("USER")

if not prod:
    print(f"\n{F_COLOR}{F_BOLD}No gig found.{F_END}\n")
    sys.exit(1)

user_mode = "all"
launch_only = False
list_only = False
args_clean = []

i = 0
while i < len(args):
    if args[i] in ("-h", "--help"):
        print(HELP_TEXT)
        sys.exit(0)
    elif args[i] in ("-user", "-u") and i + 1 < len(args):
        user_mode = args[i + 1]
        i += 2
    elif args[i] == "-mine":
        user_mode = user_self
        i += 1
    elif args[i] in ("-launch", "-l"):
        launch_only = True
        i += 1
    elif args[i] == "-list":
        list_only = True
        i += 1
    else:
        args_clean.append(args[i])
        i += 1

if len(args_clean) == 0:
    shot = shot_default
    seq = seq_default
    dept = dept_default
    if not shot:
        print(HELP_TEXT)
        sys.exit(1)
elif len(args_clean) == 1:
    if not seq_default:
        print(f"\n{F_COLOR}{F_BOLD}Sequence is not set.{F_END}\n")
        sys.exit(1)
    shot = args_clean[0]
    seq = seq_default
    dept = dept_default
elif len(args_clean) == 2:
    seq, shot = args_clean
    dept = dept_default
else:
    print(HELP_TEXT)
    sys.exit(1)

if not dept:
    print(f"\n{F_COLOR}{F_BOLD}Department is not set.{F_END}\n")
    sys.exit(1)

n = nav.Navigator()
n.read_environment()
n.set_assettype("seq")
n.set_tree("work")
n.parse_arguments([seq, shot, dept])
seq_str = n.get_sequence()
shot_str = n.get_shot()
dept_str = n.get_department()

# old department directory path (NEST?)
#dept_dir = f"/myserver/shows/{prod}/work/Sequences/seq/{seq_str}/seqData/{dept_str}"

# new department directory path (OHIO?)
dept_dir = f"/myserver/shows/{prod}/work/Sequences/seq/{seq_str}/seqData/{dept_str}"

if not os.path.isdir(dept_dir):
    print(f"\n{F_COLOR}{F_BOLD}Department directory not found: {dept_dir}{F_END}\n")
    sys.exit(1)


user_filter = ''
if user_mode != "all":
    if user_mode == user_self:
        user_filter = '[ -O "$f" ] && '
    else:
        user_filter = f'[ "$(stat -c %U \"$f\")" = "{user_mode}" ] && '
print()

# Explicitly defined exclusions based on a list (update as needed)
EXCLUDED_DIRS = ["miscdata", "logs", "pic", "temp", "texture"]
wildcard_mode = (shot_str == "seqData")
search_label = "any" if wildcard_mode else shot_str

if user_mode == "all":
    user_label = "any user"
elif user_mode == user_self:
    user_label = f"{user_self}"
else:
    user_label = f"{user_mode}"

print(f"{F_COLOR}{F_BOLD}Searching sequence {F_UNDERLINE}{seq_str}{F_END}{F_COLOR}{F_BOLD} hip files by {F_UNDERLINE}{user_label}{F_END}{F_COLOR}{F_BOLD} for shot context option: {F_UNDERLINE}{search_label}{F_END}\n")

paths = []

if wildcard_mode:
    # Iterate through all usernames under seqData/lighting/<username>/
    usernames = [d for d in os.listdir(dept_dir) if os.path.isdir(os.path.join(dept_dir, d))]
    for user in usernames:
        user_path = os.path.join(dept_dir, user)
        # Get all subdirectories, ignoring the exclusion list
        subdirs = [os.path.join(user_path, sub) for sub in os.listdir(user_path)]
        subdirs = [sub for sub in subdirs if os.path.isdir(sub) and os.path.basename(sub).lower() not in EXCLUDED_DIRS]

        for sub in subdirs:
            houdini_dir = os.path.join(sub, "houdini")
            if os.path.isdir(houdini_dir):
                f = subprocess.getoutput(f'ls -1 "{houdini_dir}/lighting_v"????.hip 2>/dev/null | sort | tail -1')
                if f and os.path.isfile(f):
                    if user_mode == "all":
                        paths.append(f)
                    else:
                        stat_user = subprocess.getoutput(f'stat -c %U "{f}"').strip()
                        if (user_mode == user_self and os.stat(f).st_uid == os.getuid()) or (stat_user == user_mode):
                            paths.append(f)
else:
    # Use find over the department base directory, filtering out unwanted directories, and targeting the 'houdini' folder
    excluded_args = " ".join([f'-name "{ex}" -prune -o' for ex in EXCLUDED_DIRS])
    # Constructing a find query that dives into usernames, skips exclusions, finds task/shot folders containing a 'houdini' subfolder
    cmd = f'''
    find "{dept_dir}" -mindepth 2 -maxdepth 2 -type d \\( {excluded_args} -print \\) | while read d; do
      houdini_dir="$d/houdini"
      if [ -d "$houdini_dir" ]; then
        f=$(ls -1 "$houdini_dir"/lighting_v????.hip 2>/dev/null | sort | tail -1)
        [ -f "$f" ] && {user_filter} strings "$f" | grep -q '"uiconfig":"{{\\\\"label\\\\": \\\\"shot\\\\"' && \\
          strings "$f" | grep -q '\\[\\\\"{shot_str}\\\\", \\\\"{shot_str}\\\\\"\\]' && \\
          echo "$f"
      fi
    done
    '''
    result = subprocess.run(cmd, shell=True, text=True, capture_output=True)
    paths = result.stdout.strip().split("\n") if result.stdout.strip() else []

if not paths:
    print(f"{F_COLOR}{F_BOLD}No matching .hip files found.{F_END}\n")
    sys.exit(0)

file_info = []
for path in paths:
    try:
        stat = os.stat(path)
        mtime_ts = stat.st_mtime
        mtime_str = datetime.fromtimestamp(mtime_ts).strftime("%b %d %H:%M")
        owner = subprocess.check_output(["stat", "-c", "%U", path], text=True).strip()
        file_info.append((mtime_ts, mtime_str, owner, path))
    except Exception:
        continue

file_info.sort(reverse=True, key=lambda x: x[0])
max_user_len = max(len(user) for _, _, user, _ in file_info)

if launch_only:
    latest = file_info[0]
    print(f"{F_COLOR}{F_BOLD}[1]{F_END} {F_COLOR}{latest[1]:<12} {latest[2]:<{max_user_len}} {latest[3]}{F_END}")
    launch_cmd = f"run_houdini -n {latest[3]} &"
    print(f"\n{F_COLOR}{F_BOLD}Running command:\n{launch_cmd}{F_END}\n")
    subprocess.Popen(launch_cmd, shell=True)
    sys.exit(0)

for idx, (_, mtime_str, user, path) in enumerate(file_info, 1):
    padding = " " if idx < 10 else ""
    print(f"{F_COLOR}{F_BOLD}[{idx}]{padding}{F_END} {F_COLOR}{mtime_str:<12} {user:<{max_user_len}} {path}{F_END}")
print()

if list_only:
    sys.exit(0)

try:
    choice = input(f"{F_COLOR}{F_BOLD}Which hip do you want to open? (0 to cancel){F_END}  ")
    if choice.strip().isdigit():
        choice_num = int(choice)
        if 1 <= choice_num <= len(file_info):
            selected_path = file_info[choice_num - 1][3]
            launch_cmd = f"run_houdini -n {selected_path} &"
            print(f"\n{F_COLOR}{F_BOLD}Running command:\n{launch_cmd}{F_END}\n")
            subprocess.Popen(launch_cmd, shell=True)
        elif choice_num == 0:
            print(f"\n{F_COLOR}{F_BOLD}Cancelled by user.{F_END}\n")
        else:
            print(f"\n{F_COLOR}{F_BOLD}Invalid selection.{F_END}\n")
    else:
        print(f"\n{F_COLOR}{F_BOLD}Invalid input.{F_END}\n")
except KeyboardInterrupt:
    print(f"\n\n{F_COLOR}{F_BOLD}Cancelled by user.{F_END}\n")
    sys.exit(0)
