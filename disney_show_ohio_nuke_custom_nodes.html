WDAS Custom Nodes

Positional Tools

The elements for this set of tools are found in the hy_all_util_pass > geometry passes (if turned 'on' in the render specs):

  • Pos
  • Pref
  • Note: Use implicitAlpha on the import/instance node

Pos

Static position data based on the spacial location.

Pref

  • 'Stuck' to objects. Use if you want tools to 'stick' to objects or characters.
  • The reference space of object is set to their 'rest poses', so for characters that's most likely a T-pose, and for animated objects, that'll be in a rest position (e.g. a book - might have the pref created in its closed state).

RegionGrad

  • Create with RMB > RegionGrad.
  • Double-click if the properties aren't visible.
  • Position control should appear on the viewer area:
    • Move to center the RegionGrad on the point on the position data.
  • Hard Expand to set overall size
  • Soft Falloff to set falloff ramp at the edge of the grad and black.
  • All other settings are the same as in the Hyperion render (3D).

To Copy the RegionGrad to Houdini

Select RegionGrad node, and in its properties, click:

  • Copy To Houdini (via Node Builder)
  • In the GUI:
    • Select the RegionGrad you want from a list of them in your scene file
    • click on Copy Nodes to Houdini Clipboard
    • This take a while to 'cook'.
    • When done, in Houdini, paste into the node graph.
  • Unpremult is activated by default.

PosPlanes, PosSphere, PosRectangle

These cannot be exported to Houdini.

  • Tab > Pos<shape>
  • You need an unpremult between the Pos pass and these tools.

Other:

  • The PosSphere is like the RegionGrad
  • The PosPlanes is a slice tool to split scenes by an X, Y, Z axis.

Depth

Depth passes can be found in most import nodes.

  • Set the instance node to implicitAlpha
  • Add an unpremult node
  • Add a Grade node.
  • For blackpoint and whitepoint:
    • <Ctrl> <Alt> across Depth pass to set sample points
  • Add a shuffle and pipe the R, G or B into the Alpha
  • Position control should appear on the viewer area:
    • Move to center of RegionGrad
  • Hard Expand to set overall size

QuickPaint

Useful for making mask shapes that stick via a hold frame (or even a full RGB patch).

  • Only use this on static objects
  • Connect the WorldPos pipe to the position pass.
  • Connect a RotoPaint to the Paint pipe
  • The output of the QuickPaint node becomes a matte or a full RGB patch.

Paint your mask, then:

  • Click Set Frame on the QuickPaint
  • Now, if you scrub through, you should see the mask stick.

The Cam input allows for projections onto geo.

Normal Rotate

Found in Shadow Box. (Search for normal.)

  • Plug in 'normal' pass
  • Use Y and Z sliders to 'rotate' the normals
  • Use R, G or B as a matte.

Recolor

This node can blend the 'color' pass (no lighting) into your emissions.

It can be useful for adjusting specific emission categories. (Can be used for removing reflections from eyes.)

  • File > Insert Comp Nodes -> Nuke R&D
  • Look for reColor node.
  • color input is the 'color' pass
  • emission is your light emission.

You can also use to do the eye work:

  • color and emission and mask
  • Adjust multiply slider to 'blend'

ContactSheetDisney

  • <Tab> > ContactSheetDisney

This node comes with only one input.

  • Add Input to add additional input pipes.
  • Connect inputs to tile.
  • Arrange rows, columns and gaps
  • You can Enable Comments to add your own text to inputs.

Interactive Cache

Used to precomp (render) portions of you comp network.

  • Tab and search
  • By default set to Live (pass-through)
  • Custom Pass Name your precomp
  • Set checkboxes if using Ocula, OpticalFlares or Sapphire to load those plugins on the farm.
  • Read Path and Write Path should be set.

To Render:

  • On the properties:
    • Click on Quip Setup button at base.
  • In the Interactive Cache UI:
    • This will list the InteractiveCache nodes (and display status)
    • Select IC Nodes:
      • Submit Selected to Queue

When the precomp render is complete:

  • On the node, set the Read State to Precomp (from Live)

Other details:

  • There are filtering options:
    • Run precomp with crossfilter:
      • to clean up noise (baked into precomp)
    • Enable Color Variance Override
  • Switch Read State to Precomp_filtered to pickup the variants.

HueCorrect

Nuke standard node:

  • <Ctrl> <Alt> click to lock on a color
  • Select the categories on the left of the panel, and adjust the curves.

Lightwrap Disney

Bloom or lens diffusion.

  • Tab > LightWrapDisney

Useful when overring onto a bright background.

Options:

  • Wrap Controls (BG Over FG):
    • Wrap Width
    • Wrap Strength
  • OUTPUT:
    • Full Composite
    • Wrap BG Over FG Only
    • Bleed FG Over BG Only
    • Bloom Highlights Only

Better Bloom

Available in Shadow Box (in Default).

Overall bloom and glow but with more controls:

  • Uncheck Enable Mask
  • Find a range with histogram graph
  • You can layer glows and blooms by activating Enabled on a new rank.

SHD Saturation

  • Tab > SHDSaturation
  • Plug color pass into SurfaceColor
  • Plug render/image into Image
  • Mask as needed.
  • Click on Matte Preview:
    • False color guide to mask strength:
      • Red - highs
      • Green - mids
      • Blue - darks
  • There are controls to Saturate AND Tint for:
    • Hights
    • Mids
    • Lows

Use mattes to isolate areas. (Mask pipe)

Artzy Checker

A diffuser (Kuwahara filter) to help assess frame values.

  • FilpX and FlipY to help obfuscate familiarity.

Simple Volume

NOTE: Not good with motion blur.

Hyperion volume has shadow occlusions and details - Nuke version is very clean (although there is a shadows tab; but it might not work too well).

In Shadow Box look for SimpleVolumeBasic.

Volume visibility will be very low by default:

  • SingleVolumeDist:
    • Set Extinction Distance to something higher (100000)
    • Eccentricity:
      • -1 -> Dense smoke
      • 1 -> Soft atmosphere or vapor

Setup:

  • bg <- Depth pass
  • obj/scn <- Cam (or Scene)
  • Scene will have a light be default:
    • You can disconnect and add your own light:
      • Perhaps a directional Nuke
      • You can export lights from Houdini
      • RMB on a light:
        • Copy Light to Clipboard for Nuke
        • <Ctrl> + V in Nuke to paste the light.

Position bounding box around area

In the 3d view in Nuke (Tab in viewer):

  • Import geo from Quip:
    • Bottom of Quip panel has scene geo - import
  • Add PositionToPoints node from a hy_all_utility node:
    • Set surface point to pos
    • Set surface normal to normal
  • Plug the output from the PositionToPoints node into your Scene node.
  • In the SimpleVolume node, click on:
    • Bounding Volume tab:
      • Click on Auto Set Bounding Box button to set to the points.

TIP: Nuke Edit > Preferences > Viewer Handles > 3D Navigation -> Maya.

Bokeh Disney V2

Strictly used with Supervisor direction. Used to 'fix' DoF issues or introduce an art directed effect, not achievable in Hyperion.

Render scene WITHOUT Depth of Field (DoF) if using this node.

DO NOT APPLY AT END OF COMP. Large changes in focus does not work well.
  • Tab > BokehDisneyV2
  • Plug Depth pass into alphaZ
  • Render into img

Rather than use across an image (comp) add to each layer (clone if necessary to keep consistent settings across layers).

  • Switch Output Type to Focal Plane Visualization to get a false color 'map' of front, focus and back blur.
  • Switch back to Defocused image for final effect.

Mattes

Use a 'Merge In' node to combine the original alpha with the mattes created with these tools.
