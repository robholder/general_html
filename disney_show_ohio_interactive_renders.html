Helios: Interactive Rendering

  • Select interactiveRender node. (Next to 'Interactive' backdrop note)
  • On parm panel (of node):
    • Hit Interactive Render button
    • Switch on Hyperedit button for update with changes

Icons in Helios

  • Arrow:
    • select items in the render and see the path show up.
  • Magnifier:
    • Show pixel values
  • Red-X:
    • start/stop rendering toggle.
    • Restarting doesn't update the scene with changes
  • Blue Arrow:
    • Send current render to catalog
    • RVit can stack image snapshots in its own sidebar
    • Save catalog and re-open in RV
  • Exposure Slider:
    • view only

Helios: Menu Items and Shortcuts

  • Helios: Edit > Lock (toggle):
    • You can now tumble in the renderview like a viewer!
    • Useful for seeing if items are culled (off screen items)
  • / - Sidebar toggle (emission category list)
  • \ - Denoise toggle

Helios: Sidebar

  • Shows emission categories and AOV passes

Hyperedit

When looking at a lightbox parm panel, there are two Hyperedit buttons:

  • One above the rig tree:
    • Select lights
    • Click Hyperedit button to update the selections lights
  • One on the main panel:
    • Update scene
    • Live edit checkbox:
      • update continuously

Lightboard

  • Add the pane with a +:
    • Look for Lightboard
  • Start a Helios render:
    • Select the FINAL_RENDER node in Houdini (not the [[interactiveRender]] node)
  • The FINAL_RENDER will be way too many samples for interactive/Helios:
    • In the Render tab of the FINAL_RENDER node:
      • Click cog icon > set override
      • Set samples to 16/32/64 or whatever
      • Choose what to include (Xgen, SSS, etc.)
    • Click Interactive Render again.

When Helios is set on the FINAL_RENDER and rendered:

  • Set to a specific lightbox node
  • Set to exposure node (render settings node)
  • Set Hyperion node to FINAL_RENDER node

To view:

  • Cycle icon (Import rendered image)
  • Lightbox menu has denoise button (takes a moment).
  • The lights will show up in panel, and you can adjust:
    • Values
    • Colors
  • Arrow into screen:
    • Send 'new' values back to real lights
  • Arrow out of screen:
    • Retrieve values from Houdini
NOTE: light list is limited by only showing light categories, so shared emission numbers spoil it.
NOTE: The renderlog has a red-x button to cancel the render.
