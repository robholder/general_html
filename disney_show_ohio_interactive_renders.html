Notes

Ion

  • Ion is the interactive port (Houdini Viewport setting)
  • GPU render

Viewport Settings

  • Click on cam widget (persp, shotcam):
    • Render Settings
    • Stop rendering
  • Things not accurate:
    • Xgen
    • Cucoloris (Gobos)

Ion: Settings 'd' in Viewport

  • d to open settings:
  • Show Options For: Set to Ion
    • Permanent:
      • Render tab:
        • Samples per pixel: 32, 64 etc. (as in Helios/Hyperion)
        • Some options are mirrors of the Sidebar (Right) Icons
          • Enable Default White Dome Light
          • Enable Volumes
      • Temporary (in other words DON'T LEAVE ON!:
      • Exposure (only Viewport!)

Sidebar (Right) Icons

  • RGB icon - Set on/of:
    • Global Illumination
    • Direct
    • Ambient Occlusion (white)
    • Base Color (no lighting)
  • Default dome light
  • Enable Default White Dome Light
  • Enable/Disable Selections

Chimera

Good for

  • Chimera can run Presto (animation dept)
  • Good for eye-specs

Notes

  • Switching Viewport render engine will be laggy.
  • Shows Xgen as guides
  • No bounce
  • Light values inaccurate

Chimera: Settings 'd' in Viewport

  • d to open settings:
  • Show Options For: Set to Chimera

Chimara: Sidebar (Right) Icons

  • Enable/Disable lights
  • Enable/Disable Headlight

Scene Graph Tree

Three indicators (Two are only for Viewport):

Viewport only:

  • L:
    • Managing memory
  • On/Off icon:
    • Prune from scene
  • Star icon:
    • Solo selection

Viewport & Render:

  • Eye icon:
    • Visibility

Tips

  • x for snapping menu
  • Use targeting manipulators for lights
