Gnome - Apps On Taskbar

Title Bars

To set app (open window/instance) indicators on the taskbar for All workspaces: 

gsettings set org.gnome.shell.extensions.dash-to-dock isolate-workspaces false

To set app (open window/instance) indicators on the taskbar for current workspace: 

gsettings set org.gnome.shell.extensions.dash-to-dock isolate-workspaces true
