Tmux - Nudging Window Dividers

You can easily nudge, resize, or shift window dividers (panes) in Tmux using keyboard shortcuts.

Fine-Grained Nudges (1 cell at a time)

Press your prefix key (usually Ctrl + b, or j), then hold Ctrl and press an arrow key: [[[

  • <prefix>, then <Ctrl> + Up \ rightarrow <- Nudge divider up
  • <prefix>, then <Ctrl> + Down \ rightarrow <- Nudge divider down
  • <prefix>, then <Ctrl> + Left \ rightarrow <- Nudge divider left
  • <prefix>, then <Ctrl> + Right \ rightarrow <- Nudge divider right

(Tip: Because these are repeatable commands, you don't have to keep pressing <Ctrl> + arrow for every single nudge. Once you press prefix, you can tap <Ctrl> + Arrow repeatedly as long as you do it quickly).

Larger Nudges (5 cells at a time)

If you want to move the divider faster, use Alt instead of Ctrl after your prefix: Ctrl + b, then Alt + Up / Down / Left / Right
