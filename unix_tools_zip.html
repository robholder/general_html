Secure Compressed Zip Files

To compress a file with security on the commandline (tested on MacOS):

To compress without password, just omit the e from the -er flag. The r is recursive; for zipping directory contents. 

zip -er <file.zip> <file_to_zip>

# <enter>
# Enter password
# <enter>
# Confirm password
# <enter>

# compressed file will be created

# Example:
zip -er myfile.zip myfile.txt

# Will create secure myfile.zip archive

Regular:

  • zip -r <ZIP FILE> <FILE/DIR TO ZIP>

With encryption:

  • zip -er <ZIP FILE> <FILE/DIR TO ZIP>

Unzip

unzip backup.zip

Adding Date to Zip

Depending on shell type, you might get this to work: 

zip -r backup_$(date +%F).zip foldername

TCSH

tcsh (and csh) don’t support the Bourne-style command substitution $(…). You get “Illegal variable name.” You need to use backticks: 

zip -r backup_`date +%F`.zip foldername

This runs date +%F in backticks, inserts its output into the filename, and then compresses foldername into something like backup_2025-08-12.zip.

Excluding Hidden Files

Exclude hidden files or specific patterns (optional) If you need to omit hidden files (or any pattern), use the -x flag: 

zip -r backup.zip foldername -x "foldername/.*"

This skips everything whose name starts with a dot inside foldername[^8]

A Thorough Breakdown

The zip utility is a powerful command-line tool used to compress and package files.

Core Command Syntax

zip [options] archive_name.zip file1 file2 folder1
unzip archive_name.zip

Essential Options & Flags

  • -r (Recursive): Compresses an entire directory and all of its contents (subfolders and files). Crucial for folders.
  • -e (Encrypt): Prompts you to enter and verify a password to secure the ZIP file.
  • -m (Move): Deletes the original source files after the ZIP archive is successfully created.
  • -q (Quiet): Suppresses the standard output so Terminal doesn't list every file being compressed.
  • -v (Verbose / View): Shows detailed compression progress, or lists the contents of an existing ZIP without extracting it (e.g., zip -v archive.zip).
  • -0 to -9 (Compression Level): Controls speed vs. size. -0 means no compression (just packaging), while -9 offers maximum compression (slowest).

== Practical Examples

1. Zipping Folders & Files ==

Compress a single folder and everything inside it

zip -r archive.zip my_folder/
# Compress multiple individual files together
zip archive.zip document.txt photo.jpg notes.pdf
# Maximize compression on a heavy folder
zip -r9 archive.zip heavy_folder/

2. Encrypting (Method 1)

Compress a folder with password protection

zip -er secured_archive.zip sensitive_folder/

Note: Using -e will securely prompt you to type the password in the terminal. Avoid using flags like -P password because your password will remain visible in your command history.

3. Unzipping

Extract everything to the current directory

unzip archive.zip
# Extract a password-protected ZIP (it will prompt for the password)
unzip secured_archive.zip
# Test the validity of a ZIP file without extracting it
unzip -t archive.zip
# Extract contents directly into a specific destination folder
unzip archive.zip -d /path/to/destination_folder/

macOS vs. Linux Differences

While zip behaves similarly on both operating systems, there are two major differences to note:

Feature macOS Linux
Hidden Metadata Automatically includes hidden metadata folders like __MACOSX and .DS_Store. These clutter the folder when unzipped on Windows/Linux. Does not generate Mac-specific metadata.
Stripping Metadata Use zip -r archive.zip folder/ -x "*.DS_Store" "*__MACOSX*" to keep the ZIP clean for other platforms. Not required.
Encryption Standard The default -e flag uses standard ZipCrypto encryption. (Weak, but natively readable by Windows/Mac without extra apps). Same default, but modern Linux tools make it easier to pipe into stronger AES256 tools like 7z.

Simple Example for macOS

You can compress and encrypt files on macOS using the built-in Terminal app with the zip -er command.

Method 1: Use Terminal (Built-in & Free)

macOS does not offer a password option in the right-click menu, but you can use the Terminal app for a secure, cross-platform ZIP file. [3, 4]

  1. Open the Terminal app (search for it in Spotlight or find it in Applications > Utilities).
  2. Type cd (type cd followed by a space).
  3. Drag and drop the folder containing your files from Finder directly into the Terminal window, then press Enter.
  4. Type the encryption command: zip -er archive.zip foldername (replace archive.zip with your desired name and foldername with the name of the file or folder you want to compress).
  5. Press Enter, type your password, and press Enter again (characters will not show on screen as you type).
  6. Re-enter the password to verify and hit Enter.
