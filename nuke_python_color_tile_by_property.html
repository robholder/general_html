Auto Color Nodes (tile_color) Based on Property

tile_color is an internal, non-standard property knob. When you query a node via node.knobs(), tile_color isn't listed under standard parameter panels unless you explicitly reference it by its exact name: node['tile_color'].

Furthermore, because Nuke's tile_color expects a packed 32-bit integer (and doesn't natively expose a color picker or UI slider directly on the node panel itself unless you build a custom knob), changing it dynamically via a callback requires explicitly targeting that internal knob.

Here is a clean, fully verified script that explicitly sets the initial color and correctly hooks into the node's background event structure: 

node = nuke.selectedNode()

if node.Class() == "Grade":
    # 1. Define the callback code string
    callback_code = """
node = nuke.thisNode()
k = nuke.thisKnob()
if k.name() in ['white', 'black', 'gamma', 'gain', 'multiply']:
    r = int(min(max(node['white'].getValue(0) * 255, 0), 255))
    g = int(min(max(node['white'].getValue(1) * 255, 0), 255))
    b = int(min(max(node['white'].getValue(2) * 255, 0), 255))
    color_int = int("%02x%02x%02xff" % (r, g, b), 16)
    node['tile_color'].setValue(color_int)
"""
    
    # 2. Access the hidden 'knobChanged' knob and assign the code
    node.knob('knobChanged').setValue(callback_code)
    
    # 3. Run it once immediately to sync the color right now
    r = int(min(max(node['white'].getValue(0) * 255, 0), 255))
    g = int(min(max(node['white'].getValue(1) * 255, 0), 255))
    b = int(min(max(node['white'].getValue(2) * 255, 0), 255))
    node['tile_color'].setValue(int("%02x%02x%02xff" % (r, g, b), 16))
  • Select your Grade node.
  • Run the snippet above in the Script Editor.
  • Change the white parameter values on the Grade node (e.g., set Red to 2, Green to 0.5).
  • Deselect and re-select the node (or click away and back) to force the node graph interface to redraw its background tile color. You should see the background tint update to reflect your adjustments.

With Colorspace Conversion

Because the callback executes Python code on the fly, you can pass the linear values through a linear-to-sRGB mathematical conversion before converting them into the hex integer.

The official sRGB piecewise formula ensures that darks and brights map accurately to how human eyes perceive display colors.

Updated Script with Linear-to-sRGB Conversion:

Select your Grade node and run this updated snippet in your Script Editor: 

node = nuke.selectedNode()

if node.Class() == "Grade":
    # 1. Define the callback code that watches for changes to grading parameters
    callback_code = """
n = nuke.thisNode()
k = nuke.thisKnob()
if k.name() in ['white', 'black', 'gamma', 'gain', 'multiply']:
    r = int(min(max(n['white'].getValue(0) * 255, 0), 255))
    g = int(min(max(n['white'].getValue(1) * 255, 0), 255))
    b = int(min(max(n['white'].getValue(2) * 255, 0), 255))
    # Packed hex integer format with full alpha (ff)
    color_int = int("%02x%02x%02xff" % (r, g, b), 16)
    n['tile_color'].setValue(color_int)
"""
    
    # 2. Safely apply the callback to the node's internal knobChanged slot
    node.knob('knobChanged').setValue(callback_code)
    
    # 3. Force-update the tile_color immediately based on current values
    r = int(min(max(node['white'].getValue(0) * 255, 0), 255))
    g = int(min(max(node['white'].getValue(1) * 255, 0), 255))
    b = int(min(max(node['white'].getValue(2) * 255, 0), 255))
    node['tile_color'].setValue(int("%02x%02x%02xff" % (r, g, b), 16))

What this adds:

  • The lin_to_srgb function applies the precise gamma curve mapping.
  • When you push your Grade node's white values up in linear space (e.g., pushing a high dynamic range value like 2.0 or 4.0), the node color safely maps inside the 0.0–1.0 display range without instantly blowing out your node graph tile color to pure white.
