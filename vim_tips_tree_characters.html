Diagrams (like Tree hierarchies)

Vim handles Unicode characters natively and provides a few built-in ways to type characters like │, ├, and └ directly from your keyboard without needing to copy and paste.

The two best methods to do this in Vim are Digraphs and Unicode Hex Entry.

Method 1: Using Digraphs (Ctrl-K)

Vim has built-in shortcuts called "digraphs" for typing special characters.

While in Insert Mode:

  • Press Ctrl-K
  • Type a two-character code representing the box-drawing piece.

Common box-drawing codes include:

  • │ (Vertical): Type Ctrl-K then v| (or Vv)
  • ├── (Branch): Type Ctrl-K then tq
  • └── (Last branch): Type Ctrl-K then la (or bl)

(You can see the full internal list by typing :digraphs in command mode).

Method 2: Typing by Unicode Hex Code (Ctrl-V)

If you know the Unicode hex value of the character you want, you can type it directly.

While in Insert Mode:

  • Press Ctrl-V (or Ctrl-Q if your terminal intercepts Ctrl-V)
  • Type u followed by the 4-digit hex code.

Box-drawing hex codes:

  • │ : Press Ctrl-V, then type u2502
  • ├ : Press Ctrl-V, then type u251c
  • └ : Press Ctrl-V, then type u2514
  • ─ : Press Ctrl-V, then type u2500

(For example, typing Ctrl-V u251c followed by Ctrl-V u2500 u2500 will output ├──).

Example Hierarchy Diagram:

root-folder/
├── <folder-name>/
│   ├── <file-name>
│   └── <file-name>
├── <folder-name>/
│   ├── <sub-folder>/
│   │   └── <file-name>
│   └── <file-name>
├── <file-name>
└── <file-name>
