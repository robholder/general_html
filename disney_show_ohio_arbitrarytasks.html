OHIO - Training

Arbitrary Task Modules

Task Modules:

  • Packets of Data that make up the entirety of the shot
  • Hierarchy of modules

Hierarchy Possibilities:

  • Sequence
    • Subsequence
  • Scene
    • Subscene
  • Packet
    • Supacket
  • Shot

The impact of planning get's in the way when the hierarchy has to be run by Shotgun. This strict adherence has been relaxed.

Scene Builder

Scene Builder is the way the sequence and shots are built.

If there are no Task modules except the top most sequence task module (i.e., missing: scene, packets, etc.), scene_builder will take the whole list of sequence shots,and create a wide node graph where each 'shot node' is set in a sequential row across the graph (emanating from the top 'sequence' node). Not ideal. 

LoadShot
├── 229.0
│   ├── 001.00
│   ├── 002.00
│   ├── 003.00
│   ├── 004.00
│   ├── 005.00
│   ├── 006.00

│   ├── 008.00

When the shots have been designated with Scene, Packets, Subpackets...

│       ├── Packet A - Swamp Intro
│       │   ├── Subpacket A - closeup

│       ├─ Packet B - Eyes
└── etc.

The organized structure will influence the layout of node streams in Houdini with scene_build; where there are a branches leading off to the various layers of hierarchy.

Modes

There are two modes:

  • Build
  • Edit

Edit

This enables the creation of the hierarchy (scenes, packets, etc.).

  • RMB >
    • Add Task Module
    • Rename Task Module
    • Mark for Deletion
    • Unmark for Deletion
    • Undo Changes
    • Open in Shotgrid

After the hierarchy build, shots can be dragged and dropped into the various directories to organize the sequence.

  • You can add suffix terms (Label)
  • There's an undo
  • Deleting turns items red and struckthrough, but they only delete on completion.

Commit

  • When done, you have to save or commit the changes
  • Add a 'commit' message in the field at the base.
  • Export Hierarchy:
    • You can click on show Terminal output as it works through.

Things going on:

  • Shotgrid supplies the starting hierarchy
  • Prod keeps track with this.
  • When a commit is made:
    • The change is NOT sent to Shotgrid
    • The scene_builder hierarchy is sent to Conduit.
    • From here on, Conduit supplies the hierarchy
    • (outside of Shotgrid)

Build UI

This is artist level workflow.

To create an Houdini file for your allocation:

  • Select the highest point on your allocated group:
    • e.g., Packet C
    • Don't select the shots below; it will build up and down.
    • You can choose Custom Dir to give the enclosing dir another name.
  • Click Build

In Use

  • Navigate to seqData of shot:
    • n <seq> seqData lighting
  • Run scene_builder
  • The UI shows the sequence hierarchy.
  • There's a filter in the top left (to add username, numbers, etc.)
  • You might have to click the little filter lozenge if your shots don't show.
  • Choose the point of origin (Packet perhaps)
  • Running scene_builder will always create lighting_v0001.hip:
    • You will be warned it it already exists.
    • You can use Custom Dir to write to a different directory

Scene Builder in Houdini

  • RMB on the pane bar
  • Scene Builder:
    • Hierarchy will build
  • You can select a network source:
    • Scene/Packet/Shot
    • There's an option to Build selected nodes only
    • Build
    • The network will build commited modules into your scene file:
      • Connections to common ancestors will be made
      • The Build selected nodes only option will only install 'missing' modules for that element (Packet/Shot) and connect into the existing nodes.
        Only changes that have been committed will be inherited/installed.

After Building

Inside seqData, and inside your username directory, you'll find a sub directory with the scene, packet or shot name (from scene_builder).

Inside THERE will be a houdini directory, and inside there will be the actual built Houdini hip file.

Houdini

There is an optional checkbox on scene_builder ('Launch Houdini') to launch Houdini on completion of the build if required.

Open the scene in Houdini:

  • run_houdini lighting_v0001.hip
  • Maybe re-save as lighting_v0002.hip immediately.

Context Options Editor

In the Context Options Editor panel, you can choose which shots to have the scene conclude with or resolve to. You'll see a drop down with the shots that have been built into the 'hip' file (the shots of the packet).
