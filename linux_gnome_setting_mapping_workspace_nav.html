Gnome - Mapping h & l to Workspace Navigation

To set: 

gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-left "['<Control><Alt>Left', '<Control><Alt>h']"
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-right "['<Control><Alt>Right', '<Control><Alt>l']"
gsettings set org.gnome.desktop.wm.keybindings move-to-workspace-left "['<Control><Alt><Shift>Left', '<Control><Alt><Shift>h']"
gsettings set org.gnome.desktop.wm.keybindings move-to-workspace-right "['<Control><Alt><Shift>Right', '<Control><Alt><Shift>l']"

To revert: 

gsettings reset org.gnome.desktop.wm.keybindings switch-to-workspace-left
gsettings reset org.gnome.desktop.wm.keybindings switch-to-workspace-right

GNOME's keybinding settings accept arrays of strings, meaning you can assign multiple shortcut combinations to the exact same action (e.g., keeping the arrow keys while adding <Ctrl><Alt>+h and <Ctrl><Alt>+l for left and right navigation).

Because GNOME's default settings UI only allows one shortcut per action, you can use the command-line tool gsettings to append your custom keybinding.

How to add + h (Left) and + l (Right)

Open your terminal and run the following commands to add your new shortcuts alongside the existing arrow keys:

For switching to the workspace using 'h' and 'l':

gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-left "['<Control><Alt>Left', '<Control><Alt>h']"
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-right "['<Control><Alt>Right', '<Control><Alt>l']"

Optional: If you also want to move windows using these keys

If you want the ability to drag current windows with you to the adjacent desktop using those keys, you can apply the same array logic to the "move window" actions: 

gsettings set org.gnome.desktop.wm.keybindings move-to-workspace-left "['<Control><Alt><Shift>Left', '<Control><Alt><Shift>h']"
gsettings set org.gnome.desktop.wm.keybindings move-to-workspace-right "['<Control><Alt><Shift>Right', '<Control><Alt><Shift>l']"

How to revert if you change your mind:

If you ever want to wipe out the custom additions and reset them back to the plain defaults, you can simply reset the keys: 

gsettings reset org.gnome.desktop.wm.keybindings switch-to-workspace-left
gsettings reset org.gnome.desktop.wm.keybindings switch-to-workspace-right
