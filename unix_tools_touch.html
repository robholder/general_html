Touch

Using 'touch' to change dates

You use the touch command to change the creation or modification date of a file on both Linux and macOS.

By default, running touch filename updates the file's modification time to the exact current second. To set a specific date and time in the past or future, use the flags below.

How to Modify File Dates

  • Change to specific date/time: Run touch -m -t YYYYMMDDhhmm filename to set a custom modification time.
  • Format breakdown: The timestamp format reads sequentially as Year (4 digits):
    • Month (2), Day (2), Hour (2), and Minute (2).
  • Target modification only: Use the -m flag to explicitly change the modification date without touching the access date.
  • Target access only: Use the -a flag to explicitly change the access date without touching the modification date.

Examples

  • Set date to Christmas 2025 at 5:30 PM: 
touch -m -t 202512251730 sample.hip
  • Match another file's date exactly: 
touch -r reference_file.txt target_file.txt

A Note on "Creation Date" (Birth Time)

Linux and macOS handle true creation dates differently:

  • On macOS: You can change the actual creation date using the -t flag combined with -m and -a, or use the macOS-specific command setfile -d "12/25/2025 17:30:00" <filename>.
  • On Linux: Most Linux file systems (like ext4) strictly lock the creation time (btime) at the system kernel level when the file is written. You cannot manually alter or spoof the birth time on Linux without completely recreating the file or modifying raw file system blocks.

Do you need to batch-update an entire folder of files (like a sequence of Houdini caches), or are you trying to fix a specific file sorting issue in your finder/file explorer?

Batch

To batch-update the dates on an entire folder or a sequence of files, you combine the touch command with tools like wildcard expansions or the find command.

Here is how you can batch-update your files depending on exactly how you want to target them.

Option 1: Update an Entire Sequence (Using Wildcards)

If you have a numbered cache sequence or a folder of project files and want them all set to the exact same timestamp, use the asterisk (*) wildcard. 

# Sets EVERY file in the current folder to Dec 25, 2025 at 5:30 PM
touch -m -t 202512251730 *

# Sets only specific files (e.g., all .hip files starting with "smoke_v01")
touch -m -t 202512251730 smoke_v01.*.hip

Option 2: Update Recursively (Including Subfolders)

If you want to modify files hidden inside deep subfolder structures without changing the folders themselves, combine find with touch. 

# Finds all files in the directory and updates their modification dates
find . -type f -exec touch -m -t 202512251730 {} +
  • . looks inside your current directory.
  • -type f ensures you only touch files and leave folder modified dates alone.
  • -exec ... {} + batches the files together and runs the touch command on all of them instantly.

Option 3: Stagger the Times Sequentially (Advanced)

If you update a file sequence to the exact same second, your file explorer might sort them randomly instead of in order. You can use a quick shell loop to stagger the time, adding 1 minute to each consecutive file so they sort perfectly.

Run this directly in your Zsh terminal: 

# Sets the first file to 5:30 PM, the next to 5:31 PM, 5:32 PM, etc.
minute=30
for file in *.hip; do
  touch -m -t 2025122517${minute} "$file"
  ((minute++))
done
