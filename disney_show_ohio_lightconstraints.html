Simple Constraint

Step 1

Add a dlgt_simpleConstraint node

  • In the node graph:
    • <TAB> > dlgtSimpleConstraint below the light(s).

Step 2

In the node's parm panel, assign the Source & Target

  • Select the Light and add it to the Source path
  • Select the character in the scene graph and the rig_loc_grp.
  • Drag one of the locators into the Target path.

To identify which locator to constrain too use the dpipe_RigLocatorVisualizer tool.

  • James Lojo created this to make it easier to verify the locator positions and visualize how they are transforming.

Character rig Locators

  • Most characters have a rig_loc_grp that carries locators that lighting can constrain too.

Step 3 Select the Type of Constraint

  • Select the type of Constraint you would like, such as Point
  • Make sure Maintain Position is checked so your light doesn't move.

Step 4 Check the constraint

  • Drag in the timeline to make sure the constraint is working
  • If it isn't working check the following.
    • Make sure the source and target are correct.
    • Make sure the display flag is on the constraint or lower.
    • Check the rig locators position is correct.
  • If it still isn't working there is a possibility the characters rig locator is incorrect.
  • In this scenario you will need to constrain to the geometry either using the locator approach or a point constraint.

Palette Constraint

Another approach is to constrain to a Palette instead of a light. With this approach all lights added to that palette will follow the target.

Pros Cons
Preserves the position of the light Extra setup
Can Hyperedit from the light. No visual confirmation of Palette position
Single constraint for multiple lights Difficult to remove constraint without losing the lights position
Multishot - Easy to adjust light positions at any level Problematic with Point and Surface Constraints
Multishot - Easy to add more lights at any level. Doesn't have surface and point constraints
  Multishot - Can break if published locators change

In this example we want several lights to follow Moana and she has published rig_locators we can bind too.

Step 1 Create a new subPalette

  • Add a dpipe_SubPalette node above lightbox
  • Rename the node something descriptive
  • Assign the Parent Palette Path to lr_stage

Note that Palettes have Positional data and currently our new subPalette lives at the Origin.

Step 2 Constrain the subPallette

  • Add a dlgt_SimpleConstraint node above lightbox
  • Rename it
  • Assign the Source to this new sub Palette.
  • Assign the Target to one of the character's rig locators
  • Choose a Constraint type such as point
  • Make sure Maintain Position is selected

We have no visual confirmation but the subpallette is now Point constrained to the character.

Step 3 Add the lights to the subpalette

  • Select lightbox
  • Drag the lights to constrain under the new subPallette

Note: Lights created above the current lightbox can not change palettes! They need to be created in lightbox.

Caution

Sometimes the char rig locators don't follow the animation and are unusable for constraints. This is probably due to the animation being baked out. To check the position of locators use dpipeRigLocatorVisualizer.

If the locators aren't following the animation you will need to constrain to the geometry either using the locator approach or a point constraint.

Step 4 Check the constraint

  • Drag in the timeline to make sure the constraint is working
  • If it isn't working check the following.
    • Make sure the Source and Target are correct.
    • Make sure Point and Maintain Position are selected
    • Make sure the display flag is on the constraint or lower.

Locator Constraint

The final approach is the most versatile but takes more time to setup. By adding a dlgt_locator into the workflow we can constrain directly to the geometry and not be dependent upon locators published with assets.

Pros Cons
Preserves the position of the light more setup time
Can Hyperedit from the light. No visual confirmation of Palette position
Single constraint for multiple lights Difficult to remove constraint without losing the lights position
works with Point and Surface Constraints  
Inherits well down to shots  
Multishot - Easy to adjust light positions at any level  
Multishot - Easy to add more lights at any level.  
Multishot - Ability to change or replace the upper (locator) constraint But the constraint would have to be changed at top level !!

In an example we want to constrain several lights to follow a canoe.These will be setup at the sequence level and will be adjustable downstream in the shots.

Step 1 Create a new locator

  • Add a dlgt_locator above the lightbox
  • Rename it.

Step 2 Constrain the locator

  • Add a point constraint
  • Rename it.
  • Add the locator as the Source in the constraint
  • Select a piece of geometry and add as the Target

Next we need to select the points on the surface

  • Select the assignment arrow to the right or the Group field.
  • This will put the viewer in vertex selection mode.
  • Select a point or points and hit <Enter>

Be patient , this can take a moment to calculate.

dlgt locator

As of NEST the dlgt_locator node will show up in the viewer and have Guide options in the parameters.

Step 3 Create a subPalette

  • Add a dpipe_SubPalette node above lightbox
  • Rename the node
  • Assign the Parent Palette Path to lr_stage

Note that Palettes have Positional data and currently our new subPalette lives at the Origin.

Step 4 Constrain the subPalette to the locator

  • Add a dlgt_SimpleConstraint node above lightbox
  • Rename the node
  • Assign the subPalette as the source
  • Assign locator we created earlier as the Target
  • Choose a Constraint type such as Point
  • Make sure Maintain Position is selected

We have no visual confirmation but the subpalette will now follow the locator.

Step 5 Add the lights to the subpalette

  • Select lightbox
  • Drag the lights you want to constrain under the new subPallette

Step 6 Check the constraint

  • Drag in the timeline to make sure the constraint is working
  • If it isn't working first walk back through the steps
  • Checking the Source and Target
  • Change frames and back to the frame you built the constraints on

How to remove a Constraint

dlgt: Break constraint

This new node breaks a specified constraint upstream by removing the time samples on the xforms, but maintaining the position at the specified frame.

Method 1

This is a method for preserving the current position of a light when you either don't remember which frame you added a constraint or you inherited the constraint from another shot.

  • Change the frame to the desired light position.
  • RMB on the light in the scene graph and select Export Selected.
  • This will create a copy of the light in the current position.

Next Delete the constraint node.

  • Select the copy
  • RMB on Translate and select Copy Parameter
  • Now Select the original light
  • RMB on the Translate Paste values
  • The original light should be in the correct position now.
  • Delete the copy.

Alternatively you could delete the original light and rename the copy instead of transferring the position data.

Method 2

Disabling a constraint using the transform node.

  • Works well with removing palette constraints in a Shot.
  • Works for removing constraints on lights, locators, palettes.
  • No renaming or deleting needed.
  • The original lights are freed up.
  • Doesn't capture the current position of the light.

Go to the shot you where you want to remove the constraint.

  • Add a Transform and assign it to the palette which carries the constraint.
  • Check Set Absolute Transform

This will set the palette back to the origin, and the lights underneath it will be back to the position they were in when the palette was constrained.
