Simple Constraint

Step 1

Add a dlgt_simpleConstraint node In the node graph:

  • <TAB> & add a dlgtSimpleConstraint below the light(s).

Step 2

Assign the Source & Target

  • Select the Light and add it to the Source path
  • Select the character in the scene graph and the rig_loc_grp.
  • Drag one of the locators into the Target path.

To identify which locator to constrain too use the dpipe_RigLocatorVisualizer tool.

  • James Lojo created this to make it easier to verify the locator positions and visualize how they are transforming.

Character rig Locators

  • Most characters have a rig_loc_grp that carries locators that lighting can constrain too.

Step 3 Select the Type of Constraint Select the type of Constraint you would like, such as Point Make sure Maintain Position is checked so your light doesn't move.

Step 4 Check the constraint Drag in the timeline to make sure the constraint is working

If it isn't working check the following. Make sure the source and target are correct. Make sure the display flag is on the constraint or lower. Check the rig locators position is correct.

If it still isn't working there is a possiblity the characters rig locator is incorrect. In this scenario you will need to constrain to the geometry either using the locator approach or a point constraint.
