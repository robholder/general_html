Versioning

Disney had no real versioning system. Instead, we have a three stage plan.

  • temp:
    • Render submissions
  • current:
    • To Nuke
  • old:
    • Previous 'current'

Images are moved with manage_pics; layer/pass by layer/pass (only passes that exist in temp, not all images move):

  • Temp -> Current
  • Current -> Old
  • Old -> deleted permanently

If you don't manage_pics and re-render, temp is overwritten.

Flavors

These 'Flavors' exist in Houdini and Nuke.

Nuke

Fullcomp images can have different 'versions'

  • fullcomp
  • fullcomp_b

In Quip:

  • Flavor field:
    • Blank by default
    • Add flavor suffix here (it'll be added to the fullcomp directory name fullcomp.<your_flavor> and renderfarm name.)
    • This will render to a named directory:
      • fullcomp.<flavor_suffix>

(Directory contents are wiped eventually automatically.)

Backup

As a hack, you can rename the fullcomp directory to fullcomp_something if you want to free up the fullcomp directory for experiments; but flavors is better.

Houdini

You can also render flavor in Houdini.

Render-Submitter

In the Render Submitter dialog, there is a field named Flavor.

The pass name(s) won't change in the interface, but will render with the flavor suffix.

When you jump to Nuke, you can choose the flavor in Nuke's importer nodes' properties.

  • <pass-name>.<flavor>:
    • <ch_all> -> original pass name
    • <flavor> -> your 'flavor' suffix

In the render submitter dialog, there is a field for flavor:

  • Render submitter:
    • Flavor field
    • Add suffix
    • <pass>.<suffix>
    • e.g., ch_all.lifted

When reading into Nuke, choose Flavor:

NOTE: the pass names DON'T change in the Nuke dialogs/nodes, but it will take the images from the flavor directory version/flavor.

manage_pics

  • -h, --help:
    • show help
  • -x, --exclude:
    • Opposite of what you list (inverted mask)
  • --frames <FRAMES>:
    • Act on only listed <FRAMES>
    • e.g., 1-10:2 or 1,3,5,5-9
    • Runs --pickup underneath
    • "This flag implicitly sets --pickup"
  • -p, --pickup:
    • Merge frames in temp to current
    • Nothing gets moved to 'old'
DIRTY HACK: If you wanted to move old to current, you could rename the folders. Works, but is very unsatisfactory as a strategy!

Nuke

updatenuke

  • When running updatenuke choose from temp/current/old.
  • Final Nodes add the last nodes template
  • Update Shot Cameras to pick up revised cameras if needed:
    • essential if propagating scenes
  • Update Project Settings to revert to database settings (e.g., frame range)
    • essential if propagating scenes
