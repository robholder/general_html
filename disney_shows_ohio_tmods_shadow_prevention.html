TMODs - Prevent Shadowing

I haven't found documentation, but this is how it works.

Preventing One Object Shadowing Another

The counter intuitive thing here is that you cannot change a light's behavior.

You can only universally remove one objects influence (shadowing) on another (the shadow receiver) for every light in the pass.

How to set up the TMOD

Create a TMOD ('Transport Modifier') in Houdini's node graph and put in the stream before the render passes.

  • Source: object > the shadow casting object
  • Target: object > the shadow receiving object
  • At the end of the parameters in the Target tab:
    • Visibility to zero ('0')

The potential shadows from the Source object (for all lights) will now be eliminated from the Target object.

This is for all lights in the scene that potentially illuminate the Target.

If you only want to affect one light,  you have to create a special pass with this TMOD setup, and emissionOFF all other lights.

  • Create a dpipe Modifier
  • Set to emissionOFF type
  • Target patch:
    • :wdas:shot:lrig*:trs_master
  • Excludes:
    • Your lights
    • Example: :wdas:shot:lrigLOCAL:<your light path>
