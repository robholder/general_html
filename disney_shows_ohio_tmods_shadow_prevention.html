TMODs - Prevent Shadowing

I haven't found documentation, but this is how it works.

Preventing One Object Shadowing Another

The counter intuitive thing here is that you cannot change a light's behavior.

You can only universally remove one objects influence (shadowing) on another (the shadow receiver).

TMOD

  • Create a TMOD ('Transport Modifier') in Houdini's node graph.
  • Source: object > the shadow casting object
  • Target: object > the shadow receiving object
  • At the end of the parameters in the Target tab:
    • Visibility to zero ('0')

The potential shadows from the Source object (for all lights) will now be eliminated from the Target object.

This is for any light in the scene that illuminates the Target.
