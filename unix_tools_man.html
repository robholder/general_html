Unix Tools

man

Manuals for utilities and tools can usually be presented with man. 

man <command_name>
# e.g.,
man cal

To exit: 

q

Scrolling

Scroll with arrow keys (or Vim navigation h,j,k,l, or space for one page at a time).

Optionals

Optionals are optional arguments, and in the 'man' page, the optionals appear in square brackets.

Example: 

ncal [-31bhJeoSM] [-A number] [-B number] [-d yyyy-mm] [year]

man echo

Ellipsis

Ellipsis means 'one or more of', and in this case, it groups all the following options in the term 'OPTIONS': 

echo [OPTIONS]... [STRING]...

cp has required arguments (and here SOURCE and DEST) are required (source path and destination path): 

cp [OPTIONS]... SOURCE DEST

The core difference comes down to how many times you are allowed to use that option.

Direct Comparison

Syntax What it means How many times you can use it
[-f] (No ellipsis) The option is optional but can only be used once. 0 or 1 time
[-f]... (With ellipsis) The option is optional and can be repeated multiple times. 0, 1, or many times

A Real-World Example

Let's look at how this changes the actual behavior of two different commands:

1. Without Ellipsis: rm [-f]

The rm (remove) command takes a -f (force) flag. The man page might look like this: 

rm [-f] file
  • What you can type: rm file or rm -f file.
  • What you can't type: rm -f -f -f file. (Repeating it doesn't make sense or add any extra meaning).

2. With Ellipsis: ssh [-v]...

The ssh command uses -v (verbose mode) to print debugging details. The more -v flags you add, the more details it prints. The man page looks like this: 

ssh [-v]... hostname
  • What you can type:
  • ssh hostname (No verbose)
    • ssh -v hostname (Low verbose)
    • ssh -v -v hostname (Medium verbose)
    • ssh -v -v -v hostname (High verbose)

Summary Rule of Thumb

  • Square brackets [ ] mean "you don't have to type this."
  • Ellipsis ... means "you can type what's next to me over and over again."

Search Man Pages

Search all the 'man' pages on your system for a search term: 

man -k <search_term>

Search Within a Specific Command's Man Pages

You can search for a term directly from your terminal without opening the page, or while you are actively viewing the page.

1. While Viewing the Man Page (Interactive Search)

Once you have opened a man page (e.g., man grep), you are using a viewer program called less. You can use these keyboard shortcuts to find terms instantly:

  • /term : Type a forward slash followed by your word and press Enter to search forward from your current position.
  • ?term : Type a question mark followed by your word and press Enter to search backward.
  • n : Press n to jump to the next instance of that term.
  • N : Press Shift + n to jump back to the previous instance.

2. From the Terminal Line (Non-Interactive Search)

If you don't want to open the manual and scroll through it, you can pipe the man page directly into grep to extract only the lines containing your term: 

man ls | grep "human-readable"

If you also want to see a few lines of context around that term (like the flag and its description), use the -C flag with grep to show surrounding lines: 

man ls | grep -C 3 "human-readable"

This shows the matching line, plus 3 lines before it and 3 lines after it.
