MacOS

The macOS Slack app can show badge notifications (red dots or unread counts) on the Dock icon when you receive new messages.

To make sure this feature is enabled, you generally need to check two places:

1. Check Slack's In-App Preferences

  1. Open Slack on your Mac.
  2. Click your profile picture in the bottom-left corner and select Preferences (or use the top menu bar: Slack > Preferences).
  3. Go to the Notifications tab.
  4. Scroll down until you find the option labeled "Show a badge on Slack's icon to indicate new activity" and ensure it is checked.

2. Check macOS System Settings

  1. Open System Settings (or System Preferences) on your Mac.
  2. Click on Notifications in the sidebar.
  3. Scroll down and select Slack.
  4. Ensure that Allow Notifications is toggled on, and make sure Badge application icon is enabled.

Note: If badges still do not appear, ensure that your Mac is not in a Focus mode* or Do Not Disturb, which can sometimes suppress notification indicators.*

QUESTION

I don't see notification badges even though the option is 'on'. I don't see the Slack up in the list of apps in the System Settings 'Notifications' page/section.

ANSWER

That is a known macOS quirk: sometimes macOS fails to register an app in the Notification Center list until the app actually triggers its very first system notification or alert. Because Slack hasn't successfully pushed an alert through Apple's system layer yet, it won't show up in your System Settings.

You can force macOS to recognize Slack and add it to the list using these steps:

1. Trigger a Self-Reminder in Slack

  1. Open Slack and go to any chat (you can even go to your own "Jot something down" or a saved messages space, or message yourself in the "Direct Messages" section).
  2. Type the following command into the message box and press Enter: 
/remind me to test in 10 seconds
  1. Wait briefly for Slackbot to send you a reminder notification banner.
  2. The moment that notification banner pops up in the top-right corner of your screen, macOS is forced to register Slack.

2. Check System Settings Again

  1. Go back to System Settings > Notifications.
  2. Slack should now appear in the application list.
  3. Click on it and make sure Allow Notifications and Badge application icon are turned on.

Alternative Fix: Restart the Mac Notification Center

If the self-reminder trick doesn't immediately force it to show up, macOS's notification daemon might be stuck:

  1. Open Activity Monitor (search for it via Spotlight or find it in Applications > Utilities).
  2. Type Notification in the top-right search bar.
  3. Select NotificationCenter (or usernoted), then click the Stop (X) button in the upper-left toolbar to quit it.
  4. Confirm by clicking Force Quit (macOS will automatically restart the process instantly).
  5. Fully quit Slack (right-click the Dock icon and choose Quit), then reopen it and try the /remind trick again.
