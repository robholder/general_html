Eject Volumes Via Terminal

To safely eject external drives using the macOS Terminal, use the diskutil eject or diskutil unmountDisk command. This ensures all cached data is written to the drive before it is disconnected, preventing data corruption.

Step 1: Find the Drive Identifier

Before ejecting, you need to identify the target drive's identifier (such as disk2 or disk3).

  1. Open Terminal.
  2. Run the following command: 
diskutil list
  1. Locate your external drive in the list by looking at the NAME and SIZE columns.
  2. Note the identifier in the rightmost column (e.g., disk2, disk3, or a specific partition like disk2s1).

Step 2: Run the Eject Command

Depending on the type of drive, choose one of the following methods:

  • For standard thumb drives and USB hard drives (Recommended):
    • This completely spins down and prepares the entire physical drive for removal. Replace diskX with your drive's identifier (e.g., disk2): 
diskutil eject diskX
  • Alternative (For multi-partition drives or network shares):
    • If the standard eject command returns an error or you only want to unmount the volume structure: 
diskutil unmountDisk diskX

Troubleshooting: "Volume is in use" Error

If a background process or application is actively reading/writing to the drive, macOS will block the ejection.

  1. Force the unmount safely by adding the force modifier: 
diskutil unmountDisk force diskX
  1. Find what is blocking it: If you want to know what app is preventing a normal ejection, run: 
`lsof | grep /Volumes/YourDriveName`
