Finding a List of Emissions to Turn Off

Make sure the scene has the lgt_metadata node inline for Houdini renders (to allow for emission StickyNotes).

In Nuke, when 'Emission Notes' have been installed for all the Read Instances, select all that do not contribute to a render (of a pass).

Example

For a character:

  • If the Instance doesn't contribute to the comp for that pass:
    • Move the Read Instance down to the stream pipe (horizontal stream)
    • Switch off the 'Merge' node
  • Because of this visual technique, you can select all the emission notes for the pass in one sweep.
  • Run the following Python script to harvest all the emission light names: 
import re
import nuke

lights = []
nodes = nuke.selectedNodes()

for n in nodes:
  # Check if the node is a StickyNote to avoid errors on other node types
  if n.Class() == 'StickyNote':
    label_knob = n.knob('label')

    if label_knob:
      label_content = label_knob.value()

      # Regex to find everything between <font color=white> and </font>
      # This handles case-insensitivity and optional quotes around the color value
      matches = re.findall(
          r'<font\s+color=["\']?white["\']?>(.*?)</font>',
          label_content,
          re.IGNORECASE,
      )

      # Add found strings to our list (stripping any extra whitespace)
      for match in matches:
        lights.append(match.strip())

# Print the resulting list to the Nuke Script Editor
for light in lights:
    print(light)

Houdini

Creating the Selection List

  • Back in Houdini, go to the relevant render pass block (for the pass you've harvested the emissions to be switched off).
  • Add a dpipe Collections node just after the render settings node of the pass:
    • NOTE: If the light contributions are different per shot, add a pass edit for the customized shots/passes.
  • Create an empty Collection (perhaps name it lgt_emissionsOff_<render_pass>):
    • If you inadvertently find items in the collection, delete them from its inventory.
  • Switch the Collection list to 'text' mode.
  • Paste in the list from your edited light list (with the wdas addresses).
  • On the elements list part of the Collections parm panel (lower half), use the 'Collection Bindings' row of tools:
    • Select these patches

Setting EmissionsOFF

After the Collections node (you can actually set this node aside - the collection serves no purpose other than to be a selection set)

  • Create a dpipe Modifier node
  • Set to emissionsOFF
  • Select the light list using the Collections group method (as above)
  • Add them to the assignment section (Targets) on the emissionsOFF modifier node
