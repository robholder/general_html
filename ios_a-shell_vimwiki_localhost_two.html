Vimwiki Sync-and-Serve Setup for iPad (a-Shell)

Quick Recap

  • Purpose: To view local Vimwiki HTML files with fully colored syntax highlighting in Safari (via a local Python server running in a-Shell).
  • The Workflow: Keep a-Shell running in the background (using Split View or Slide Over), type your shortcut command, and open Safari at http://localhost:8000.

Step 1: Verify & Configure SSH Keys

Since your SSH keys are stored in ~/Documents/.ssh/, you need to make sure SSH knows where to look for them.

  1. Verify your keys exist: 
ls -la ~/Documents/.ssh/

You should see id_ed25519 and id_ed25519.pub.

  1. Create an SSH Config file so a-Shell knows where to find the keys: 
mkdir -p ~/.ssh
vim ~/.ssh/config
  1. Paste this configuration (press i to type): 
Host github.com
    HostName github.com
    User git
    IdentityFile ~/Documents/.ssh/id_ed25519

Press Esc, then type :wq and hit Enter to save.

  1. Test the GitHub Connection: 
ssh -T git@github.com

Type yes if asked about the fingerprint. If it says you've successfully authenticated, you're good to go!

Step 2: Set Up the Repository & Bookmarks

  1. Navigate to Documents and clone your repo via SSH: 
cd Documents
lg2 clone git@github.com:YOUR_USERNAME/YOUR_REPO_NAME.git Vimwiki

Replace YOUR_USERNAME and YOUR_REPO_NAME with your actual GitHub details.

  1. Navigate into your HTML folder and bookmark it: 
cd Vimwiki/general_html
bookmark vimwiki

Step 3: Create the Sync Script

  1. *Create and move into your bin folder:* 
cd ~/Documents
mkdir -p bin
cd bin
  1. Create the script file: 
vim sync_serve.sh
  1. Paste the following content (press i to type): 
# Keep app active
isForeground

# Kill any zombie python servers
killall python

# Jump to the bookmarked folder
jump vimwiki

# Sync with GitHub
lg2 pull

# Start the server in the background
python -m http.server 8000 &

Press Esc, then type :wq and hit Enter to save.

  1. Make the script executable: 
chmod +x sync_serve.sh

Step 4: Set Up Aliases

  1. Open your profile configuration: 
vim ~/.profile
  1. Add your aliases at the bottom (press i to type): 
alias server='sh ~/Documents/bin/sync_serve.sh'
alias which='alias'

Press *Esc*, then type :wq and hit *Enter* to save.

  1. Reload your profile: 
source ~/.profile

Step 5: Run and View

  1. Type your shortcut command in a-Shell: 
server
  1. Open Safari, navigate to http://localhost:8000, and bookmark it to your home screen or favorites.
  2. Keep a-Shell open in a Split View or Slide Over window to ensure the server keeps running smoothly.
