WC with 'ls' and 'eza'

== Word count to count line using ls or eza, you can pipe (|) their output into the wc -l (word count - lines) command.

To count files using ls or eza, you can pipe (|) their output into the wc -l (word count - lines) command.

Here is how to do it efficiently with both tools, depending on what you want to include:

1. Using ls

Combine ls with -1 (forces a single file per line) and wc -l:

  • Count visible files and folders: 
ls -1 | wc -l
  • Include hidden files (dotfiles): 
ls -1A | wc -l

2. Using eza

eza is a modern, faster replacement for ls and handles listing cleanly. Since eza defaults to columnar output depending on your terminal width, force it to list one item per line using -1:

  • Count visible files and folders: 
eza -1 | wc -l
  • Include hidden files: 
eza -1 -a | wc -l

Pro-Tip: Pure Files Only (Excluding Folders)

Both ls and eza count both files and directories together. If you want to count *strictly files* (ignoring subdirectories), the find command is usually more accurate: 

find . -maxdepth 1 -type f | wc -l

Deleting Files Based On Modified Time

To delete files based on their modified date, the find command is the standard and safest tool.

Here are the most common ways to do it, depending on whether you want to delete files *older than* or *newer than* a certain timeframe.

1. Delete Files Older Than X Days

To delete files that haven't been modified in *more than 30 days*, use the -mtime flag: 

find . -type f -mtime +30 -delete
  • .: Starts the search in the current directory.
  • -type f: Targets *files only* (protecting directories from being accidentally removed).
  • -mtime +30: Matches files modified more than 30 days ago. *(Use -mmin +60 if you want minutes instead of days).*
  • -delete: Removes the matched files.

2. Delete Files Newer Than X Days

If you want to clear out recent files—for example, removing files modified within the *last 2 hours* (-mmin -120): 

find . -type f -mmin -120 -delete

⚠️ Safety First: Preview Before You Delete!

Because the -delete action is permanent, it is always smart to preview what you are about to delete first. Replace -delete with -print to just list the files that match your criteria: 

# Preview first:
find . -type f -mtime +30 -print

# Run the delete only after verifying the list:
find . -type f -mtime +30 -delete

mtime

The -mtime (and related time-based flags) in the find command can be tricky because of how the mathematical sign (+ vs -) and time periods are interpreted.

Here is a complete breakdown of how -mtime, -mmin, and time calculations work.

1. The Core Operators (+, -, and Exact)

The sign you put before the number completely changes what find looks for:

  • +n (Older than): Means strictly greater than n periods old.
    • Example: -mtime +30 means modified more than 30 days ago (i.e., 31+ days old).
  • -n (Newer than): Means less than n periods old.
    • Example: -mtime -30 means modified *within the last 30 days* (i.e., anywhere from 0 to 29.9 days old).
  • n (Exactly): Means exactly n periods ago (rounded to the nearest 24-hour block).
    • Example: -mtime 30 means modified between 30 and 31 days ago. (This is rarely used because files are rarely timestamped to the exact second of a day boundary).

2. How -mtime Calculates a "Day" (The 24-Hour Rule)

-mtime does not count literal calendar days (like "since midnight"). Instead, it works in rolling 24-hour increments calculated backward from the exact second you run the command:

  • 1 day (-mtime 1) = 24 to 48 hours ago.
  • 0 days (-mtime 0) = Within the last 24 hours (0 to 24 hours ago).
  • +1 = Older than 48 hours.
  • -1 = Newer than 24 hours.

Common Pitfall with -mtime +0 vs -mtime -1:

If you want to target files created today or files older than today, people often confuse these:

  • find . -mtime +0 means older than 24 hours.
  • find . -mtime -1 means newer than 24 hours.

3. Finer Control: Minutes (-mmin)

If you need precision down to hours or minutes rather than full 24-hour days, swap -mtime for -mmin (modification time in minutes):

  • Older than 2 hours (120 minutes): 
find . -type f -mmin +120
  • Newer than 30 minutes: 
find . -type f -mmin -30

4. Advanced: Combining Time and Other Attributes

You can chain multiple time rules together (for example, finding files older than 7 days, but newer than 30 days): 

find . -type f -mtime +7 -mtime -30
  • -mtime +7 filters for older than a week.
  • -mtime -30 filters for newer than a month.
  • Combined, this targets files sitting in that specific 7-to-30-day window.

Quick Reference Cheat Sheet

Command Flag What it matches
-mtime +7 Older than 7 days (7+ days old)
-mtime -7 Within the last 7 days
-mmin +60 Older than 1 hour
-mmin -60 Within the last 1 hour
-mtime 0 Between 0 and 24 hours ago
