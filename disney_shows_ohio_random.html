OHIO - Training

Random

  • We are given shots:
    • e.g. 265/11.7
  • To navigate to the Houdini:
    • n 265 seqData lighting
    • cd <user>
  • Run scene_bulder:
    • scene_builder is a database structure, which is created to set an order/hierarchy of 'packets'
    • Packets appear as directories on disk
    • Packets appear as modules (nodes) in Houdini
    • This might be already setup in scene_builder:
      • When set, Build to create the directory/directories and set in the Houdini file
    • cd <packet directory>
    • cd houdini
    • run_houdini lighting_v0001.hip
    • (Note: Scene_builder can be run within Houdini to set up modules, but not the 'on disk' directories.
    • In a Shelf, there is a Version Up button
  • To navigate to the Nuke directory:
    • n 265 11.7 lighting
    • cd comp
    • run_nuke fullcomp_v0001.nk
    • In addition to 'Save' there is 'Save as version' to up the version number.
  • In each Packet or module:
    • Add a Light Box in a module.
    • Light Box nodes have a dedicated panel in Houdini (although they can be viewed in a regular parm panel too.
    • Light Boxes hold the olden day DLight/Disney light organization

Interactive Rendering

This is set with a special node that just hangs near the end of the graph:

  • You can set what to render (xgen, subsurface, volumes etc.)
  • You can set resolution
  • You an set SPP (samples):
    • For OHIO - I used 16, which is very low, but faster and enough to make assessments.
  • To trigger:
    • In a panel called Context Options Editor:
      • Choose which pass to render
      • Choose which shot to render
    • On a Shelf (a Lighting department shelf):
      • Interactive Render button
  • To actually render:
    • On a Shelpf (a Lighting department shelf):
    • Render Submitter
