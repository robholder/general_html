Tmux - Auto-Completion of Session Names

If your Tmux doesn't perform auto-completion of Session names with attach: 

tmux attach -t <Tab>

...then you have to employ some workarounds.

If you do not have sudo privileges, you can completely bypass system installation. You can download and run the official Tmux tab-completion script straight into your local home folder profile. Here is how to set it up manually for Bash or Zsh without needing root access.

If Your Shell is Bash

NOTE: THIS DIDN'T WORK FOR ME.

Download the completion script: Run this command to download the official script file directly from GitHub into your home directory: 

curl -fSsL "https://raw.githubusercontent.com/imomaliev/tmux-bash-completion/master/completions/tmux" -o ~/.tmux-completion.bash

Link it to your shell: Open your ~/.bashrc file with a text editor (like nano ~/.bashrc) and append this line to the very bottom: 

[ -f ~/.tmux-completion.bash ] && source ~/.tmux-completion.bash

Reload: Apply the changes instantly by running: 

source ~/.bashrc

If Your Shell is Zsh

NOTE: THIS WORKED FOR ME.

Zsh features a built-in completion system that does not require system-wide packages, but it needs to be initialized in your user file.

  • Open configuration: Open your ~/.zshrc file in a text editor.
  • Add initialization: Paste these lines at the very bottom: 
# Set up custom local completion paths
autoload -Uz compinit
compinit

Reload: Apply the changes instantly by running: 

source ~/.zshrc

Alternative: Use the "Choose-Tree" Overlay

If your corporate network blocks GitHub downloads entirely via firewall, remember you can completely bypass the command line. Press prefix_keys then s inside Tmux. This visual overlay is baked natively into the binary code, bypassing the shell autocomplete logic completely.
