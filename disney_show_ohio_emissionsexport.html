Emission Notes in Nuke

Add colored/named sticky notes in Nuke (to match each emission to the light in Houdini).

You need to export the data from Houdini to get this functionality in Nuke.

Houdini

Importing the Node

  • Launch Shadowbox from the Houdini Shelf:
  • Switch to the DEFAULT gig by selecting the drop-down
  • Under the Houdini category, you should see an lgtMetadata entry.
    • Select it and you should see a description and some screenshots on the right.
    • If you don't, you may have to enlarge the window to allow for the other UI widgets to show up.
  • On the upper right you should see an Import button. Click that to import into your node graph.
  • Connect the node to the main graph, just before the final Hyperion_Render node.
    • The reason for this, is to grab all lighting information at the end.
    • But it can be placed mostly anywhere in the graph, as long as the /DisneyRenderSettings prim is defined before it.
    • Typically it would be placed at the end however.

Nuke

You can import the stickies in Nuke via the updatenuke or the breakout tools or with Shadowbox ("Default/EmissionsNotes")
