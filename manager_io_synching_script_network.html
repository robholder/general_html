Synching Between Two Macs

Here is the complete, linear setup from scratch for macmini.local and macbook-m3.local (both with user noddy), keeping macbook-m3.local as the master machine while allowing you to trigger syncs from either Mac, check whether Manager.io is open, block accidental overwrites when a non-master copy is newer, and push changes back to master only with --reverse.

Overview of the Linear Order

  1. Enable Remote Login on both Macs so they accept SSH connections.
  2. Generate uniquely named SSH keys on each Mac (id_ed25519_macmini on macmini.local and id_ed25519_macbook_m3 on macbook-m3.local).
  3. Authorize each Mac's public key on the other Mac and configure ~/.ssh/config on each Mac so passwordless ssh works in both directions.
  4. Install and test sync-manager.sh on both Macs.

Step 1: Turn On Remote Login on Both Macs

  1. Enable Remote Login in System Settings: On macmini.local and macbook-m3.local.

On both Macs, open System Settings -> General -> Sharing and turn on Remote Login. Note each Mac's .local hostname (for example, macmini.local and macbook-m3.local).

Verification: On each Mac, the Remote Login toggle is on and when clicking on the 'i' displays ssh noddy@....

  1. Verify Network Reachability with ping: From macmini.local and macbook-m3.local.

From macmini.local, run ping -c 3 macbook-m3.local. From macbook-m3.local, run ping -c 3 macmini.local.

Verification: Both commands report 3 packets received with 0.0% packet loss.

Step 2: Create Uniquely Named SSH Keys on Each Mac

  1. Generate macmini.local's SSH Key Pair: Run on macmini.local.

In Terminal on macmini.local, create a dedicated key pair: 

ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_macmini -C "noddy@macmini.local"
chmod 700 ~/.ssh && chmod 600 ~/.ssh/id_ed25519_macmini && chmod 644 ~/.ssh/id_ed25519_macmini.pub

Verification: ls -la ~/.ssh/id_ed25519_macmini* lists both the private key (600) and .pub public key (644).

  1. Generate macbook-m3.local's SSH Key Pair: Run on macbook-m3.local.

In Terminal on macbook-m3.local, create its own uniquely named key pair: 

ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_macbook_m3 -C "noddy@macbook-m3.local"
chmod 700 ~/.ssh && chmod 600 ~/.ssh/id_ed25519_macbook_m3 && chmod 644 ~/.ssh/id_ed25519_macbook_m3.pub

Verification: ls -la ~/.ssh/id_ed25519_macbook_m3* lists both the private key (600) and .pub public key (644).

Step 3: Authorize Keys and Configure ~/.ssh/config Both Ways

  1. Authorize macmini's Key on macbook-m3 and Configure SSH: Run on macmini.local.

Push id_ed25519_macmini.pub into ~/.ssh/authorized_keys on macbook-m3.local, then add a host entry to ~/.ssh/config on macmini.local: 

cat ~/.ssh/id_ed25519_macmini.pub | ssh noddy@macbook-m3.local 'mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys'
touch ~/.ssh/config && chmod 600 ~/.ssh/config
cat <<'EOF' >> ~/.ssh/config

Host macbook-m3.local
User noddy
IdentityFile ~/.ssh/id_ed25519_macmini
IdentitiesOnly yes
EOF

Verification: Running ssh -o BatchMode=yes noddy@macbook-m3.local "echo mini-to-m3-ok" prints mini-to-m3-ok without asking for a password.

  1. Authorize macbook-m3's Key on macmini and Configure SSH: Run on macbook-m3.local.

Push id_ed25519_macbook_m3.pub into ~/.ssh/authorized_keys on macmini.local, then add a host entry to ~/.ssh/config on macbook-m3.local: 

cat ~/.ssh/id_ed25519_macbook_m3.pub | ssh noddy@macmini.local 'mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys'
touch ~/.ssh/config && chmod 600 ~/.ssh/config
cat <<'EOF' >> ~/.ssh/config

Host macmini.local
User noddy
IdentityFile ~/.ssh/id_ed25519_macbook_m3
IdentitiesOnly yes
EOF

Verification: Running ssh -o BatchMode=yes noddy@macmini.local "echo m3-to-mini-ok" prints m3-to-mini-ok without asking for a password.

Step 4: Install sync-manager.sh on Both Machines

Save this script as ~/bin/sync-manager.sh on both macmini.local and macbook-m3.local, and run chmod +x ~/bin/sync-manager.sh on each. 

#!/usr/bin/env zsh
set -euo pipefail

# Master machine (macbook-m3.local) and master file paths as stored ON macbook-m3
MASTER_HOST_SHORT="macbook-m3"
MASTER_SSH="noddy@macbook-m3.local"
MASTER_FILES=(
  "/Users/noddy/Library/CloudStorage/Dropbox/RealEstate/RHAZ/RanasingheAndHolder-AZ/Manager_io/RHAZ.manager"
  "/Users/noddy/Library/CloudStorage/Dropbox/RealEstate/Personal_Property_EquityShared/QueenCreek_FruitTreeLn/Manager_io/Kim_and_Holder.manager"
  "/Users/noddy/Library/CloudStorage/Dropbox/RealEstate/Personal_Property/Manager_io/HOLDER_AZ.manager"
)

# Secondary / non-master machine and folder (macmini.local)
PEER_SSH="noddy@macmini.local"
PEER_DIR="/Users/noddy/Documents/Manager.io"

REVERSE=false
DRY_RUN=false
FORCE=false

usage() {
  cat <<'EOF'
Usage: sync-manager.sh [--reverse] [--dry-run] [--force]

  --reverse    Push newer secondary changes back to the macbook-m3 master
  --dry-run    Preview what rsync would do without changing files
  --force      Skip the check for open Manager.io processes
EOF
  exit 1
}

for arg in "$@"; do
  case "$arg" in
    --reverse) REVERSE=true ;;
    --dry-run) DRY_RUN=true ;;
    --force)   FORCE=true ;;
    -h|--help) usage ;;
    *) echo "Unknown option: $arg"; usage ;;
  esac
done

CURRENT_SHORT="$(scutil --get LocalHostName 2>/dev/null || hostname -s)"
CURRENT_SHORT="${CURRENT_SHORT%.local}"

check_manager_closed() {
  [[ "$FORCE" == true ]] && return 0

  if pgrep -if "Manager(\.io|Desktop)?\.app" >/dev/null 2>&1 || pgrep -ix "Manager" >/dev/null 2>&1; then
    echo "WARNING: Manager.io is open on $CURRENT_SHORT. Quit it (Cmd+Q) or pass --force." >&2
    exit 1
  fi

  local remote_target=""
  if [[ "$CURRENT_SHORT" == "$MASTER_HOST_SHORT" ]]; then
    remote_target="$PEER_SSH"
  else
    remote_target="$MASTER_SSH"
  fi

  if ssh -o BatchMode=yes -o ConnectTimeout=5 "$remote_target" \
    'pgrep -if "Manager(\.io|Desktop)?\.app" >/dev/null 2>&1 || pgrep -ix "Manager" >/dev/null 2>&1' 2>/dev/null; then
    echo "WARNING: Manager.io is open on $remote_target. Quit it there or pass --force." >&2
    exit 1
  fi
}

get_local_mtime() {
  stat -f '%m' "$1" 2>/dev/null || echo 0
}

get_remote_mtime() {
  local host="$1"
  local file_path="$2"
  ssh -o BatchMode=yes -o ConnectTimeout=5 "$host" \
    "stat -f '%m' $(printf '%q' "$file_path") 2>/dev/null || echo 0"
}

check_manager_closed

RSYNC_OPTS=(-av --progress)
[[ "$DRY_RUN" == true ]] && RSYNC_OPTS+=(--dry-run)

if [[ "$CURRENT_SHORT" == "$MASTER_HOST_SHORT" ]]; then
  # Invoked FROM master (macbook-m3) -> sync against PEER_DIR on macmini.local
  for master_path in "${MASTER_FILES[@]}"; do
    if [[ ! -e "$master_path" ]]; then
      echo "Warning: Master file missing, skipping: $master_path" >&2
      continue
    fi

    filename="$(basename "$master_path")"
    peer_file="$PEER_DIR/$filename"
    master_mtime="$(get_local_mtime "$master_path")"
    peer_mtime="$(get_remote_mtime "$PEER_SSH" "$peer_file")"

    if [[ "$REVERSE" == true ]]; then
      if [[ "$peer_mtime" -eq 0 ]]; then
        echo "Skipping reverse sync (secondary file missing): $peer_file"
        continue
      fi
      echo "[REVERSE] Secondary -> Master: $filename"
      rsync "${RSYNC_OPTS[@]}" "${PEER_SSH}:$(printf '%q' "$peer_file")" "$master_path"
    else
      if [[ "$peer_mtime" -gt "$master_mtime" ]]; then
        echo "SKIPPED: Secondary '$filename' is newer than master. Use --reverse to push it to master."
        continue
      fi
      echo "[MASTER -> SECONDARY] $filename"
      ssh -o BatchMode=yes "$PEER_SSH" "mkdir -p $(printf '%q' "$PEER_DIR")"
      rsync "${RSYNC_OPTS[@]}" "$master_path" "${PEER_SSH}:$(printf '%q' "$PEER_DIR")/"
    fi
  done
else
  # Invoked FROM secondary (macmini) -> sync against MASTER_SSH
  mkdir -p "$PEER_DIR"

  for master_path in "${MASTER_FILES[@]}"; do
    filename="$(basename "$master_path")"
    local_file="$PEER_DIR/$filename"
    master_mtime="$(get_remote_mtime "$MASTER_SSH" "$master_path")"
    local_mtime="$(get_local_mtime "$local_file")"

    if [[ "$REVERSE" == true ]]; then
      if [[ ! -e "$local_file" ]]; then
        echo "Skipping reverse sync (local file missing): $local_file"
        continue
      fi
      echo "[REVERSE] Secondary -> Master: $filename"
      rsync "${RSYNC_OPTS[@]}" "$local_file" "${MASTER_SSH}:$(printf '%q' "$master_path")"
    else
      if [[ "$master_mtime" -eq 0 ]]; then
        echo "Warning: Master file not found on $MASTER_SSH, skipping: $master_path" >&2
        continue
      fi
      if [[ "$local_mtime" -gt "$master_mtime" ]]; then
        echo "SKIPPED: Local '$filename' is newer than master. Use --reverse to push it to master."
        continue
      fi
      echo "[MASTER -> SECONDARY] $filename"
      rsync "${RSYNC_OPTS[@]}" "${MASTER_SSH}:$(printf '%q' "$master_path")" "$PEER_DIR/"
    fi
  done
fi

How to Run From Either Machine

  • Preview without changing files: sync-manager.sh --dry-run
  • *Sync master (macbook-m3) to secondary (macmini):* sync-manager.sh (skips any file if the secondary copy is newer)
  • *Push newer secondary changes back to master (macbook-m3):* sync-manager.sh --reverse
