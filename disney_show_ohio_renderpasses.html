Making Passes

The passes pass down through the network.

  • Select the RenderPassManager node (at the base of each seq/packet/shot before output):
    • In the parms:
      • Create New Pass:
        • Template <- type
        • Category <- CHARS, ENV etc
        • Render Pass Name

Rename Passes:

  • You can rename passes on the last node of the backdrop.
  • Or in the Render Pass Manager parms

Rendering Pipeline

CLI tool to show render hours:

  • qssummary:
    • corehours in the main table shows render times
    • Core Hours shows actual time, bid time and the percentage of bid.
