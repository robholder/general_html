    • 64 spp

Making Passes

The passes pass down through the network.

  • Select the RenderPassManager node (at the base of each seq/packet/shot before output):
    • In the parms:
      • Create New Pass:
        • Template <- type
        • Category <- CHARS, ENV etc
        • Render Pass Name

Rename Passes:

  • You can rename passes on the last node of the backdrop.
  • Or in the Render Pass Manager parms

Rendering Pipeline

CLI tool to show render hours:

  • qssummary:
    • corehours in the main table shows render times
    • Core Hours shows actual time, bid time and the percentage of bid.

Render Submitter

  • Click Render Submitter button on the Houdini > Lighting tools menu.

the Dialog

  • On the left are the potential layers:
    • hotkey 'b' will toggle/gray-out the selection (not renderable)

To see all the current values:

  • RMB and choose Load Settings from Stage (or <Ctrl> + L)

Everything renders from the last 'Farm' node at the base of the Houdini network.

Switch to TC/Stero

Run on shot label (not individual passes).

  • RMB on shot number (or pass but not recommended) and choose:
    • Switch to Stereo and TC (1 item)
    • (or Switch to TC if that's all you need - probably not)
      The Switch to TC doesn't change the Samples!

You can change SPP in the submitter or the Node Graph.

To Switch back to non-TC

  • RMB on shot number (or pass but not recommended) and choose:
    • Switch to Mono: Turn off Stereo and TC
